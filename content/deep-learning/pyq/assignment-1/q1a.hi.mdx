**In simple words:** hidden units hidden layers ke neurons hain, yaani input aur output ke beech ki layers. Ye asli computation karte hain aur data ke useful patterns seekhte hain.

**Hidden unit kya karta hai:** ye pichhli layer ke outputs leta hai, unhe weights se multiply karta hai, bias add karta hai aur activation function lagata hai. Feedforward network mein hidden units "hidden units (apply weights + activation)" hain. <Cite id="class-dl-chp1" loc="slide 28" />

<Img id="class-perceptron-mlp-brain-hierarchy" caption="Hidden layers step by step seekhti hain: edges, phir corners aur contours, phir object parts, phir object." />

**Purpose:**

1. **Important patterns aur features seekhna.** Pehli hidden layer edges dhoondhti hai, agli corners aur contours, aur aise hi aage; zyada hidden layers zyada complex patterns seekhne dete hain. <Cite id="class-dl-m1" loc="p. 12" /> <Cite id="class-dl-chp2" loc="slide 2" />
2. **Non-linearity laana** activation function ke through, taaki network XOR jaisi problems solve kar sake jo single perceptron nahi kar sakta. <Cite id="class-dl-chp1" loc="slide 22" />
3. **Training data in layers ka desired output nahi dikhata**, isliye inhe hidden layers kehte hain. <Cite id="class-dl-m1" loc="p. 11" />

**Unit chunna:** rectified linear units ek excellent default choice hain; best type trial and error se validation set par dhoondha jaata hai. <Cite id="class-dl-m1" loc="p. 15" />

**Conclusion:** hidden units input se useful features nikaalti hain aur network ko complex relationships model karne ki power deti hain.
