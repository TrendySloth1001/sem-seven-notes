**In simple words:** hidden units are the neurons of the hidden layers, the layers between the input and the output. They do the real computation and learn the useful patterns in the data.

**What a hidden unit does:** it takes the outputs of the previous layer, multiplies them with weights, adds a bias and applies an activation function. In a feedforward network the hidden units are the "hidden units (apply weights + activation)". <Cite id="class-dl-chp1" loc="slide 28" />

<Img id="class-perceptron-mlp-brain-hierarchy" caption="Hidden layers learn step by step: edges, then corners and contours, then object parts, then the object." />

**Purpose:**

1. **Learn important patterns and features.** The first hidden layer detects edges, the next corners and contours, and so on; more hidden layers allow learning more complex patterns. <Cite id="class-dl-m1" loc="p. 12" /> <Cite id="class-dl-chp2" loc="slide 2" />
2. **Introduce non-linearity** through the activation function, so the network can solve problems like XOR that a single perceptron cannot. <Cite id="class-dl-chp1" loc="slide 22" />
3. **Training data does not show the desired output of these layers**, which is why they are called hidden layers. <Cite id="class-dl-m1" loc="p. 11" />

**Choosing the unit:** rectified linear units are an excellent default choice; the best type is found by trial and error using a validation set. <Cite id="class-dl-m1" loc="p. 15" />

**Conclusion:** hidden units extract useful features from the input and give the network its power to model complex relationships.
