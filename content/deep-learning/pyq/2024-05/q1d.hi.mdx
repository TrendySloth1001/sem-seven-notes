**In simple words:** undercomplete autoencoder ki beech ki layer patli hoti hai, to wo input copy nahi kar sakta aur sirf wahi rakhta hai jo important hai. <Cite id="class-dl-chp3" loc="slide 13" />

**Definition:** an Undercomplete Autoencoder is an autoencoder in which the hidden layer (Bottleneck/Code) has fewer neurons than the input layer. Because of this smaller bottleneck, the network is forced to compress the data and keep only the important features. <Cite id="class-dl-chp3" loc="slide 13" />

**"Undercomplete" kyun:** Code Size < Input Size. Example: input 784 neurons, bottleneck 64 neurons, output 784 neurons.

<Img id="class-autoencoders-under-architecture" caption="Undercomplete autoencoder: 784 → 64 → 784, goal Input ≈ Output kam neurons ke saath." />

**Kaise kaam karta hai:** (1) input encoder mein jaata hai, (2) encoder information compress karta hai, (3) bottleneck sirf important features store karta hai, (4) decoder input reconstruct karta hai, (5) loss calculate hota hai, (6) weights backpropagation se update hote hain. <Cite id="class-dl-chp3" loc="slide 13" />

**Advantages:** meaningful features seekhta hai, data efficiently compress karta hai, simple copying rokta hai, overfitting kam karta hai. **Disadvantages:** bahut chhota bottleneck important information kho sakta hai, aur bottleneck size dhyan se chunna padta hai. <Cite id="class-dl-chp3" loc="slide 14" />

**Uses:** image compression, feature extraction, dimensionality reduction. Textbook add karta hai ki isme explicit regularization term nahi hota, to sirf chhoti hidden layer use memorize karne se rokti hai. <Cite id="class-dl-m3" loc="p. 15" />

**Conclusion:** narrow bottleneck network ko memorize nahi, seekhne par majboor karta hai.

Exam mein English mein likho: "In an undercomplete autoencoder the code size is smaller than the input size, so the network must keep only the important features."
