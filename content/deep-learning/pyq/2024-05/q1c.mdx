**In simple words:** dropout means that during training we randomly switch off some neurons in each step, so the network cannot depend too much on any one neuron. <Cite id="srivastava2014" />

**Definition.** Dropout is a regularization method that sets randomly chosen neurons to zero at every training step. Large networks overfit because neurons come to depend on each other and together memorize the training data; dropout breaks that dependence.

**How it works.**

1. Choose a keep probability $p$, for example 0.5 for hidden layers.
2. For each training batch, keep each neuron with probability $p$ and switch it off otherwise; the next batch drops a different random set.
3. At test time keep all neurons. Either scale weights by $p$, or use *inverted dropout*, which scales kept values up by $1/p$ during training.

**Worked example (inverted dropout).** Given: four hidden neurons output 2, 4, 6, 8; $p = 0.5$; neurons 2 and 4 are switched off. To find: the values passed on.

1. Switched-off outputs become 0.
2. Scale the kept values by $1/p = 2$: $2 \times 2 = 4$ and $6 \times 2 = 12$.

**Answer: the layer passes on 4, 0, 12, 0.**

<Box kind="verify">

Average over many batches. A neuron is kept with probability 0.5 and then outputs twice its value, so for neuron 1 the expected output is $0.5 \times 4 + 0.5 \times 0 = 2$, its original value. For neuron 3 it is $0.5 \times 12 = 6$, also original. So dropout does not change the layer's output on average.

</Box>

**Advantages:** reduces overfitting without changing the loss; very cheap (a random 0/1 mask); acts like averaging many thinned networks; forces each neuron to learn useful features on its own. **Limitation:** training is slower because the signal is noisier, and $p$ must be tuned. <Cite id="gfg-dropout" />
