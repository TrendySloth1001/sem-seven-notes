**In simple words:** feedforward neural network ek layered network hai jisme information sirf ek hi direction mein chalti hai: input layer se, hidden layers ke through, output layer tak. Isme koi loop nahi hota. Jab har layer agli layer se fully connected hoti hai, use aksar multilayer perceptron (MLP) kehte hain. <Cite id="gfdl-ch6" />

**Ye kyun zaroori hai.** Ek perceptron sirf ek seedhi line bana sakta hai, isliye wo XOR nahi seekh sakta. Hidden layers network ko curved, complex patterns seekhne dete hain.

**Ye kaise kaam karta hai.**

1. **Input layer** features leti hai aur aage bhejti hai.
2. Har **hidden** neuron apne inputs ko weight deta hai, bias jodta hai, aur ReLU ya sigmoid jaisa non-linear activation lagata hai.
3. **Output layer** prediction deti hai (sigmoid, softmax ya linear).
4. Training mein loss nikalte hain, phir backpropagation aur gradient descent weights ko adjust karte hain.

**Advantages:** ye non-linear patterns seekhta hai, aur kaafi hidden neurons ho to ye closed aur bounded region ke kisi bhi continuous function ko approximate kar sakta hai. <Cite id="hornik1989" />

**Disadvantages:** sequences ki memory nahi hoti, badi images ke liye weights bahut zyada hote hain, aur bahut saare labelled data ki zaroorat padti hai.

**Applications:** tabular data par classification aur regression (credit scoring, diagnosis), aur CNNs ki aakhri dense layers.

**Conclusion.** Ye basic deep-learning model hai: one-way, layered aur non-linear.

Exam mein English mein likho: "A feedforward network passes information in one direction only, from input to output, with no loops."
