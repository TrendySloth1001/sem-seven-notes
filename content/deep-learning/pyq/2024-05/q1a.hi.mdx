**In simple words:** feedforward neural network wo network hai jismein information sirf ek direction mein jaati hai, input layer se hidden layers ke through output layer tak, bina kisi loop ke. <Cite id="class-dl-chp1" loc="slide 28" />

**Definition:** deep feedforward networks, jinhe feedforward neural networks ya multilayer perceptrons (MLPs) bhi kehte hain, prototypical deep learning models hain. Goal kisi function $f^*$ ko approximate karna hai; network $y = f(x;\theta)$ define karta hai aur wo parameters $\theta$ seekhta hai jo best approximation dein. <Cite id="class-dl-m1" loc="p. 10" />

<Img id="class-perceptron-mlp-ffnn-diagram" caption="Feedforward network: information input layer se hidden layer ke through output layer tak sirf aage jaati hai." />

**"Feedforward" kyun:** information $x$ se beech ki computations ke through output $y$ tak jaati hai, aur koi feedback connection nahi hota. Feedback connections hon to ye recurrent neural network ban jaata hai. <Cite id="class-dl-m1" loc="p. 10" />

**"Network" kyun:** kai functions chain mein jude hote hain, $f(x) = f^{(3)}(f^{(2)}(f^{(1)}(x)))$. Chain ki length depth hai; output ke alawa baaki layers hidden layers hain. <Cite id="class-dl-m1" loc="p. 11" />

**Key features:** data ka backward flow nahi, cycles ya loops nahi, output sirf current input par depend karta hai. **Example:** pass ya fail predict karna, handwritten digit recognition. <Cite id="class-dl-chp1" loc="slide 28" />

**Conclusion:** feedforward network simplest neural network hai aur deep learning models ki foundation hai.
