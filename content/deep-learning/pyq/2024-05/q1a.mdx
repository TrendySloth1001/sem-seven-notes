**In simple words:** a feedforward neural network is a layered network in which information moves in one direction only: from the input layer, through hidden layers, to the output layer. There are no loops. When each layer is fully connected to the next, it is often called a multilayer perceptron (MLP). <Cite id="gfdl-ch6" />

**Why it is needed.** One perceptron can draw only a straight line, so it cannot learn XOR. Hidden layers let the network learn curved, complex patterns.

**How it works.**

1. The **input layer** receives the features and passes them on.
2. Each **hidden** neuron weighs its inputs, adds a bias and applies a non-linear activation such as ReLU or sigmoid.
3. The **output layer** gives the prediction (sigmoid, softmax or linear).
4. Training: the loss is measured, then backpropagation and gradient descent adjust the weights.

**Advantages:** it learns non-linear patterns, and with enough hidden neurons it can approximate any continuous function on a closed, bounded region. <Cite id="hornik1989" />

**Disadvantages:** no memory for sequences, too many weights for large images, and it needs much labelled data.

**Applications:** classification and regression on tabular data (credit scoring, diagnosis), and the final dense layers of CNNs.

**Conclusion.** It is the basic deep-learning model: one-way, layered and non-linear.
