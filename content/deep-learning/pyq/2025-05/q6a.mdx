**In simple words:** the activation function is the "decision" step of a neuron. It takes the neuron's weighted sum and bends it, so that a stack of layers can learn complicated, curved patterns.

**Definition.** A neuron adds its weighted inputs and a bias to get $z$, then outputs $a = f(z)$, where $f$ is the activation function. Think of a dimmer switch: $z$ is how hard you push, $f$ decides how bright the bulb gets.

**Significance of activation functions**

1. **Without them depth is useless.** Straight-line layers combine into one straight-line layer. A non-linear function after each layer lets the network learn non-linear tasks like XOR, image and speech recognition. <Cite id="gfdl-ch6" loc="§6.1" />
2. **They set the output range,** for example (0, 1) for a probability.
3. **They decide how well gradients flow.** Backpropagation multiplies each layer's slope. If the function saturates (goes flat), gradients vanish and deep networks train badly. <Cite id="glorot2010" />
4. **They allow sparse, selective neurons** that are active only for some inputs (ReLU). <Cite id="glorot2011" />

**How it works.** Weighted sum → activation reshapes it → output to next layer; during training, its slope scales the error passed back.

**Different types**

- **Linear (identity),** $f(z) = z$: any output. *Pro:* simple. *Con:* no bend. Regression output only.
- **Sigmoid (logistic),** $\dfrac{1}{1+e^{-z}}$: S-curve into (0, 1). *Pro:* probability output. *Cons:* saturates (slope at most 0.25), vanishing gradient, not zero-centred. Binary output.
- **Tanh:** S-curve into (−1, 1). *Pro:* zero-centred, slope 1 at centre, better than sigmoid for hidden units. *Con:* still saturates. RNN, LSTM, GRU. <Cite id="gfdl-ch6" loc="§6.3.2" />
- **ReLU,** $\max(0, z)$: keeps positives, zeros negatives. *Pros:* fast, no vanishing for positive inputs. *Con:* dying ReLU. Standard hidden layer. <Cite id="gfdl-ch6" loc="§6.3.1" />
- **Leaky ReLU:** small slope $\alpha \approx 0.01$ for negatives. *Pro:* keeps neurons alive. *Con:* extra value to choose. Hidden layers.
- **Softmax:** turns a list of class scores into probabilities that add to 1. Multi-class output, for example digits 0 to 9.

| | Range | Zero-centred | Saturates | Typical place |
|---|---|---|---|---|
| Linear | any | yes | no | Regression output |
| Sigmoid | (0, 1) | no | yes | Binary output |
| Tanh | (−1, 1) | yes | yes | RNN hidden units |
| ReLU | [0, ∞) | no | no (for positive inputs) | Hidden layers |
| Leaky ReLU | (−∞, ∞) | roughly | no | Hidden layers |
| Softmax | (0, 1), sum 1 | no | can | Multi-class output |

**Conclusion.** Activation functions give neural networks their non-linear power and strongly affect training speed. ReLU-type functions are used inside the network; linear, sigmoid or softmax at the output, matched to the task.
