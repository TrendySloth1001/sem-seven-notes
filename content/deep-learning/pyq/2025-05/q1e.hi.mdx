**In simple words:** CNN image ko ek ek chhote patch se dekhta hai, chhote seekhe hue filters use karta hai jo pattern detectors ki tarah kaam karte hain, aur phir decide karta hai ki image mein kya hai.

**Ye kyun chahiye:** fully connected network ko images ke liye bahut zyada weights chahiye, aur wo ye bhi nahi janta ki kaun se pixels ek dusre ke padosi hain. <Cite id="gfdl-ch9" />

**Basic working**

1. **Convolution:** ek chhota filter (jaise 3×3) image pe slide karta hai, apne weights ko neeche ke pixels se multiply karta hai aur jodta hai. Output bada hota hai jahan filter ka pattern, jaise edge, dikhta hai.
2. **ReLU:** positive values rakhta hai aur negative ko 0 kar deta hai.
3. **Pooling:** jaise har 2×2 block ka max, jisse width aur height dono aadhi ho jaati hain.
4. **Steps 1 se 3 repeat:** shuruaati layers edges dhoondhti hain, baad ki layers shapes aur object ke parts.
5. **Flatten, phir fully connected layers aur softmax** class probabilities dete hain.

**Advantages:** shared filters ka matlab hai bahut kam weights, aur network apne features khud seekhta hai. **Limitation:** bahut data aur computation chahiye. <Cite id="gfg-cnn" />

**Applications:** image classification, face recognition, medical imaging. <Cite id="ibm-cnn" />

**Conclusion:** convolution aur pooling features nikaalte hain, aur fully connected layers unhe classify karti hain.

Exam mein English mein likho: "A CNN extracts features with convolution and pooling, then classifies them with fully connected layers."
