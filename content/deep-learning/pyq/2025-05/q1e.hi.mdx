**In simple words:** CNN picture ko waise dekhta hai jaise aap crowd photo scan karte ho: ek chhoti window ek baar mein, har jagah wahi sawaal poochte hue. Convolution aur pooling features dhundte hain; flatten aur fully connected layers class decide karte hain. <Cite id="class-dl-chp4" loc="slide 4" />

**Definition:** CNN ek deep learning model hai jo convolutional filters se images ke spatial features khud seekhta hai. <Cite id="class-dl-chp4" loc="slide 5" />

<Img id="class-cnn-arch-digits" caption="CNN ka basic working: input, convolution + ReLU, max pooling, flatten, fully connected layer, softmax." />

**Basic working** <Cite id="class-dl-chp4" loc="slide 28" />

1. **Input:** image numbers ka grid hai (RGB = 3 channels).
2. **Convolution + ReLU:** chhote filters image par slide karte hain (multiply aur add) aur feature maps dete hain; ReLU negatives ko 0 banata hai. Early layers edges dhundti hain.
3. **Pooling:** height aur width kam karta hai, depth nahi.
4. **Repeat:** deeper layers edges ko shapes aur object parts mein combine karti hain.
5. **Flatten:** 3D feature maps 1D vector ban jaate hain.
6. **Fully connected layer + softmax:** probabilities deta hai; sabse high wali predicted class hai.

**Ye kyun kaam karta hai:** local connectivity, weight sharing (har jagah same filter) aur pooling ki wajah se fully connected network se bahut kam parameters lagte hain. <Cite id="class-dl-chp4" loc="slide 5" />

**Conclusion:** CNN = features ke liye convolution + pooling, decision ke liye fully connected layers.
