**In simple words:** activation function neuron ka "decision" step hai. Yeh neuron ke weighted sum ko tedha kar deta hai, taaki layers ka ek stack jatil aur curved patterns seekh sake.

**Definition.** Neuron apne weighted inputs aur bias ko jodkar $z$ banata hai, phir $a = f(z)$ output deta hai, jahan $f$ activation function hai. Dimmer switch ki tarah socho: $z$ kitna zor se dabaya gaya hai, $f$ tay karta hai ki bulb kitna roshan hoga.

**Significance of activation functions**

1. **Inke bina depth bekaar hai.** Seedhi-line layers mil kar ek seedhi-line layer ban jaati hain. Har layer ke baad ek non-linear function network ko XOR, image aur speech recognition jaise non-linear kaam seekhne deta hai. <Cite id="gfdl-ch6" loc="§6.1" />
2. **Ye output ki range tay karte hain,** jaise probability ke liye (0, 1).
3. **Ye gradients ka flow tay karte hain.** Backpropagation har layer ki slope multiply karta hai. Agar function saturate hota hai (flat ho jaata hai), to gradients vanish ho jaate hain aur deep networks kharaab train hote hain. <Cite id="glorot2010" />
4. **Ye sparse, selective neurons banane dete hain** jo kuch inputs ke liye hi active hote hain (ReLU). <Cite id="glorot2011" />

**Kaam kaise karta hai.** Weighted sum → activation use shape deta hai → output agli layer ko jaata hai; training mein uski slope piche aane wale error ko scale karti hai.

**Different types**

- **Linear (identity),** $f(z) = z$: koi bhi output. *Pro:* simple. *Con:* koi bend nahi. Sirf regression output ke liye.
- **Sigmoid (logistic),** $\dfrac{1}{1+e^{-z}}$: S-curve jo (0, 1) mein jaata hai. *Pro:* probability output. *Cons:* saturate hota hai (slope zyada se zyada 0.25), vanishing gradient, zero-centred nahi. Binary output.
- **Tanh:** S-curve jo (−1, 1) mein jaata hai. *Pro:* zero-centred, centre par slope 1, hidden units ke liye sigmoid se behtar. *Con:* phir bhi saturate hota hai. RNN, LSTM, GRU. <Cite id="gfdl-ch6" loc="§6.3.2" />
- **ReLU,** $\max(0, z)$: positives rakhta hai, negatives ko zero karta hai. *Pros:* tez, positive inputs ke liye vanish nahi hota. *Con:* dying ReLU. Standard hidden layer. <Cite id="gfdl-ch6" loc="§6.3.1" />
- **Leaky ReLU:** negatives ke liye chhoti slope $\alpha \approx 0.01$. *Pro:* neurons zinda rehte hain. *Con:* ek extra value chunni padti hai. Hidden layers.
- **Softmax:** class scores ki list ko aise probabilities mein badalta hai jinka sum 1 ho. Multi-class output, jaise digits 0 se 9.

| | Range | Zero-centred | Saturates | Typical place |
|---|---|---|---|---|
| Linear | any | yes | no | Regression output |
| Sigmoid | (0, 1) | no | yes | Binary output |
| Tanh | (−1, 1) | yes | yes | RNN hidden units |
| ReLU | [0, ∞) | no | no (positive inputs ke liye) | Hidden layers |
| Leaky ReLU | (−∞, ∞) | roughly | no | Hidden layers |
| Softmax | (0, 1), sum 1 | no | can | Multi-class output |

Exam mein English mein likho: "Activation functions add non-linearity, which lets a neural network learn complex patterns."

**Conclusion.** Activation functions neural networks ko non-linear power dete hain aur training ki speed par gehra asar daalte hain. Network ke andar ReLU-type functions use hote hain; output par task ke hisaab se linear, sigmoid ya softmax.
