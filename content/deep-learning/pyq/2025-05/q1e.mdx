**In simple words:** a CNN looks at an image one small patch at a time, using small learned filters that act like pattern detectors, then decides what the image shows.

**Why it is needed:** a fully connected network needs far too many weights for images and ignores which pixels are neighbours. <Cite id="gfdl-ch9" />

**Basic working**

1. **Convolution:** a small filter (for example 3×3) slides over the image, multiplying its weights with the pixels below and adding them up. The output is large where the filter's pattern, such as an edge, appears.
2. **ReLU:** keeps positive values and sets negatives to 0.
3. **Pooling:** for example the max of each 2×2 block, which halves the width and the height.
4. **Repeat** steps 1 to 3: early layers find edges, later layers find shapes and object parts.
5. **Flatten, then fully connected layers and softmax** give class probabilities.

**Advantages:** shared filters mean far fewer weights, and the network learns its own features. **Limitation:** needs much data and computation. <Cite id="gfg-cnn" />

**Applications:** image classification, face recognition, medical imaging. <Cite id="ibm-cnn" />

**Conclusion:** convolution and pooling extract features, and fully connected layers classify them.
