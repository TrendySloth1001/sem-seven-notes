**In simple words:** activation function decide karta hai ki neuron fire kare ya nahi aur kitni strength se, aur ye network ko non-linear banata hai taaki wo complex patterns seekh sake. <Cite id="class-dl-m2" loc="p. 13" />

**Importance:**

1. **Non-linearity:** iske bina neuron sirf $y = z$ deta hai, to poora network linear model ban jaata hai aur sirf linear relationships seekhta hai. <Cite id="class-dl-m2" loc="p. 13" />
2. **Output control karta hai:** neuron ka firing aur output ki strength decide karta hai.
3. **Learning mein madad:** backpropagation mein gradients isse hokar flow karte hain; ReLU par vanishing gradient problem ka asar kam hota hai. <Cite id="class-dl-chp2" loc="slide 25" />
4. **Output range** task ke hisaab se set karta hai: binary classification ke liye sigmoid, many classes ke liye softmax, regression ke liye linear. <Cite id="class-dl-chp2" loc="slide 53" />

<Img id="class-activation-functions-significance" caption="Activation function ke bina model linear hai; iske saath model non-linear hai aur complex patterns seekhta hai." />

| Layer | Usual choice |
|---|---|
| Hidden | ReLU (neurons die hon to Leaky ReLU), tanh |
| Output, binary | Sigmoid |
| Output, many classes | Softmax |
| Output, regression | Linear |

**Conclusion:** activation functions network ko non-linear patterns seekhne ki power dete hain.
