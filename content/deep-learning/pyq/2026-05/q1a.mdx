**In simple words:** a network makes a guess and the loss says how wrong it is. Gradient descent is the step that actually fixes the weights, by moving them a little downhill on the loss again and again. <Cite id="class-dl-chp2" loc="slide 60" />

**Definition:** Gradient Descent (GD) is an optimization algorithm that updates the weights and biases to reduce the loss. <Cite id="class-dl-chp2" loc="slide 60" />

**Role in learning:**

1. **Shows the way:** the loss only tells how much error exists. The gradient (slope) tells which weight to change, in which direction and by how much. <Cite id="class-dl-chp2" loc="slide 60" />
2. **Updates the weights:** $W_{new} = W_{old} - \eta \dfrac{\partial L}{\partial W}$, where $\eta$ is the learning rate. <Cite id="class-dl-chp2" loc="slide 63" />
3. **Repeats** until the loss is minimum, so the network learns from its mistakes.
4. **Variants** (batch, SGD, mini-batch) trade speed against stability. <Cite id="class-dl-m1" loc="p. 34" />

**Conclusion:** without gradient descent the network could measure its error but could never reduce it.
