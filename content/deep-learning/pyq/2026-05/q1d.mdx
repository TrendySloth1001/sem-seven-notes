**In simple words:** an activation function decides whether a neuron fires and how strongly, and it makes the network non-linear so that it can learn complex patterns. <Cite id="class-dl-m2" loc="p. 13" />

**Importance:**

1. **Non-linearity:** without it the neuron gives only $y = z$, so the whole network is a linear model and learns only linear relationships. <Cite id="class-dl-m2" loc="p. 13" />
2. **Controls the output:** it decides the firing of a neuron and the strength of its output.
3. **Helps learning:** gradients flow through it during backpropagation; ReLU is less affected by the vanishing gradient problem. <Cite id="class-dl-chp2" loc="slide 25" />
4. **Sets the output range** for the task: sigmoid for binary classification, softmax for many classes, linear for regression. <Cite id="class-dl-chp2" loc="slide 53" />

<Img id="class-activation-functions-significance" caption="Without an activation function the model is linear; with it the model is non-linear and learns complex patterns." />

| Layer | Usual choice |
|---|---|
| Hidden | ReLU (Leaky ReLU if neurons die), tanh |
| Output, binary | Sigmoid |
| Output, many classes | Softmax |
| Output, regression | Linear |

**Conclusion:** activation functions give the network its power to learn non-linear patterns.
