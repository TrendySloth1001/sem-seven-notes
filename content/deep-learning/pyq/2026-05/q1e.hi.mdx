**In simple words:** MSE dekhta hai ki har prediction true value se kitni door hai, us gap ko square karta hai taaki bade mistakes zyada count hon, aur phir average leta hai. <Cite id="class-dl-chp2" loc="slide 32" />

**Definition:** MSE ek regression loss function hai jo predicted value aur actual value ke squared differences ka average naapta hai. $\text{MSE} = \dfrac{1}{n}\sum_{i=1}^{n} (y_i - \hat y_i)^2$, jahan $y_i$ actual value, $\hat y_i$ prediction aur $n$ samples ki sankhya hai. <Cite id="class-dl-chp2" loc="slide 32" />

**Square kyun:** 2 g aur 20 g ke errors ke squared errors 4 aur 400 hote hain, isliye bade error ko bahut zyada penalty milti hai aur network usse jaldi kam karta hai. Square karne se sign bhi hat jaata hai, to positive aur negative errors ek doosre ko cancel nahi karte. <Cite id="class-dl-chp2" loc="slide 32" />

<Sum>

<Given>

actual values 180, 200, 160, 150 aur predicted values 185, 195, 170, 145.

</Given>

<Find>

MSE.

</Find>

<Steps>

1. Errors (actual minus predicted): $-5$, $5$, $-10$, $5$.
2. Har ek ko square karo: $25$, $25$, $100$, $25$.
3. Jodo: $25 + 25 + 100 + 25 = 175$.
4. $n = 4$ se divide karo: $175/4 = 43.75$. *Reason: MSE average squared error hai.*

</Steps>

<Answer>

MSE $= 43.75$ <Cite id="class-dl-chp2" loc="slide 33" />

</Answer>

<Box kind="verify">

Error $-10$ total $175$ mein se $100$ deta hai, yaani aadhe se zyada, jabki wo chaar samples mein se sirf ek hai. Isse dikhta hai ki MSE bade errors ko kaise punish karta hai.

</Box>

</Sum>

**Note:** MSE outliers ke liye sensitive hai, aur linear output layer wale regression ke liye suitable hai; classification ke liye cross entropy use hoti hai. <Cite id="class-dl-chp2" loc="slide 31" />
