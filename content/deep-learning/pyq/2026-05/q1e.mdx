**In simple words:** MSE finds how far each prediction is from the true value, squares that gap so big mistakes count much more, and then takes the average. <Cite id="class-dl-chp2" loc="slide 32" />

**Definition:** MSE is a regression loss function that measures the average of the squared differences between the predicted value and the actual value. $\text{MSE} = \dfrac{1}{n}\sum_{i=1}^{n} (y_i - \hat y_i)^2$, where $y_i$ is the actual value, $\hat y_i$ the prediction and $n$ the number of samples. <Cite id="class-dl-chp2" loc="slide 32" />

**Why squared:** errors of 2 g and 20 g give squared errors 4 and 400, so the large error gets a much higher penalty and the network reduces it quickly. Squaring also removes the sign, so positive and negative errors cannot cancel. <Cite id="class-dl-chp2" loc="slide 32" />

<Sum>

<Given>

actual values 180, 200, 160, 150 and predicted values 185, 195, 170, 145.

</Given>

<Find>

the MSE.

</Find>

<Steps>

1. Errors (actual minus predicted): $-5$, $5$, $-10$, $5$.
2. Square each: $25$, $25$, $100$, $25$.
3. Add: $25 + 25 + 100 + 25 = 175$.
4. Divide by $n = 4$: $175/4 = 43.75$. *Reason: MSE is the average squared error.*

</Steps>

<Answer>

MSE $= 43.75$ <Cite id="class-dl-chp2" loc="slide 33" />

</Answer>

<Box kind="verify">

The error $-10$ gives $100$ of the total $175$, more than half, though it is only one of four samples. This shows how MSE punishes large errors.

</Box>

</Sum>

**Note:** MSE is sensitive to outliers, and it suits regression with a linear output layer; for classification cross entropy is used. <Cite id="class-dl-chp2" loc="slide 31" />
