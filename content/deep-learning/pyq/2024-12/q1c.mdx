**In simple words:** dropout means that during training we randomly switch off some neurons in each step, so the network cannot depend too much on any single neuron. <Cite id="srivastava2014" />

**Why it is needed.** Big networks overfit: neurons rely on each other and memorize the training data instead of learning general patterns.

**How it works**

1. Choose a drop rate for the hidden layers, for example 0.5 (switch off about half the neurons).
2. In every training step, pick a fresh random set of neurons and switch them off.
3. Train the thinned network on that batch. The next batch drops a different set.
4. At test time keep all neurons, with their outputs scaled so the signal matches training. <Cite id="gfdl-ch7" />

**Advantages**

- Reduces overfitting with very little extra cost.
- Works like averaging many smaller networks (an ensemble).
- Forces each neuron to learn useful features on its own.

**Limitation:** training is slower, and the drop rate must be tuned.

**Application:** fully connected layers of image classifiers such as AlexNet. <Cite id="gfg-dropout" />

**Conclusion.** Dropout is a cheap way to make a network generalize better.
