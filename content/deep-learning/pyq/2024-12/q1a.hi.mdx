**In simple words:** representation power matlab network kitne alag-alag functions ko represent karna seekh sakta hai. MLPs mein ye bahut hoti hai, kyunki ye universal function approximators hain. <Cite id="class-dl-m1" loc="p. 16" />

**Universal approximation theorem:** a feedforward network with a linear output layer and at least one hidden layer with any activation function (such as the logistic sigmoid) can approximate any measurable function from one finite-dimensional space to another with any desired non-zero amount of error, provided that the network is given enough hidden units. <Cite id="class-dl-m1" loc="p. 24" />

**Comments:**

1. **Linear vs non-linear:** hidden layer ke bina model linear hai aur sirf seedhi line kheenchta hai. Hidden layer weighted sums par activation functions lagakar non-linear, curved boundary deti hai. <Cite id="class-dl-chp1" loc="slide 30" />
2. **Depth:** ek single hidden layer kisi bhi function ko represent karne ke liye kaafi hai, lekin wo infeasibly badi ho sakti hai aur seekh ya generalize na kar paaye. Deeper models ko bahut kam units chahiye ho sakte hain aur ye aksar generalization error kam karte hain. <Cite id="class-dl-m1" loc="p. 24" />
3. **Factors:** hidden layers ki sankhya, neurons ki sankhya, non-linear activation function, aur depth vs width. <Cite id="class-dl-m1" loc="p. 16" />
4. **Hierarchical features:** har hidden layer higher-level features seekhti hai (edges, phir shapes, phir objects). <Cite id="class-dl-chp1" loc="slide 30" />

**Conclusion:** MLPs universal function approximators hain; depth unhe complex functions ko efficiently represent karne layak banati hai.
