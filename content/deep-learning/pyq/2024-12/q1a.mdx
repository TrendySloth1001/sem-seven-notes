**In simple words:** representation power asks which functions a network can express at all, if we find its best weights. One perceptron is very limited. An MLP with hidden layers can express almost any function.

**Why one perceptron fails.** It draws one straight line, so it handles only linearly separable problems such as AND, OR and NOT. It cannot do XOR. <Cite id="minsky-papert-1969" />

**How hidden layers help.** Each hidden neuron draws its own line, and the output combines them. XOR needs two hidden neurons: one computes OR, one computes AND, and the output fires for "OR but not AND".

**Universal approximation.** With one hidden layer of sigmoid-type neurons and a linear output, an MLP can approximate any continuous function on a bounded region as closely as we like, given enough neurons. <Cite id="hornik1989" /> <Cite id="gfdl-ch6" /> <Cite id="gfg-uat" />

**Limits.** The theorem does not say how many neurons are needed (it may be huge), or that training will find the weights. For the same number of neurons, deep networks can cut the input into far more linear pieces than one wide layer. <Cite id="montufar2014" />

**Conclusion.** MLPs are universal in theory; in practice we use deep, moderately wide networks.
