**In simple words:** representation power is how many different functions a network can learn to represent. MLPs have a lot of it, because they are universal function approximators. <Cite id="class-dl-m1" loc="p. 16" />

**Universal approximation theorem:** a feedforward network with a linear output layer and at least one hidden layer with any activation function (such as the logistic sigmoid) can approximate any measurable function from one finite-dimensional space to another with any desired non-zero amount of error, provided that the network is given enough hidden units. <Cite id="class-dl-m1" loc="p. 24" />

<Img id="class-perceptron-mlp-rep-more-layers" caption="More hidden layers give more complex decision boundaries and so more representation power." />

**Comments:**

1. **Linear versus non-linear:** without a hidden layer the model is linear and draws only a straight line. The hidden layer applies activation functions to weighted sums and gives a non-linear, curved boundary. <Cite id="class-dl-chp1" loc="slide 30" />
2. **Depth:** a single hidden layer is sufficient to represent any function, but it may be infeasibly large and may fail to learn and generalize. Deeper models can need far fewer units and often reduce generalization error. <Cite id="class-dl-m1" loc="p. 24" />
3. **Factors:** number of hidden layers, number of neurons, a non-linear activation function, and depth versus width. <Cite id="class-dl-m1" loc="p. 16" />
4. **Hierarchical features:** each hidden layer learns higher-level features (edges, then shapes, then objects). <Cite id="class-dl-chp1" loc="slide 30" />

**Conclusion:** MLPs are universal function approximators; depth makes them efficient at representing complex functions.
