**In simple words:** a CNN is a deep learning model that learns features from images with sliding filters. Convolution and pooling layers find the features; flatten and fully connected layers decide the class.

**Definition:** a CNN is a type of deep neural network specially designed to work with images and other grid-like data. <Cite id="class-dl-chp4" loc="slide 5" />

**Why needed:** a fully connected network gives too many parameters (28×28 pixels with 100 neurons need 78,400 weights) and loses spatial information. A CNN uses local connectivity, weight sharing and pooling. <Cite id="class-dl-chp4" loc="slide 5" />

**Layers** <Cite id="class-dl-chp4" loc="slide 28" />

1. **Convolution + ReLU:** filters slide over the input, multiply and add, giving one feature map per filter. Output size $\lfloor (N - F + 2P)/S \rfloor + 1$, depth = number of filters.
2. **Pooling:** reduces height and width, not depth.
3. **Flatten + fully connected + softmax:** features become a vector and are turned into class probabilities.

**Parameters of a convolution layer** $= (F \times F \times D + 1) \times K$. <Cite id="class-dl-chp4" loc="slide 27" />

<Img id="class-cnn-architectures-sum-ten-filters" caption="The class drawing of this very sum: 32×32×3 input, 10 filters of 5×5×3, stride 1, padding 2, output 32×32×10, 76 parameters per filter, 760 in all." />

<Sum>

<Given>

input volume 32×32×3, ten 5×5 filters, stride 1, padding 2.

</Given>

<Find>

the number of parameters (and the output size).

</Find>

<Steps>

1. **Each filter is 5×5×3,** because its depth must equal the input depth (3).
2. **Weights per filter:** $5 \times 5 \times 3 = 75$.
3. **Add one bias per filter:** $75 + 1 = 76$.
4. **All ten filters:** $76 \times 10 = 760$.
5. **Output size:** $(32 - 5 + 2 \cdot 2)/1 + 1 = 32$, depth 10, so 32×32×10. Stride and padding do not change the parameter count.

</Steps>

<Answer>

760 parameters (output 32×32×10).

</Answer>

<Box kind="verify">

Formula: $(5 \cdot 5 \cdot 3 + 1) \times 10 = 76 \times 10 = 760$. Padding 2 with a 5×5 filter is "same" padding ($P = (F-1)/2 = 2$), so 32×32 stays 32×32.

</Box>

</Sum>

**Conclusion:** a CNN learns features with shared filters, so this layer needs only 760 parameters however big the image is.
