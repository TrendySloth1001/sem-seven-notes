**In simple words:** a convolutional neural network (CNN) looks at an image one small patch at a time. Small learned filters slide over the image to find patterns such as edges, pooling shrinks the result, and fully connected layers make the final decision.

**Why it is needed.** A fully connected layer on even a 32×32×3 image needs 3072 weights per neuron, ignores which pixels are neighbours and must relearn a pattern at every position. A CNN fixes all three.

**Architecture, layer by layer**

1. **Input layer:** the image as height × width × channels, for example $32 \times 32 \times 3$.
2. **Convolutional layer:** filters slide over the input with a chosen stride and padding. At each position a filter multiplies and adds over all input channels, giving one number; one filter gives one feature map. The same filter is reused everywhere (**weight sharing**) and each output sees only a small patch (**local connectivity**).
3. **ReLU:** turns negative values into 0, adding non-linearity.
4. **Pooling layer:** max or average of small blocks (usually 2×2, stride 2); halves height and width, keeps channels, has no parameters.
5. **Repeat** conv → ReLU → pool: early layers find edges, deeper layers find shapes and object parts.
6. **Flatten and fully connected layers**, then a **softmax output layer** with one probability per class.

**Advantages:** few parameters, learns its own features, finds a pattern anywhere in the image. **Limitation:** needs much labelled data and GPU time. <Cite id="gfdl-ch9" /> <Cite id="gfg-cnn" />

**Numerical: parameters in this convolutional layer.**

Given: input $32 \times 32 \times 3$, ten $5 \times 5$ filters, stride $S = 1$, padding $P = 2$.

To find: the number of parameters in this layer.

1. **Weights in one filter:** $5 \times 5 \times 3 = 75$, because each filter spans all 3 input channels.
2. **Add one bias:** $75 + 1 = 76$.
3. **Multiply by the ten filters:** $76 \times 10 = 760$. The same numbers are reused at all positions, so positions add no parameters.
4. **Output size:** $(32 - 5 + 2 \times 2)/1 + 1 = 32$, so the output is $32 \times 32 \times 10$. Padding keeps the size and adds no parameters.

**Answer: 760 parameters** (750 weights + 10 biases).

<Box kind="verify">

Count another way: 10 filters × 75 weights = 750, plus 10 biases = 760. For scale, a fully connected layer with the same 32×32×10 output needs $3072 \times 10240 = 31{,}457{,}280$ weights (about 31.5 million), so weight sharing saves a huge number.

</Box>

**Conclusion:** local connections and weight sharing let a CNN learn image features with very few parameters (here only 760).
