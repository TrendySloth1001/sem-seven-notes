**In simple words:** PageRank, by Larry Page and Sergey Brin, gives every web page a score for how important it is. A page is important if important pages link to it. <Cite id="hadoop-ecosystem-mmds" loc="§5.1" /> <Cite id="web-bda-2-wiki-pagerank" />

1. **Links are votes.** A link from page A to page B is a vote for B, and a vote from an important page counts more.
2. **Random surfer.** Imagine a surfer who keeps clicking a random out-link. The fraction of time spent on a page is its PageRank.
3. **Rank flows through links.** A page with $n_j$ out-links gives $1/n_j$ of its rank to each page it links to.
4. **Formula.** $r_i = \sum_{j \to i} \dfrac{r_j}{n_j}$, or in matrix form $r = Mr$, where $M_{ij} = 1/n_j$ if page $j$ links to $i$. Start with $r = (1/n, \dots, 1/n)$ and repeat until it stops changing. With teleporting: $r = \beta Mr + (1-\beta)e/n$, $\beta \approx 0.85$. <Cite id="pagerank-cs246-pagerank" />
   **Example:** links are A to B, C, D; B to A, D; C to A; D to B, C. Start at $1/4$ each. Then $r_A = r_B/2 + r_C = 1/8 + 1/4 = 3/8$ after one step. <Cite id="mapreduce-algorithms-gfg-pagerank" loc="diagram" />

<Img id="img-bda-n3-pagerank-surfer" caption="A random surfer on a small web: pages that many pages link to are visited more often and get a higher rank." />

**Main purpose:** to rank web pages by importance, independent of the query, so that search results list the more important pages first. Links are hard to fake, so it resists spam that fools word-matching alone. <Cite id="web-bda-2-mmds-linkanalysis" loc="slides 41-47" />

**Extend in the exam (add these if the question carries more marks):**

- **Dead ends.** A page with no out-links leaks its rank, so all ranks slowly drain to zero. <Cite id="pagerank-cs246-pagerank" />
- **Spider traps.** A group of pages that link only to each other keeps all the rank inside the group. <Cite id="pagerank-cs246-pagerank" />
- **Fix: teleporting.** With probability $1-\beta$ the surfer jumps to a random page, so no page is a trap and the scores always settle. <Cite id="pagerank-cs246-pagerank" />
- **At web scale.** The matrix is huge and sparse, so PageRank is computed with MapReduce, one multiplication round after another. <Cite id="mapreduce-algorithms-gfg-pagerank" />

**Conclusion:** PageRank scores a page by the importance of the pages linking to it, and its purpose is to order web pages for search.
