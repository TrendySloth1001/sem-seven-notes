**In simple words:** Flajolet-Martin estimates the number of distinct elements in a stream. Hash every element, count the zeros at the right end of the hash (trailing zeros), keep the largest count $R$, and estimate $2^R$. <Cite id="stream-counting-fm1985" /> <Cite id="stream-counting-wiki-fm" />

<Sum>

<Given>

Stream 1, 2, 5, 4, 3, 2, 2, 8. Hash $h(x) = (3x+1) \bmod 32$, written as a 5-bit binary number.

</Given>

<Find>

the hash values, 5-bit binary, trailing zeros, $R$ and the estimate $D = 2^R$.

</Find>

<Steps>

1. **Hash each element and write it in 5 bits.** *Reason: the algorithm works on the hash, not the raw element.*

   | $x$ | $3x+1$ | $h(x)$ | 5-bit binary | Trailing zeros |
   |---|---|---|---|---|
   | 1 | 4 | 4 | 00100 | 2 |
   | 2 | 7 | 7 | 00111 | 0 |
   | 5 | 16 | 16 | 10000 | 4 |
   | 4 | 13 | 13 | 01101 | 0 |
   | 3 | 10 | 10 | 01010 | 1 |
   | 2 | 7 | 7 | 00111 | 0 |
   | 2 | 7 | 7 | 00111 | 0 |
   | 8 | 25 | 25 | 11001 | 0 |

2. **Maximum trailing zeros.** $R = \max(2, 0, 4, 0, 1, 0, 0, 0) = 4$, from $x = 5$ (hash 10000). *Reason: repeats of 2 give the same hash, so they never change $R$.*
3. **Estimate.** $D = 2^R = 2^4 = 16$.

</Steps>

<Answer>

$R = 4$, so the estimated number of distinct elements is $D = 2^4 = 16$.

</Answer>

<Box kind="verify">

The true distinct elements are 1, 2, 3, 4, 5, 8, which is 6, so 16 is a rough estimate. With one hash function, a single value (here 16 = 10000 with four trailing zeros) can push $R$ up and make the estimate overshoot. Real use takes many hash functions, averages inside groups and then takes the median. <Cite id="stream-counting-mmds-home" loc="§4.4" />

</Box>

</Sum>

**Extend in the exam (add these to reach 10 marks):**

- **Why it works.** About 1 hash in $2^r$ ends with at least $r$ zeros, so a longest tail $R$ suggests about $2^R$ distinct elements. <Cite id="stream-counting-gfg-fm" />
- **Memory.** Only $R$ is stored, one small number, however long the stream is.
- **Limitation.** One hash function is unreliable, as the 16 against a true 6 shows.
- **Improvement.** Use many hash functions, average within groups, then take the median of the groups.
- **Applications.** Counting distinct visitors, distinct queries or distinct IP addresses.

**Conclusion:** the hashes are 4, 7, 16, 13, 10, 7, 7, 25, $R = 4$ and the estimate is $D = 16$, rough because only one hash is used.
