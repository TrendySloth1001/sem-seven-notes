**In simple words:** data frame R mein ek table hai. Rows do tareeke se chun sakte hain: `subset()` function (condition mein seedhe column ke naam) aur `[ rows, columns ]` brackets (condition mein `df$column`, aur column wala hissa khali chhodo to saare columns aate hain). <Cite id="pyq-2024-05-ce-r-subset" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Pehle data frame banao**

```r
df <- data.frame(subject = 1:6,
                 class   = c(1, 2, 1, 2, 1, 2),
                 marks   = c(56, 75, 48, 69, 84, 53))
```

**i. `subset()` se subject 4 se chhota**

```r
subset(df, subject < 4)
```

Output (rows 1 se 3 rehte hain, kyunki unka subject 1, 2, 3 hai):

```
  subject class marks
1       1     1    56
2       2     2    75
3       3     1    48
```

**ii. `[ ]` se subject 3 se chhota aur class 2**

```r
df[df$subject < 3 & df$class == 2, ]
```

*Kaise kaam karta hai:* `df$subject < 3` rows 1 aur 2 ke liye TRUE; `df$class == 2` rows 2, 4, 6 ke liye TRUE; `&` wahi rows rakhta hai jahan dono TRUE, yaani sirf row 2. Comma ke baad khali jagah saare columns rakhti hai.

Output:

```
  subject class marks
2       2     2    75
```

**Check:** subject 3 se chhota wali rows 1 (class 1) aur 2 (class 2) hain, to sirf row 2 ki class 2 hai. <Cite id="pyq-2025-05-ce-w3-r-df" />

**Conclusion:** `subset()` padhne mein aasaan hai; `[ ]` har object pe chalta hai aur `df$` prefix maangta hai.

Exam mein English mein likho: `subset(df, subject < 4)` aur `df[df$subject < 3 & df$class == 2, ]`.
