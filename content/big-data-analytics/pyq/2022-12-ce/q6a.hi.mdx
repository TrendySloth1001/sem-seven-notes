**In simple words:** `sort()` vector ki values ko order mein lagata hai, aur R mein subsets chunne ke liye kuch operators hain (`[ ]`, `[[ ]]`, `$`) aur comparison aur logical operators. <Cite id="pyq-2024-12-ce-r-sort" /> <Cite id="pyq-2025-05-ce-w3-r-vectors" />

**i. Vector sort karna**

```r
x <- c(23, 45, 10, 34, 89, 20, 67, 99)
sort(x)                       # ascending (default)
sort(x, decreasing = TRUE)    # descending
```

Output:

```
[1] 10 20 23 34 45 67 89 99
[1] 99 89 67 45 34 23 20 10
```

Check: dono lines mein wahi 8 values hain, aur doosri pehli ka ulta hai. (`order(x)` values ki jagah positions deta hai.)

**ii. Data subsets banane wale operators**

| Operator | Matlab | Example `x` ya data frame `df` pe | Result |
|---|---|---|---|
| `[ ]` | position, negative position ya logical test se chunna | `x[c(1, 3)]`, `x[-1]`, `x[x > 30]` | 23 10; pehle ke alawa sab; 45 34 89 67 99 |
| `[ , ]` | table ki rows aur columns | `df[2, ]`, `df[ , "marks"]` | row 2; marks column |
| `[[ ]]` | list ya column se ek element nikalna | `df[["marks"]]` | marks vector |
| `$` | naam se column ya list item | `df$marks` | marks vector |
| Comparison `<  >  ==  !=  <=  >=` | TRUE/FALSE test banata hai | `x > 30` | F T F T T F T T |
| Logical `&  \|  !` | tests jodna (and, or, not) | `x[x > 30 & x < 90]` | 45 34 89 67 |
| `subset()` | condition se rows filter karne wala function | `subset(df, marks > 60)` | marks 60 se upar wali rows |

*Reason:* logical test har element ke liye TRUE/FALSE deta hai, aur `[ ]` sirf TRUE wale rakhta hai. <Cite id="pyq-2024-05-ce-r-subset" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Conclusion:** `sort()` values ko order karta hai, aur bracket, `$` aur logical operators data ka chahe hua hissa chunte hain.

Exam mein English mein likho: "sort(x) for ascending and sort(x, decreasing = TRUE) for descending."
