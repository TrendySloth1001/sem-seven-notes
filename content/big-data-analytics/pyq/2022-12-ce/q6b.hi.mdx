**In simple words:** ye **content-based recommendation** hai. System har product ko uski properties (features) se describe karta hai, user ne jo pasand kiya uska profile banata hai, aur aise products recommend karta hai jinki properties us profile ke sabse paas hon. <Cite id="recommendation-systems-mmds-book" loc="Ch. 9" /> <Cite id="recommendation-systems-gfg-cb" />

**Steps**

1. **Item profile:** har product ke features likho, jaise movie ka genre, director, actors; text ke liye important words (tf-idf).
2. **User profile:** user ne jo products pasand kiye ya high rate kiye unke profiles ko combine (average) karo.
3. **Match:** user profile aur har unseen product ke beech similarity (aam taur pe cosine) nikalo.
4. **Recommend:** sabse high score wale products dikhao. <Cite id="recommendation-systems-google-cb" />

<Sum>

<Given>

Features (Action, Sci-fi, Romance) 1 = hai, 0 = nahi. Liked: M1 = (1, 1, 0), M2 = (1, 0, 0). Unseen: M3 = (0, 0, 1), M4 = (1, 1, 1), M5 = (0, 1, 0).

</Given>

<Find>

pehle kaun si unseen movie recommend karni hai.

</Find>

<Steps>

1. **User profile** = M1 aur M2 ka average $= ((1+1)/2, (1+0)/2, (0+0)/2) = (1, 0.5, 0)$. *Reason: user ko Action poora pasand hai aur Sci-fi aadha.* Length $\sqrt{1 + 0.25 + 0} = 1.118$.
2. **M3:** dot product $= 1\cdot0 + 0.5\cdot0 + 0\cdot1 = 0$, to cosine $= 0$.
3. **M4:** dot $= 1 + 0.5 + 0 = 1.5$; M4 ki length $= \sqrt3 = 1.732$; cosine $= 1.5 / (1.118 \times 1.732) = 1.5 / 1.936 = 0.775$.
4. **M5:** dot $= 0.5$; length 1; cosine $= 0.5 / 1.118 = 0.447$.
5. Cosine se rank: M4, M5, M3.

</Steps>

<Answer>

M4 recommend karo (0.775), phir M5 (0.447); M3 (0) recommend nahi.

</Answer>

<Box kind="verify">

Common sense bhi yahi kehta hai: M4 mein Action aur Sci-fi dono hain jo pasand hain; M5 mein sirf Sci-fi; M3 pure Romance hai jisme user ne kabhi interest nahi dikhaya. Aur $\sqrt{1.25} \times \sqrt{3} = \sqrt{3.75} = 1.936$.

</Box>

</Sum>

**Advantages:** doosre users ki zaroorat nahi, naye ya niche items ke liye chalta hai, batata hai item kyun recommend hua. **Disadvantages:** acche features chahiye, sirf milti-julti cheezein recommend karta hai (surprise nahi), naye users ke liye cold start. **Real example:** Pandora ka Music Genome Project songs ko properties se describe karta hai. <Cite id="recommendation-systems-wiki-recsys" />

**Conclusion:** content-based filtering aise products recommend karta hai jinki properties user ki pasand se match karti hain.

Exam mein English mein likho: "Content-based filtering recommends items similar in properties to those the user liked."
