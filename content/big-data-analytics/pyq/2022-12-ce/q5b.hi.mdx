**In simple words:** R mein `c()` values ko vector mein jodta hai, `data.frame()` vectors se table banata hai, aur `rbind()` table mein aur rows jodta hai. <Cite id="pyq-2025-05-ce-w3-r-vectors" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**i. 10 salaries enter karna**

```r
emp <- data.frame(
  SrNo   = 1:10,
  Name   = c("Vivek", "Karan", "James", "Soham", "Renu",
             "Farah", "Hetal", "Mary", "Ganesh", "Krish"),
  Salary = c(21000, 55000, 67000, 50000, 54000,
             40000, 30000, 70000, 20000, 15000)
)
emp
```

Output:

```
   SrNo   Name Salary
1     1  Vivek  21000
2     2  Karan  55000
3     3  James  67000
4     4  Soham  50000
5     5   Renu  54000
6     6  Farah  40000
7     7  Hetal  30000
8     8   Mary  70000
9     9 Ganesh  20000
10   10  Krish  15000
```

(Sirf salaries chahiye to `sal <- c(21000, 55000, 67000, 50000, 54000, 40000, 30000, 70000, 20000, 15000)` kaafi hai.)

**ii. 5 naye employees jodna.** Question mein data nahi diya, isliye (any suitable data) ye naye employees maante hain. `rbind()` rows stack karta hai, aur column names match hone chahiye.

```r
new <- data.frame(
  SrNo   = 11:15,
  Name   = c("Anita", "Rahul", "Sneha", "Imran", "Pooja"),
  Salary = c(45000, 38000, 62000, 27000, 33000)
)
emp <- rbind(emp, new)
emp
```

Output (pehli 10 rows same, phir):

```
   SrNo   Name Salary
11   11  Anita  45000
12   12  Rahul  38000
13   13  Sneha  62000
14   14  Imran  27000
15   15  Pooja  33000
```

`nrow(emp)` ab `[1] 15` deta hai. <Cite id="pyq-2024-05-ce-r-cbind" />

**Note:** `rbind()` rows jodta hai (same columns); `cbind()` columns jodta hai; `merge()` common column pe do tables join karta hai. Simple vector ke liye `c(sal, new_sal)` values append karta hai.

**Conclusion:** `data.frame()` table banata hai aur `rbind()` naye records usme jodta hai.

Exam mein English mein likho: "rbind() is used to join new rows to an existing data frame."
