**In simple words:** `sort()` puts vector values in order, and R has a few operators (`[ ]`, `[[ ]]`, `$`) plus comparison and logical operators to pick subsets. <Cite id="pyq-2024-12-ce-r-sort" /> <Cite id="pyq-2025-05-ce-w3-r-vectors" />

**i. Sorting the vector**

```r
x <- c(23, 45, 10, 34, 89, 20, 67, 99)
sort(x)                       # ascending (default)
sort(x, decreasing = TRUE)    # descending
```

Output:

```
[1] 10 20 23 34 45 67 89 99
[1] 99 89 67 45 34 23 20 10
```

Check: the 8 values are the same in both lines, and the second is the first reversed. (`order(x)` gives the positions instead of the values.)

**ii. Operators used to form data subsets**

| Operator | Meaning | Example on `x` or a data frame `df` | Result |
|---|---|---|---|
| `[ ]` | pick by position, negative position or logical test | `x[c(1, 3)]`, `x[-1]`, `x[x > 30]` | 23 10; all but first; 45 34 89 67 99 |
| `[ , ]` | rows and columns of a table | `df[2, ]`, `df[ , "marks"]` | row 2; the marks column |
| `[[ ]]` | pick one element out of a list or column | `df[["marks"]]` | the marks vector |
| `$` | pick a column or list item by name | `df$marks` | the marks vector |
| Comparison `<  >  ==  !=  <=  >=` | build a TRUE/FALSE test | `x > 30` | F T F T T F T T |
| Logical `&  \|  !` | combine tests (and, or, not) | `x[x > 30 & x < 90]` | 45 34 89 67 |
| `subset()` | function that filters rows by a condition | `subset(df, marks > 60)` | rows with marks above 60 |

*Reason:* a logical test gives TRUE/FALSE for every element, and `[ ]` keeps only the TRUE ones. <Cite id="pyq-2024-05-ce-r-subset" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Conclusion:** `sort()` orders values, and the bracket, `$` and logical operators select the part of the data you want.
