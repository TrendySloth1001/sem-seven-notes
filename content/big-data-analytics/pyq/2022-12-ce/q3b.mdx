**In simple words:** a data frame is a table in R. We can pick rows in two ways: the `subset()` function (write the condition with plain column names) and the `[ rows, columns ]` brackets (write the condition with `df$column` and leave the column part empty to keep all columns). <Cite id="pyq-2024-05-ce-r-subset" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**First create the data frame**

```r
df <- data.frame(subject = 1:6,
                 class   = c(1, 2, 1, 2, 1, 2),
                 marks   = c(56, 75, 48, 69, 84, 53))
```

**i. Subset of subject less than 4 using `subset()`**

```r
subset(df, subject < 4)
```

Output (rows 1 to 3 keep, because their subject is 1, 2, 3):

```
  subject class marks
1       1     1    56
2       2     2    75
3       3     1    48
```

**ii. subject less than 3 and class equal to 2 using `[ ]`**

```r
df[df$subject < 3 & df$class == 2, ]
```

*How it works:* `df$subject < 3` is TRUE for rows 1 and 2; `df$class == 2` is TRUE for rows 2, 4, 6; `&` keeps rows where both are TRUE, which is row 2 only. The comma with nothing after it keeps all columns.

Output:

```
  subject class marks
2       2     2    75
```

**Check:** rows with subject below 3 are 1 (class 1) and 2 (class 2), so only row 2 has class 2. <Cite id="pyq-2025-05-ce-w3-r-df" />

**Conclusion:** `subset()` is easier to read; `[ ]` works on any object and needs the `df$` prefix.
