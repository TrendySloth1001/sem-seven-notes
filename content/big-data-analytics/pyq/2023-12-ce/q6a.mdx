**In simple words:** a **script** is a file of R commands that runs from top to bottom. A **function** is a named block of code that takes inputs (arguments), does a job and returns a result. This topic is not in the CSE (AI&ML) syllabus, but the paper asks it. <Cite id="pyq-2023-12-ce-w3-r-functions" /> <Cite id="pyq-2023-12-ce-gfg-r-functions" />

**Part (i): advantages of functions over scripts**

1. **Reuse.** Write once, call many times with different inputs. A script must be copied or edited for each new input.
2. **Inputs and output.** A function takes arguments and returns a value that other code can use. A script just runs and leaves its results lying around.
3. **Local variables.** Variables inside a function disappear when it ends, so they do not clutter or overwrite the workspace. A script changes the global workspace.
4. **Easier testing and debugging.** A small function can be tested alone with known inputs.
5. **Shorter, clearer code.** A good name such as `area(r)` tells what the code does, and a fix in one place fixes every use.

```r
area <- function(r) {
  pi * r^2
}
area(2)      # [1] 12.56637
area(3)      # [1] 28.27433
```

| Point | Script | Function |
|---|---|---|
| Input | Edited by hand in the file | Passed as arguments |
| Output | Left in the workspace | Returned value |
| Variables | Global | Local |
| Reuse | Copy and edit | Call by name |

**Part (ii): combining two datasets.** For two vectors the function is **`c()`** (combine). It joins the values one after the other. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

```r
A <- c(6, 7, 8, 9)
B <- c(1, 2, 4, 5)
C <- c(A, B)
print(C)
```

Output:

```
[1] 6 7 8 9 1 2 4 5
```

To keep A and B as separate columns or rows, use `cbind(A, B)` or `rbind(A, B)` instead. They need the same length (4 here). <Cite id="pyq-2024-12-ce-r-cbind" />

```
> cbind(A, B)          > rbind(A, B)
     A B                 [,1] [,2] [,3] [,4]
[1,] 6 1               A    6    7    8    9
[2,] 7 2               B    1    2    4    5
[3,] 8 4
[4,] 9 5
```

**Check:** A has 4 values and B has 4, so C must have $4 + 4 = 8$ values, and `length(C)` gives 8. The first four are A and the last four are B, in the original order.

**Conclusion:** functions give reusable, testable code with their own local variables, and `c(A, B)` combines the datasets into $C = (6, 7, 8, 9, 1, 2, 4, 5)$.
