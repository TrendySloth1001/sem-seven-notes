**In simple words:** R mein **data frame** ek table hai. Har column ek vector hai (ek column mein ek hi type), aur alag columns ke type alag ho sakte hain. Hum vectors se `data.frame()` se banate hain, `str()` aur `summary()` se dekhte hain, columns naam se chunte hain, aur rows condition se chunte hain. <Cite id="pyq-2025-05-ce-w3-r-df" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Part (i): data frame banao aur dikhao.**

```r
emp_id     <- c(1:5)
emp_name   <- c("Rick", "Dan", "Michelle", "Ryan", "Gary")
start_date <- c("2012-01-01", "2013-09-23", "2014-11-15",
                "2014-05-11", "2015-03-27")
salary     <- c(60000, 45000, 75000, 84000, 20000)

emp_data <- data.frame(emp_id, emp_name, start_date, salary)
print(emp_data)
```

Output:

```
  emp_id emp_name start_date salary
1      1     Rick 2012-01-01  60000
2      2      Dan 2013-09-23  45000
3      3 Michelle 2014-11-15  75000
4      4     Ryan 2014-05-11  84000
5      5     Gary 2015-03-27  20000
```

**Part (ii): structure aur summary.** `str()` har column ka type dikhata hai. `summary()` numeric columns ka minimum, quartiles, median, mean aur maximum deta hai, aur text columns ki length aur class. <Cite id="pyq-2024-12-ce-r-str" /> <Cite id="pyq-2024-12-ce-r-summary" />

```r
str(emp_data)
summary(emp_data)
```

**Part (iii): `emp_name` aur `salary` nikalo.** Row wala hissa khali chhodo aur column names do.

```r
emp_data[, c("emp_name", "salary")]
```

```
  emp_name salary
1     Rick  60000
2      Dan  45000
3 Michelle  75000
4     Ryan  84000
5     Gary  20000
```

**Part (iv): salary 60000 ya kam wale employees.** Row pe condition har row ke liye TRUE ya FALSE deti hai; sirf TRUE rows rehti hain. `subset(emp_data, salary <= 60000)` bhi wahi result deta hai. <Cite id="pyq-2024-05-ce-r-subset" />

```r
emp_data[emp_data$salary <= 60000, ]
```

```
  emp_id emp_name start_date salary
1      1     Rick 2012-01-01  60000
2      2      Dan 2013-09-23  45000
5      5     Gary 2015-03-27  20000
```

**Check:** salaries 60000, 45000, 75000, 84000, 20000 hain. $\le 60000$ wale 60000, 45000 aur 20000 hain, yani rows 1, 2 aur 5. `summary` ka mean $(60000 + 45000 + 75000 + 84000 + 20000) / 5 = 284000 / 5 = 56800$ hai. Ye topic CSE (AI&ML) syllabus mein nahi hai, lekin paper mein pucha gaya hai.
