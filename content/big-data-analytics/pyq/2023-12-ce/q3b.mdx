**In simple words:** a **data frame** in R is a table. Each column is a vector (one type per column), and different columns can have different types. We build it from vectors with `data.frame()`, inspect it with `str()` and `summary()`, pick columns by name, and pick rows with a condition. <Cite id="pyq-2025-05-ce-w3-r-df" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Part (i): create the data frame and show it.**

```r
emp_id     <- c(1:5)
emp_name   <- c("Rick", "Dan", "Michelle", "Ryan", "Gary")
start_date <- c("2012-01-01", "2013-09-23", "2014-11-15",
                "2014-05-11", "2015-03-27")
salary     <- c(60000, 45000, 75000, 84000, 20000)

emp_data <- data.frame(emp_id, emp_name, start_date, salary)
print(emp_data)
```

Output:

```
  emp_id emp_name start_date salary
1      1     Rick 2012-01-01  60000
2      2      Dan 2013-09-23  45000
3      3 Michelle 2014-11-15  75000
4      4     Ryan 2014-05-11  84000
5      5     Gary 2015-03-27  20000
```

**Part (ii): structure and summary.** `str()` shows the type of each column. `summary()` gives the minimum, quartiles, median, mean and maximum of numeric columns, and the length and class of text columns. <Cite id="pyq-2024-12-ce-r-str" /> <Cite id="pyq-2024-12-ce-r-summary" />

```r
str(emp_data)
summary(emp_data)
```

Output (the spacing of `summary` may differ slightly on your screen):

**Part (iii): extract `emp_name` and `salary`.** Leave the row part empty and give the column names.

```r
emp_data[, c("emp_name", "salary")]
```

```
  emp_name salary
1     Rick  60000
2      Dan  45000
3 Michelle  75000
4     Ryan  84000
5     Gary  20000
```

**Part (iv): employees with salary at most 60000.** A condition on rows gives TRUE or FALSE for each row; only the TRUE rows are kept. `subset(emp_data, salary <= 60000)` gives the same result. <Cite id="pyq-2024-05-ce-r-subset" />

```r
emp_data[emp_data$salary <= 60000, ]
```

```
  emp_id emp_name start_date salary
1      1     Rick 2012-01-01  60000
2      2      Dan 2013-09-23  45000
5      5     Gary 2015-03-27  20000
```

**Check:** the salaries are 60000, 45000, 75000, 84000, 20000. The ones $\le 60000$ are 60000, 45000 and 20000, which are rows 1, 2 and 5. The mean in `summary` is $(60000 + 45000 + 75000 + 84000 + 20000) / 5 = 284000 / 5 = 56800$. This topic is not in the CSE (AI&ML) syllabus, but the paper asks it.
