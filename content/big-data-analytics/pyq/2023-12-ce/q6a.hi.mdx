**In simple words:** **script** R commands ki ek file hai jo upar se neeche chalti hai. **Function** ek naam wala code block hai jo inputs (arguments) leta hai, ek kaam karta hai aur result return karta hai. Ye topic CSE (AI&ML) syllabus mein nahi hai, lekin paper mein pucha gaya hai. <Cite id="pyq-2023-12-ce-w3-r-functions" /> <Cite id="pyq-2023-12-ce-gfg-r-functions" />

**Part (i): scripts ke upar functions ke advantages**

1. **Reuse.** Ek baar likho, alag inputs ke saath kai baar call karo. Script ko har naye input ke liye copy ya edit karna padta hai.
2. **Inputs aur output.** Function arguments leta hai aur value return karta hai jo dusra code use kar sakta hai. Script bas chalti hai aur results idhar-udhar chhod deti hai.
3. **Local variables.** Function ke andar ke variables function khatam hote hi gayab ho jate hain, isliye workspace mein kachra nahi hota aur kuch overwrite nahi hota. Script global workspace badal deti hai.
4. **Testing aur debugging aasan.** Chhote function ko known inputs se alag test kar sakte hain.
5. **Chhota, saaf code.** `area(r)` jaisa achha naam batata hai code kya karta hai, aur ek jagah fix karne se har use fix ho jata hai.

```r
area <- function(r) {
  pi * r^2
}
area(2)      # [1] 12.56637
area(3)      # [1] 28.27433
```

| Point | Script | Function |
|---|---|---|
| Input | File mein haath se edit | Arguments se pass |
| Output | Workspace mein chhoda jata hai | Returned value |
| Variables | Global | Local |
| Reuse | Copy aur edit | Naam se call |

**Part (ii): do datasets ko combine karna.** Do vectors ke liye function **`c()`** (combine) hai. Ye values ko ek ke baad ek jodta hai. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

```r
A <- c(6, 7, 8, 9)
B <- c(1, 2, 4, 5)
C <- c(A, B)
print(C)
```

Output:

```
[1] 6 7 8 9 1 2 4 5
```

A aur B ko alag columns ya rows mein rakhna ho to `cbind(A, B)` ya `rbind(A, B)` use karo. Inki length same honi chahiye (yahan 4). <Cite id="pyq-2024-12-ce-r-cbind" />

```
> cbind(A, B)          > rbind(A, B)
     A B                 [,1] [,2] [,3] [,4]
[1,] 6 1               A    6    7    8    9
[2,] 7 2               B    1    2    4    5
[3,] 8 4
[4,] 9 5
```

**Check:** A mein 4 values aur B mein 4, to C mein $4 + 4 = 8$ values honi chahiye, aur `length(C)` 8 deta hai. Pehli chaar A ki aur aakhri chaar B ki hain, original order mein.

**Conclusion:** functions reusable, testable code dete hain jiske apne local variables hote hain, aur `c(A, B)` datasets ko combine karke $C = (6, 7, 8, 9, 1, 2, 4, 5)$ banata hai.

Exam mein English mein likho: "Functions are reusable, accept arguments, return values and keep variables local, whereas scripts run top to bottom in the global workspace. The c() function combines the two datasets."
