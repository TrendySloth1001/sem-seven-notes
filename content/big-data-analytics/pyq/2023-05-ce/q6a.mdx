**In simple words:** a numeric vector is a row of numbers made with `c()`. Each row of the table (one product over five days) becomes one vector. A subset operator picks some elements out of a vector, list or data frame. This question is outside the CSE (AI&ML) syllabus, but here is the answer. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

**i. Five numeric vectors** (one per product, days in order Monday to Friday):

```r
bread     <- c(12, 3, 5, 11, 9)
milk      <- c(21, 27, 18, 20, 15)
cola      <- c(10, 1, 33, 6, 12)
chocolate <- c(6, 7, 4, 13, 12)
detergent <- c(5, 8, 12, 20, 23)
```

Optionally name the days so the output is readable: `names(bread) <- c("Mon", "Tue", "Wed", "Thu", "Fri")`.

<Box kind="verify">

Check: each vector has 5 numbers, one per day, copied from its row of the table. Totals for the week: bread $12+3+5+11+9 = 40$, milk $21+27+18+20+15 = 101$, cola $10+1+33+6+12 = 62$, chocolate $6+7+4+13+12 = 42$, detergent $5+8+12+20+23 = 68$.

</Box>

**ii. Operators used to form subsets in R.** <Cite id="pyq-2023-05-ce-r-extract" />

| Operator | Meaning | Example and result |
|---|---|---|
| `[ ]` | Single bracket: picks one or more elements by position, name, or a TRUE/FALSE condition; result keeps the same type | `bread[c(1, 3)]` gives `12 5` |
| `[[ ]]` | Double bracket: picks exactly one element, and gives the element itself (used with lists) | `milk[[2]]` gives `27` |
| `$` | Picks a named element of a list or a column of a data frame | `sales$milk` (with `sales <- list(bread = bread, milk = milk)`) gives `21 27 18 20 15` |
| `-` (negative index) | Leaves out the given positions | `bread[-1]` gives `3 5 11 9` |
| Comparison `<  >  ==  !=` inside `[ ]` | Picks elements that satisfy a condition | `bread[bread > 8]` gives `12 11 9` |
| Logical `&  \|  !` | Combines conditions: AND, OR, NOT | `bread[bread > 4 & bread < 12]` gives `5 11 9` |
| `%in%` | Picks elements found in a given set | `bread[bread %in% c(3, 9)]` gives `3 9` |

The function `subset()` is also used with data frames to pick rows by a condition. <Cite id="pyq-2023-05-ce-gfg-r-subset" /> <Cite id="pyq-2023-05-ce-r-logic" />

<Box kind="verify">

Check of the examples on `bread = 12 3 5 11 9`: greater than 8 are 12, 11, 9 (3 and 5 are not). Between 4 and 12 (exclusive) are 5, 11, 9 (12 is not less than 12). Dropping the first element leaves 3 5 11 9.

</Box>

**Conclusion:** the five vectors are the five rows of the table; `[ ]`, `[[ ]]` and `$` (with conditions and negative indexes) form subsets.
