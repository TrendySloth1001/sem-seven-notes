**In simple words:** data frame R mein ek table hai. **Subset** sirf wahi rows (aur columns) rakhta hai jo tumhe chahiye. Do tareeke puche hain: square brackets `df[rows, columns]` aur `subset()` function. Ye question CSE (AI&ML) syllabus ke bahar hai, lekin answer ye hai. <Cite id="pyq-2023-05-ce-r-extract" /> <Cite id="pyq-2023-05-ce-gfg-r-subset" />

Pehle data frame banao:

```r
df <- data.frame(
  course = c(1, 2, 3, 4, 5, 6),
  id     = c(11, 12, 13, 14, 15, 16),
  class  = c(1, 2, 1, 2, 1, 2),
  marks  = c(56, 75, 48, 69, 84, 53)
)
```

**i. `[ ]` se course 3 se kam wala subset.** Brackets ke andar comma se pehla part rows chunta hai (condition jo har row ke liye TRUE ya FALSE deti hai) aur baad wala part columns chunta hai (khaali ka matlab saare columns). Comma bhoolna nahi.

```r
df[df$course < 3, ]
```

`df$course < 3` se `TRUE TRUE FALSE FALSE FALSE FALSE` milta hai, to rows 1 aur 2 rehti hain.

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
```

**ii. `subset()` se course 3 se kam YA class 2.** `subset(data, condition)` mein column names `df$` ke bina likhte hain. `|` ka matlab OR. <Cite id="pyq-2024-05-ce-r-subset" />

```r
subset(df, course < 3 | class == 2)
```

Course 3 se kam rows 1, 2 ke liye true hai. Class equal to 2 rows 2, 4, 6 ke liye true hai. Dono ka OR rows 1, 2, 4, 6 hai.

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
4      4 14     2    69
6      6 16     2    53
```

<Box kind="verify">

Check: row 3 (course 3, class 1) aur row 5 (course 5, class 1) dono conditions fail karti hain, isliye bahar. Rakhi gayi 4 rows plus bahar ki 2 rows = original 6 rows. Row names 1, 2, 4, 6 hi rehte hain kyunki R original row numbers rakhta hai.

</Box>

| Way | Syntax | Notes |
|---|---|---|
| Brackets | `df[df$course < 3, ]` | `df$` chahiye; comma mat bhoolo; NA rows aa sakti hain |
| `subset()` | `subset(df, course < 3)` | Chhota; NA rows drop karta hai; interactive use ke liye |

**Conclusion:** part i mein rows 1 aur 2; part ii mein rows 1, 2, 4 aur 6.

Exam mein English mein likho: "df[df$course < 3, ] and subset(df, course < 3 | class == 2)."
