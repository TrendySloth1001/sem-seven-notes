**In simple words:** data structure values ko ek saath rakhne ka tareeka hai. R mein chhe main hain: **vector, list, matrix, array, factor aur data frame**. Ye dimensions (1-D, 2-D, n-D) mein aur is mein alag hain ki ek hi type ka data rakhte hain (homogeneous) ya mixed types (heterogeneous). Ye question CSE (AI&ML) syllabus ke bahar hai, lekin answer ye hai. <Cite id="pyq-2023-05-ce-gfg-r-ds" />

1. **Vector.** Basic 1-D structure; saare items ka type same (numeric, character ya logical). `c()` se banta hai: `v <- c(12, 3, 5)`. Items position se padhte hain, `v[2]` se 3 milta hai. <Cite id="pyq-2025-05-ce-w3-r-vectors" />
2. **List.** 1-D collection jisme **alag-alag** types ke items ho sakte hain, vectors ya dusri lists bhi: `l <- list(name = "Asha", marks = c(56, 75), pass = TRUE)`. `l[["name"]]` ya `l$name` se padho. <Cite id="pyq-2025-05-ce-w3-r-lists" />
3. **Matrix.** **Same** type ki 2-D table, rows aur columns ke saath: `m <- matrix(1:6, nrow = 2, ncol = 3)`. `m[1, 2]` se padho. <Cite id="pyq-2025-05-ce-w3-r-matrices" />
4. **Array.** Matrix jaisa lekin **do se zyada** dimensions, same type: `a <- array(1:24, dim = c(2, 3, 4))`. <Cite id="pyq-2023-05-ce-w3-r-arrays" />
5. **Factor.** **Categorical** data (jaise "low", "medium", "high") ko named levels ke saath integer codes mein rakhta hai: `f <- factor(c("low", "high", "low"))`. Statistics aur modelling mein use hota hai. <Cite id="pyq-2025-05-ce-w3-r-factors" />
6. **Data frame.** 2-D table jisme har column ek vector hai, aur **alag columns ke types alag** ho sakte hain. Real datasets ke liye sabse zyada use hota hai, Excel sheet jaisa: `df <- data.frame(id = 1:3, name = c("A", "B", "C"))`. <Cite id="pyq-2025-05-ce-gfg-r-df" />

| Structure | Dimensions | Types inside | Typical use |
|---|---|---|---|
| Vector | 1 | Same | Numbers ka column |
| List | 1 | Mixed | Alag objects ka bundle |
| Matrix | 2 | Same | Maths aur linear algebra |
| Array | n (3 or more) | Same | Multi-way data |
| Factor | 1 | Categories | Group labels |
| Data frame | 2 | Mixed per column | Real tabular data |

**Conclusion:** vectors, matrices aur arrays ek type rakhte hain; lists aur data frames types mix kar sakte hain; factors categories store karte hain.

Exam mein English mein likho: "R has vectors, lists, matrices, arrays, factors and data frames."
