**In simple words:** a data structure is a way to hold values together. R has six main ones: **vector, list, matrix, array, factor and data frame**. They differ in their dimensions (1-D, 2-D, n-D) and in whether they hold one type of data (homogeneous) or mixed types (heterogeneous). This question is outside the CSE (AI&ML) syllabus, but here is the answer. <Cite id="pyq-2023-05-ce-gfg-r-ds" />

1. **Vector.** The basic 1-D structure; all items have the same type (numeric, character or logical). Made with `c()`: `v <- c(12, 3, 5)`. Items are read by position, `v[2]` gives 3. <Cite id="pyq-2025-05-ce-w3-r-vectors" />
2. **List.** A 1-D collection that can hold items of **different** types, even vectors or other lists: `l <- list(name = "Asha", marks = c(56, 75), pass = TRUE)`. Read with `l[["name"]]` or `l$name`. <Cite id="pyq-2025-05-ce-w3-r-lists" />
3. **Matrix.** A 2-D table of the **same** type, with rows and columns: `m <- matrix(1:6, nrow = 2, ncol = 3)`. Read with `m[1, 2]`. <Cite id="pyq-2025-05-ce-w3-r-matrices" />
4. **Array.** Like a matrix but with **more than two** dimensions, same type: `a <- array(1:24, dim = c(2, 3, 4))`. <Cite id="pyq-2023-05-ce-w3-r-arrays" />
5. **Factor.** Stores **categorical** data (such as "low", "medium", "high") as integer codes with named levels: `f <- factor(c("low", "high", "low"))`. Used in statistics and modelling. <Cite id="pyq-2025-05-ce-w3-r-factors" />
6. **Data frame.** A 2-D table where each column is a vector, and **different columns may have different types**. The most used structure for real datasets, like an Excel sheet: `df <- data.frame(id = 1:3, name = c("A", "B", "C"))`. <Cite id="pyq-2025-05-ce-gfg-r-df" />

| Structure | Dimensions | Types inside | Typical use |
|---|---|---|---|
| Vector | 1 | Same | A column of numbers |
| List | 1 | Mixed | Bundle of unlike objects |
| Matrix | 2 | Same | Maths and linear algebra |
| Array | n (3 or more) | Same | Multi-way data |
| Factor | 1 | Categories | Group labels |
| Data frame | 2 | Mixed per column | Real tabular data |

**Conclusion:** vectors, matrices and arrays hold one type; lists and data frames can mix types; factors store categories.
