**In simple words:** the Flajolet-Martin (FM) algorithm estimates the number of **distinct** elements in a stream using very little memory. Hash every element to a binary number and count its **trailing zeros** (zeros at the right end). If the largest count seen is $R$, the estimate is $2^R$. The idea: a hash with $r$ trailing zeros happens for about 1 in $2^r$ distinct items, so seeing $R$ zeros suggests about $2^R$ distinct items. <Cite id="stream-counting-fm1985" /> <Cite id="stream-counting-mmds-home" loc="§4.4" />

**Steps:** (1) hash each item to a 4-bit number, (2) write it in binary, (3) count trailing zeros, (4) keep the maximum $R$, (5) estimate $2^R$. <Cite id="stream-counting-gfg-fm" />

<Sum>

<Given>

Stream $S = \{2, 1, 6, 1, 5, 9, 2, 3, 5\}$, hash $h(x) = (4x + 1) \bmod 16$, result written as a 4-bit binary number.

</Given>

<Find>

the Flajolet-Martin estimate of the number of distinct elements.

</Find>

<Steps>

1. Compute each hash and its binary form, then count trailing zeros.

| $x$ | $4x+1$ | $\bmod 16$ | 4-bit binary | Trailing zeros |
|---|---|---|---|---|
| 2 | 9 | 9 | 1001 | 0 |
| 1 | 5 | 5 | 0101 | 0 |
| 6 | 25 | 9 | 1001 | 0 |
| 1 | 5 | 5 | 0101 | 0 |
| 5 | 21 | 5 | 0101 | 0 |
| 9 | 37 | 5 | 0101 | 0 |
| 2 | 9 | 9 | 1001 | 0 |
| 3 | 13 | 13 | 1101 | 0 |
| 5 | 21 | 5 | 0101 | 0 |

2. The maximum number of trailing zeros is $R = 0$. *Reason: every hash ends in 1.*
3. Estimate $= 2^R = 2^0 = 1$.

</Steps>

<Answer>

estimated number of distinct elements $= 2^0 = 1$.

</Answer>

<Box kind="verify">

Check 1: the true distinct elements are $\{1, 2, 3, 5, 6, 9\}$, which is 6. So the estimate 1 is far from the truth.

Check 2: why. $4x + 1$ is always odd, so the last bit is always 1 and the trailing zeros are always 0, for any input. This hash is a poor choice, so FM correctly gives 1 here. The answer to the question as asked is still 1.

Check 3: a better hash, for example $h(x) = (3x + 2) \bmod 16$, gives $8, 5, 4, 1, 13, 11$ for $x = 2, 1, 6, 5, 9, 3$. The value $8 = 1000$ has 3 trailing zeros, and $4 = 0100$ has 2, so $R = 3$ and the estimate is $2^3 = 8$, closer to 6.

</Box>

</Sum>

**Remarks:** one hash gives a rough estimate. In practice many hash functions are used and their estimates are combined (average within groups, then median) to reduce error. <Cite id="stream-counting-wiki-fm" />

**Conclusion:** with $h(x) = 4x + 1 \bmod 16$, $R = 0$ and the estimate is $2^0 = 1$ (true value 6, because this hash is poor).
