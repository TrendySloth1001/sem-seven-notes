**In simple words:** Flajolet-Martin (FM) algorithm bahut kam memory se stream mein **distinct** elements ki sankhya estimate karta hai. Har element ko binary number mein hash karo aur uske **trailing zeros** (right end ke zeros) gino. Dekhe gaye zeros ka maximum $R$ ho to estimate $2^R$ hai. Idea: $r$ trailing zeros wala hash lagbhag $2^r$ distinct items mein se 1 ko milta hai, to $R$ zeros dikhne ka matlab lagbhag $2^R$ distinct items. <Cite id="stream-counting-fm1985" /> <Cite id="stream-counting-mmds-home" loc="§4.4" />

**Steps:** (1) har item ko 4-bit number mein hash karo, (2) binary likho, (3) trailing zeros gino, (4) maximum $R$ rakho, (5) estimate $2^R$. <Cite id="stream-counting-gfg-fm" />

<Sum>

<Given>

Stream $S = \{2, 1, 6, 1, 5, 9, 2, 3, 5\}$, hash $h(x) = (4x + 1) \bmod 16$, result 4-bit binary number ki tarah likha.

</Given>

<Find>

distinct elements ki sankhya ka Flajolet-Martin estimate.

</Find>

<Steps>

1. Har hash aur uska binary form nikalo, phir trailing zeros gino.

| $x$ | $4x+1$ | $\bmod 16$ | 4-bit binary | Trailing zeros |
|---|---|---|---|---|
| 2 | 9 | 9 | 1001 | 0 |
| 1 | 5 | 5 | 0101 | 0 |
| 6 | 25 | 9 | 1001 | 0 |
| 1 | 5 | 5 | 0101 | 0 |
| 5 | 21 | 5 | 0101 | 0 |
| 9 | 37 | 5 | 0101 | 0 |
| 2 | 9 | 9 | 1001 | 0 |
| 3 | 13 | 13 | 1101 | 0 |
| 5 | 21 | 5 | 0101 | 0 |

2. Trailing zeros ka maximum $R = 0$ hai. *Reason: har hash 1 pe end hota hai.*
3. Estimate $= 2^R = 2^0 = 1$.

</Steps>

<Answer>

distinct elements ka estimate $= 2^0 = 1$.

</Answer>

<Box kind="verify">

Check 1: asli distinct elements $\{1, 2, 3, 5, 6, 9\}$ hain, yaani 6. To estimate 1 sach se bahut door hai.

Check 2: kyun. $4x + 1$ hamesha odd hota hai, to last bit hamesha 1 aur trailing zeros hamesha 0, kisi bhi input ke liye. Ye hash achha nahi hai, isliye FM sahi mein 1 deta hai. Question ka answer phir bhi 1 hai.

Check 3: better hash, jaise $h(x) = (3x + 2) \bmod 16$, $x = 2, 1, 6, 5, 9, 3$ ke liye $8, 5, 4, 1, 13, 11$ deta hai. $8 = 1000$ ke 3 trailing zeros hain, aur $4 = 0100$ ke 2, to $R = 3$ aur estimate $2^3 = 8$, jo 6 ke zyada paas hai.

</Box>

</Sum>

**Remarks:** ek hash se rough estimate milta hai. Practice mein kai hash functions use karke estimates combine karte hain (groups mein average, phir median) taaki error kam ho. <Cite id="stream-counting-wiki-fm" />

**Conclusion:** $h(x) = 4x + 1 \bmod 16$ ke saath $R = 0$ aur estimate $2^0 = 1$ (true value 6, kyunki ye hash achha nahi hai).

Exam mein English mein likho: "Maximum trailing zeros R = 0, so the estimated number of distinct elements is 2^0 = 1."
