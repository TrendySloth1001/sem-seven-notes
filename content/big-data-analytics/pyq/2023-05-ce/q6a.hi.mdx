**In simple words:** numeric vector `c()` se bani numbers ki ek row hai. Table ki har row (ek product, paanch din) ek vector ban jaati hai. Subset operator vector, list ya data frame se kuch elements chun leta hai. Ye question CSE (AI&ML) syllabus ke bahar hai, lekin answer ye hai. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

**i. Paanch numeric vectors** (har product ka ek, days Monday se Friday order mein):

```r
bread     <- c(12, 3, 5, 11, 9)
milk      <- c(21, 27, 18, 20, 15)
cola      <- c(10, 1, 33, 6, 12)
chocolate <- c(6, 7, 4, 13, 12)
detergent <- c(5, 8, 12, 20, 23)
```

Chaho to days ke naam de do taaki output padhna easy ho: `names(bread) <- c("Mon", "Tue", "Wed", "Thu", "Fri")`.

<Box kind="verify">

Check: har vector mein 5 numbers hain, har din ka ek, table ki apni row se copy kiye. Hafte ke totals: bread $12+3+5+11+9 = 40$, milk $21+27+18+20+15 = 101$, cola $10+1+33+6+12 = 62$, chocolate $6+7+4+13+12 = 42$, detergent $5+8+12+20+23 = 68$.

</Box>

**ii. R mein subsets banane ke operators.** <Cite id="pyq-2023-05-ce-r-extract" />

| Operator | Meaning | Example and result |
|---|---|---|
| `[ ]` | Single bracket: position, naam ya TRUE/FALSE condition se ek ya zyada elements chunta hai; result ka type same rehta hai | `bread[c(1, 3)]` gives `12 5` |
| `[[ ]]` | Double bracket: bilkul ek element chunta hai, aur element khud deta hai (lists ke saath use hota hai) | `milk[[2]]` gives `27` |
| `$` | List ka named element ya data frame ka column chunta hai | `sales$milk` (`sales <- list(bread = bread, milk = milk)` ke saath) gives `21 27 18 20 15` |
| `-` (negative index) | Di gayi positions ko chhod deta hai | `bread[-1]` gives `3 5 11 9` |
| Comparison `<  >  ==  !=` inside `[ ]` | Condition satisfy karne wale elements chunta hai | `bread[bread > 8]` gives `12 11 9` |
| Logical `&  \|  !` | Conditions jodta hai: AND, OR, NOT | `bread[bread > 4 & bread < 12]` gives `5 11 9` |
| `%in%` | Diye gaye set mein milne wale elements chunta hai | `bread[bread %in% c(3, 9)]` gives `3 9` |

`subset()` function bhi data frames mein condition se rows chunne ke liye use hota hai. <Cite id="pyq-2023-05-ce-gfg-r-subset" /> <Cite id="pyq-2023-05-ce-r-logic" />

<Box kind="verify">

`bread = 12 3 5 11 9` pe examples ka check: 8 se bade 12, 11, 9 hain (3 aur 5 nahi). 4 aur 12 ke beech (exclusive) 5, 11, 9 hain (12, 12 se chhota nahi). Pehla element hatane par 3 5 11 9 bachta hai.

</Box>

**Conclusion:** paanch vectors table ki paanch rows hain; `[ ]`, `[[ ]]` aur `$` (conditions aur negative indexes ke saath) subsets banate hain.

Exam mein English mein likho: "Subsets in R are formed with the operators [ ], [[ ]] and $, along with comparison and logical operators."
