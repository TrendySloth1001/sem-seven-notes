**In simple words:** a data frame is a table in R. A **subset** keeps only the rows (and columns) you want. Two ways are asked: square brackets `df[rows, columns]` and the `subset()` function. This question is outside the CSE (AI&ML) syllabus, but here is the answer. <Cite id="pyq-2023-05-ce-r-extract" /> <Cite id="pyq-2023-05-ce-gfg-r-subset" />

First create the data frame:

```r
df <- data.frame(
  course = c(1, 2, 3, 4, 5, 6),
  id     = c(11, 12, 13, 14, 15, 16),
  class  = c(1, 2, 1, 2, 1, 2),
  marks  = c(56, 75, 48, 69, 84, 53)
)
```

**i. Subset where course is less than 3, using `[ ]`.** Inside the brackets, the part before the comma picks rows (a condition that gives TRUE or FALSE for each row) and the part after the comma picks columns (empty means all columns). The comma must not be forgotten.

```r
df[df$course < 3, ]
```

`df$course < 3` gives `TRUE TRUE FALSE FALSE FALSE FALSE`, so rows 1 and 2 are kept.

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
```

**ii. Subset where course is less than 3 OR class is 2, using `subset()`.** `subset(data, condition)` writes column names without `df$`. `|` means OR. <Cite id="pyq-2024-05-ce-r-subset" />

```r
subset(df, course < 3 | class == 2)
```

Course below 3 is true for rows 1, 2. Class equal to 2 is true for rows 2, 4, 6. The OR of them is rows 1, 2, 4, 6.

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
4      4 14     2    69
6      6 16     2    53
```

<Box kind="verify">

Check: row 3 (course 3, class 1) and row 5 (course 5, class 1) fail both conditions, so they are left out. The 4 rows kept plus the 2 left out equal the 6 original rows. The row names stay 1, 2, 4, 6 because R keeps the original row numbers.

</Box>

| Way | Syntax | Notes |
|---|---|---|
| Brackets | `df[df$course < 3, ]` | Needs `df$`; do not forget the comma; NA rows can appear |
| `subset()` | `subset(df, course < 3)` | Shorter; drops NA rows; for interactive use |

**Conclusion:** part i gives rows 1 and 2; part ii gives rows 1, 2, 4 and 6.
