**In simple words:** the **Flajolet-Martin (FM)** algorithm estimates how many distinct elements a stream has, using very little memory. Hash every element to a binary number and count its **trailing zeros** (zeros at the right end). Let $R$ be the largest count seen. The estimate is $2^R$. <Cite id="stream-counting-fm1985" /> <Cite id="stream-counting-gfg-fm" />

**Why it works.** A random hash value ends in at least $r$ zeros with probability $1/2^r$. So seeing a value with $r$ trailing zeros suggests about $2^r$ different elements were hashed. <Cite id="stream-counting-mmds-home" loc="§4.4" />

<Cite id="stream-counting-gfg-fm" loc="diagram" />

<Sum>

<Given>

Stream 9, 8, 7, 6, 5, 4, 3, 2. Hash $h(x) = (2x + 1) \bmod 32$, written as 5 bits.

</Given>

<Find>

the estimated number of distinct elements.

</Find>

<Steps>

1. **Hash and write in binary.** *Reason: FM works on the bit pattern of the hash.*

   | $x$ | $h(x) = (2x+1) \bmod 32$ | 5-bit binary | Trailing zeros |
   |---|---|---|---|
   | 9 | 19 | 10011 | 0 |
   | 8 | 17 | 10001 | 0 |
   | 7 | 15 | 01111 | 0 |
   | 6 | 13 | 01101 | 0 |
   | 5 | 11 | 01011 | 0 |
   | 4 | 9 | 01001 | 0 |
   | 3 | 7 | 00111 | 0 |
   | 2 | 5 | 00101 | 0 |

2. **Maximum.** $R = 0$.
3. **Estimate.** $2^R = 2^0 = 1$.

</Steps>

<Answer>

The FM estimate is **1** distinct element, while the stream really has 8.

</Answer>

<Box kind="verify">

Binary check: $19 = 16 + 2 + 1 = 10011$, $13 = 8 + 4 + 1 = 01101$, $5 = 4 + 1 = 00101$. The reason for the poor result: $2x + 1$ is always odd, so the last bit is always 1 and there are never any trailing zeros. A good hash must look random. For contrast, using the plain 5-bit value of $x$ gives trailing zeros 0, 3, 0, 1, 0, 2, 0, 1, so $R = 3$ and the estimate $2^3 = 8$ (lucky; FM is only rough for a stream this small).

</Box>

</Sum>

**Limitation and fix.** One hash gives a rough estimate that can be off by a large factor. In practice many hashes are used and their estimates are combined by averaging groups and taking the median. <Cite id="stream-counting-mmds-home" loc="§4.4" /> <Cite id="stream-counting-wiki-fm" />

**Conclusion:** here the given hash only ever produces odd numbers, so FM estimates 1, far from the true count of 8.
