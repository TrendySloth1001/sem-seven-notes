**In simple words:** **content-based recommender** wo items suggest karta hai jo user ke pehle pasand kiye items jaise hon, jahan "jaise" ka matlab item ki apni properties (genre, cast, keywords) se judge hota hai. <Cite id="recommendation-systems-mmds-slides" /> <Cite id="recommendation-systems-gfg-cb" />

**Ise kyun use karein (justification).**

- Ise **dusre users ka data nahi chahiye**, isliye ye naye item ya kam users wali chhoti site par bhi chalta hai.
- Ye **naye aur unpopular items** recommend kar sakta hai, kyunki ye features dekhta hai, ye nahi ki kitno ne rate kiya.
- Ye khud ko **explain** kar sakta hai ("kyunki aapko sci-fi films pasand aayi").
- Ye **alag taste** wale user ko bhi serve kar sakta hai.

Iski limits hain over-specialisation (wahi type ka item baar-baar suggest karna), naye user ke liye **cold start** jiska profile nahi hai, aur achhe features chunne ki mehnat. <Cite id="recommendation-systems-google-cb" />

**Case study: movie streaming app.** Ek user ko *Inception* aur *Interstellar* pasand aayi. App har movie ko genre features se describe karta hai, pasand ki hui movies se user profile banata hai, aur unseen movies ko us profile se similarity ke hisaab se rank karta hai. Music services bhi aise hi karti hain: Pandora ka Music Genome Project songs ko attributes se describe karta hai. <Cite id="recommendation-systems-wiki-genome" />

<Cite id="recommendation-systems-gfg-cb" loc="diagram" />

<Sum>

<Given>

Features (Sci-fi, Action, Romance, Comedy). Pasand ki: Inception $(1,1,0,0)$, Interstellar $(1,0,0,0)$. Candidates: Matrix $(1,1,0,0)$, Avengers $(0,1,0,0)$, Notebook $(0,0,1,0)$.

</Given>

<Find>

user profile aur candidates ki ranking.

</Find>

<Steps>

1. **User profile** = pasand ki hui vectors ka average $= ((1+1)/2, (1+0)/2, 0, 0) = (1, 0.5, 0, 0)$. Iski length $\sqrt{1 + 0.25} = 1.118$ hai.
2. **Cosine** $= \dfrac{u \cdot m}{|u|\,|m|}$.
3. Matrix: $u \cdot m = 1 + 0.5 = 1.5$, $|m| = \sqrt 2 = 1.414$, to $1.5 / (1.118 \times 1.414) = 0.949$.
4. Avengers: $u \cdot m = 0.5$, $|m| = 1$, to $0.5 / 1.118 = 0.447$.
5. Notebook: $u \cdot m = 0$, to cosine $= 0$.

</Steps>

<Answer>

Rank: Matrix (0.949), phir Avengers (0.447), phir Notebook (0). Pehle Matrix recommend karo.

</Answer>

<Box kind="verify">

Angle check: profile $(1, 0.5)$ $26.6^\circ$ par hai aur Matrix $(1, 1)$ $45^\circ$ par. Dono $18.4^\circ$ alag hain aur $\cos 18.4^\circ = 0.949$. Avengers $90^\circ$ par hai, $63.4^\circ$ ka farak, aur $\cos 63.4^\circ = 0.447$.

</Box>

</Sum>

**Conclusion:** content-based filtering wahan justified hai jahan item features available hain aur user data kam hai; over-specialisation se bachne ke liye ise aksar collaborative filtering ke saath mila dete hain.

Exam mein English mein likho: "A content-based recommender suggests items whose features match the user's profile, built from items the user liked earlier."
