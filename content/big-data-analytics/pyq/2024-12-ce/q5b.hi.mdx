**In simple words:** R mein vectors, matrices aur data frames ko jodne ke liye kuch built-in functions hain. Part (ii) mein `sort()` use karke ek chhota script hai.

**(i) Data combine karne ke functions**

| Function | Kya karta hai | Typical use |
|---|---|---|
| `c()` | Values ya vectors ko ek ke baad ek jodkar lamba vector banata hai | `c(a, b)` |
| `cbind()` | Objects ko **side by side** naye columns ki tarah jodta hai (rows same honi chahiye) | column add karna |
| `rbind()` | Objects ko **ek ke neeche ek** naye rows ki tarah stack karta hai (columns same honi chahiye) | records add karna |
| `merge()` | Do data frames ko common column par jodta hai, SQL join ki tarah | `merge(x, y, by = "id")` |

<Cite id="pyq-2024-12-ce-r-cbind" /> <Cite id="pyq-2024-12-ce-r-merge" /> <Cite id="pyq-2025-05-ce-w3-r-df" />

```r
a <- c(1, 2, 3)
b <- c(4, 5, 6)
c(a, b)       # [1] 1 2 3 4 5 6
cbind(a, b)   # 3 rows, columns a aur b
rbind(a, b)   # 2 rows, 3 columns

emp  <- data.frame(id = c(1, 2, 3), name = c("Asha", "Ravi", "Meena"))
dept <- data.frame(id = c(1, 2, 4), dept = c("IT", "HR", "Fin"))
merge(emp, dept, by = "id")
```

Aakhri line ka output (sirf id 1 aur 2 dono tables mein hain; `all = TRUE` baaki ko `NA` ke saath rakhta):

```
  id name dept
1  1 Asha   IT
2  2 Ravi   HR
```

**(ii) Vector ko sort karna**

```r
v    <- c(46, 23, 15, 38, 98, 56, 28, 78)
asc  <- sort(v)                      # ascending default hai
desc <- sort(v, decreasing = TRUE)   # descending
print(asc)
print(desc)
```

Output:

```
[1] 15 23 28 38 46 56 78 98
[1] 98 78 56 46 38 28 23 15
```

**Check.** Dono outputs mein wahi 8 values hain jo input mein thi. Pehle mein har value pichli se badi hai; doosre mein har value pichli se chhoti. `v[order(v)]` bhi wahi ascending result deta hai.

**Conclusion:** `c()` values jodta hai, `cbind()` aur `rbind()` column aur row se jodte hain, `merge()` key par jodta hai, aur `sort()` vector ko order karta hai.

Exam mein English mein likho: "In R, cbind() and rbind() combine by columns and rows, merge() joins data frames on a common column, and sort() orders a vector."
