**In simple words:** R has a few built-in functions to join vectors, matrices and data frames. Part (ii) is a short script using `sort()`.

**(i) Functions to combine data**

| Function | What it does | Typical use |
|---|---|---|
| `c()` | Joins values or vectors end to end into one longer vector | `c(a, b)` |
| `cbind()` | Joins objects **side by side** as new columns (same number of rows) | adding a column |
| `rbind()` | Stacks objects **one below the other** as new rows (same columns) | adding records |
| `merge()` | Joins two data frames on a common column, like a SQL join | `merge(x, y, by = "id")` |

<Cite id="pyq-2024-12-ce-r-cbind" /> <Cite id="pyq-2024-12-ce-r-merge" /> <Cite id="pyq-2025-05-ce-w3-r-df" />

```r
a <- c(1, 2, 3)
b <- c(4, 5, 6)
c(a, b)       # [1] 1 2 3 4 5 6
cbind(a, b)   # 3 rows, columns a and b
rbind(a, b)   # 2 rows, 3 columns

emp  <- data.frame(id = c(1, 2, 3), name = c("Asha", "Ravi", "Meena"))
dept <- data.frame(id = c(1, 2, 4), dept = c("IT", "HR", "Fin"))
merge(emp, dept, by = "id")
```

Output of the last line (only ids 1 and 2 are in both tables; `all = TRUE` would keep the others with `NA`):

```
  id name dept
1  1 Asha   IT
2  2 Ravi   HR
```

**(ii) Sorting the vector**

```r
v    <- c(46, 23, 15, 38, 98, 56, 28, 78)
asc  <- sort(v)                      # ascending is the default
desc <- sort(v, decreasing = TRUE)   # descending
print(asc)
print(desc)
```

Output:

```
[1] 15 23 28 38 46 56 78 98
[1] 98 78 56 46 38 28 23 15
```

**Check.** Both outputs have the same 8 values as the input. In the first each value is bigger than the one before; in the second each is smaller. `v[order(v)]` gives the same ascending result.

**Conclusion:** `c()` joins values, `cbind()` and `rbind()` join by column and row, `merge()` joins on a key, and `sort()` orders a vector.
