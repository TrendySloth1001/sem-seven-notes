**In simple words:** **data frame** R ki table hai. Har column ek type ka vector hota hai, aur saare columns ki length same hoti hai. `data.frame()` use banata hai, `str()` uska structure dikhata hai aur `summary()` har column ki statistics deta hai. <Cite id="pyq-2025-05-ce-gfg-r-df" /> <Cite id="pyq-2025-05-ce-w3-r-df" />

**(i) Data frame banao aur display karo**

```r
projects <- data.frame(
  ProjectId   = 1:5,
  ProjectName = c("Website Redesign", "Mobile App Launch", "Data Migration",
                  "AI Development", "Cybersecurity Audit"),
  Budget      = c(150000, 100000, 80000, 200000, 50000)
)
print(projects)
```

Output:

```
  ProjectId         ProjectName Budget
1         1    Website Redesign 150000
2         2   Mobile App Launch 100000
3         3      Data Migration  80000
4         4      AI Development 200000
5         5 Cybersecurity Audit  50000
```

**(ii) Structure aur summary**

```r
str(projects)
summary(projects)
```

`str()` ka output: <Cite id="pyq-2024-12-ce-r-str" />

```
'data.frame':	5 obs. of  3 variables:
 $ ProjectId  : int  1 2 3 4 5
 $ ProjectName: chr  "Website Redesign" "Mobile App Launch" "Data Migration" "AI Development" ...
 $ Budget     : num  150000 100000 80000 200000 50000
```

`summary()` ka output (spacing thodi alag ho sakti hai): <Cite id="pyq-2024-12-ce-r-summary" />

```
   ProjectId  ProjectName            Budget      
 Min.   :1   Length:5           Min.   : 50000  
 1st Qu.:2   Class :character   1st Qu.: 80000  
 Median :3   Mode  :character   Median :100000  
 Mean   :3                      Mean   :116000  
 3rd Qu.:4                      3rd Qu.:150000  
 Max.   :5                      Max.   :200000  
```

<Sum>

<Given>

Budget values 150000, 100000, 80000, 200000, 50000.

</Given>

<Find>

Budget ke liye `summary()` jo numbers dikhata hai.

</Find>

<Steps>

1. **Sort karo:** 50000, 80000, 100000, 150000, 200000. *Reason: median aur quartiles ke liye sorted values chahiye.*
2. **Min aur max:** 50000 aur 200000.
3. **Median** beech (3rd) value hai: 100000.
4. **Quartiles.** R position $1 + 0.25 \times 4 = 2$ aur $1 + 0.75 \times 4 = 4$ use karta hai: 1st Qu. $= 80000$, 3rd Qu. $= 150000$.
5. **Mean:** $(50000 + 80000 + 100000 + 150000 + 200000) / 5 = 580000 / 5 = 116000$.

</Steps>

<Answer>

Min 50000, 1st Qu. 80000, Median 100000, Mean 116000, 3rd Qu. 150000, Max 200000.

</Answer>

<Box kind="verify">

Mean check: $116000 \times 5 = 580000$, jo paanchon budgets ka total hai. ProjectId 1 se 5 ka mean aur median 3 hai, jaisa dikhaya gaya.

</Box>

</Sum>

**Conclusion:** `data.frame()` table banata hai, `str()` column types aur sizes dikhata hai, aur `summary()` har numeric column ka five-number summary aur mean deta hai.

Exam mein English mein likho: "data.frame() creates the table, str() displays its structure and summary() gives the statistics of each column."
