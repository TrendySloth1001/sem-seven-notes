**In simple words:** big data became practical because several technologies arrived together: cheap storage, cheap clusters, fast networks and software that spreads work over many machines. These are the enabling technologies. <Cite id="big-data-intro-gfg" /> <Cite id="big-data-intro-ibm" />

```mermaid
%% caption: Enabling technologies by layer: data comes in, is stored, processed and finally presented.
flowchart LR
  A["Sources: IoT, social media, logs, apps"] --> B["Ingest: Kafka, Flume, Sqoop"]
  B --> C["Store: HDFS, NoSQL, data lake, cloud storage"]
  C --> D["Process: MapReduce, Spark, stream engines"]
  D --> E["Analyse: machine learning, SQL on Hadoop"]
  E --> F["Present: dashboards, reports"]
```

1. **Distributed storage and processing (Hadoop).** HDFS stores files across many commodity machines with replication; MapReduce and YARN process them where they are stored. <Cite id="hadoop-ecosystem-gfg-hadoop-ecosystem" />
2. **NoSQL databases.** MongoDB, Cassandra, HBase and Neo4j store varied, fast-changing data and scale out horizontally.
3. **In-memory and stream processing.** Spark keeps data in memory for fast, iterative analytics; Kafka and similar systems handle live data.
4. **Cloud computing.** AWS, Azure and Google Cloud rent storage and clusters on demand, so no one must buy hardware first. <Cite id="big-data-intro-aws" />
5. **Data warehouses and data lakes.** A warehouse holds cleaned, structured data for reporting; a lake keeps raw data of any kind.
6. **Machine learning and AI.** Algorithms find patterns, predictions and recommendations in large data.
7. **IoT and mobile devices.** Sensors, phones and wearables are the sources that produce the data.
8. **Visualisation and BI tools.** Tableau and Power BI turn results into charts for decisions.

**Conclusion:** storage, distributed processing, NoSQL, cloud and analytics tools together make it possible to collect, store and analyse data at big data scale.
