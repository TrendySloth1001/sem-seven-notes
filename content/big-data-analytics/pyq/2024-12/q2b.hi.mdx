**In simple words:** big data practical isliye bana kyunki kai technologies ek saath aayi: sasta storage, sasti clusters, fast networks aur software jo kaam ko kai machines pe baant deta hai. Inhe enabling technologies kehte hain. <Cite id="big-data-intro-gfg" /> <Cite id="big-data-intro-ibm" />

```mermaid
%% caption: Enabling technologies layer ke hisaab se: data aata hai, store hota hai, process hota hai aur phir dikhaya jaata hai.
flowchart LR
  A["Sources: IoT, social media, logs, apps"] --> B["Ingest: Kafka, Flume, Sqoop"]
  B --> C["Store: HDFS, NoSQL, data lake, cloud storage"]
  C --> D["Process: MapReduce, Spark, stream engines"]
  D --> E["Analyse: machine learning, SQL on Hadoop"]

```

1. **Distributed storage aur processing (Hadoop).** HDFS files ko kai commodity machines pe replication ke saath rakhta hai; MapReduce aur YARN unhe wahin process karte hain jahan woh stored hain. <Cite id="hadoop-ecosystem-gfg-hadoop-ecosystem" />
2. **NoSQL databases.** MongoDB, Cassandra, HBase aur Neo4j varied aur fast-changing data store karte hain aur horizontally scale hote hain.
3. **In-memory aur stream processing.** Spark data memory mein rakhkar fast, iterative analytics karta hai; Kafka jaise systems live data sambhalte hain.
4. **Cloud computing.** AWS, Azure aur Google Cloud storage aur clusters kiraye pe dete hain, to pehle hardware kharidna nahi padta. <Cite id="big-data-intro-aws" />
5. **Data warehouses aur data lakes.** Warehouse mein clean, structured data reporting ke liye hota hai; lake mein kisi bhi tarah ka raw data.
6. **Machine learning aur AI.** Algorithms bade data mein patterns, predictions aur recommendations dhundhte hain.
7. **IoT aur mobile devices.** Sensors, phones aur wearables woh sources hain jo data banate hain.
8. **Visualisation aur BI tools.** Tableau aur Power BI results ko charts mein badalte hain taaki decision liye ja sakein.

<Img id="img-bda-n1-hadoop-pipeline-hive-spark-kafka" caption="Do typical big data pipelines: batch data HDFS mein aata hai aur Hive aur Spark process karte hain, jabki live data Kafka se Spark Streaming mein jaata hai." />

**Conclusion:** storage, distributed processing, NoSQL, cloud aur analytics tools milkar big data scale pe data collect, store aur analyse karna possible banate hain.

Exam mein English mein likho: "Big data enabling technologies include Hadoop, NoSQL, cloud computing, in-memory processing, data lakes and machine learning."
