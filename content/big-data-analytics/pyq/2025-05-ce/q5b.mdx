**In simple words:** a data structure is a way of keeping many values together. R has six common ones: **vector, list, matrix, array, factor and data frame**. They differ in whether all items must be of one type and in how many dimensions they have. This topic is not in the CSE (AI&ML) syllabus, but the paper asks it.

**1. Vector.** A one-dimensional sequence of items of the **same type** (numeric, character or logical). It is the basic building block of R. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

```r
v <- c(10, 20, 30)
v[2]        # 20
```

**2. List.** A one-dimensional collection whose items can be of **different types**, even other lists or vectors. Items can have names. <Cite id="pyq-2025-05-ce-w3-r-lists" />

```r
s <- list(name = "Asha", age = 21, marks = c(80, 90))
s$name      # "Asha"
```

**3. Matrix.** A two-dimensional table of items of the **same type**, with rows and columns. <Cite id="pyq-2025-05-ce-w3-r-matrices" />

```r
m <- matrix(1:6, nrow = 2)
```

```
     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6
```

**4. Array.** Like a matrix but with **two or more dimensions**, all items of the same type. `array(1:24, dim = c(2, 3, 4))` is four 2 by 3 tables stacked together.

**5. Factor.** A vector for **categories**. R stores the distinct values as *levels*. It is used for data such as "low, medium, high" in statistics. <Cite id="pyq-2025-05-ce-w3-r-factors" />

```r
f <- factor(c("low", "high", "low"))
levels(f)   # "high" "low"
```

**6. Data frame.** A table where each column is a vector, columns may have **different types**, and all columns have the same length. It is the most used structure for real datasets. <Cite id="pyq-2025-05-ce-gfg-r-df" />

```r
df <- data.frame(id = 1:2, name = c("A", "B"))
```

```
  id name
1  1    A
2  2    B
```

| Structure | Dimensions | Item types | Typical use |
| --- | --- | --- | --- |
| Vector | 1 | same | A column of numbers |
| List | 1 | mixed | Holding results of different kinds |
| Matrix | 2 | same | Mathematical tables |
| Array | 2 or more | same | Stacked tables, images |
| Factor | 1 | categories | Grouped (categorical) data |
| Data frame | 2 | mixed by column | Real datasets |

**Conclusion:** choose a vector for one kind of values, a list for mixed items, a matrix or array for numbers in a grid, a factor for categories, and a data frame for a dataset with rows and columns of different types.
