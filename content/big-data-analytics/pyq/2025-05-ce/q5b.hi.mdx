**In simple words:** data structure kai values ko saath rakhne ka tareeka hai. R mein chhe common hain: **vector, list, matrix, array, factor aur data frame**. Inme farq ye hai ki saare items ka type same hona zaroori hai ya nahi, aur kitni dimensions hain. Ye topic CSE (AI&ML) syllabus mein nahi hai, par paper mein poocha gaya hai.

**1. Vector.** Ek-dimensional sequence jisme saare items **same type** ke hote hain (numeric, character ya logical). Ye R ka basic building block hai. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

```r
v <- c(10, 20, 30)
v[2]        # 20
```

**2. List.** Ek-dimensional collection jiske items **alag types** ke ho sakte hain, doosri lists ya vectors bhi. Items ke naam ho sakte hain. <Cite id="pyq-2025-05-ce-w3-r-lists" />

```r
s <- list(name = "Asha", age = 21, marks = c(80, 90))
s$name      # "Asha"
```

**3. Matrix.** Do-dimensional table jisme rows aur columns hote hain, aur saare items **same type** ke. <Cite id="pyq-2025-05-ce-w3-r-matrices" />

```r
m <- matrix(1:6, nrow = 2)
```

```
     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6
```

**4. Array.** Matrix jaisa par **do ya zyada dimensions** ke saath, saare items same type. `array(1:24, dim = c(2, 3, 4))` chaar 2 by 3 tables ek ke upar ek rakhe hain.

**5. Factor.** **Categories** ke liye vector. R distinct values ko *levels* ke roop mein store karta hai. Statistics mein "low, medium, high" jaise data ke liye use hota hai. <Cite id="pyq-2025-05-ce-w3-r-factors" />

```r
f <- factor(c("low", "high", "low"))
levels(f)   # "high" "low"
```

**6. Data frame.** Ek table jahan har column ek vector hai, columns ke **alag types** ho sakte hain, aur saare columns ki length same hoti hai. Real datasets ke liye sabse zyada use hone wala structure. <Cite id="pyq-2025-05-ce-gfg-r-df" />

```r
df <- data.frame(id = 1:2, name = c("A", "B"))
```

```
  id name
1  1    A
2  2    B
```

| Structure | Dimensions | Item types | Typical use |
| --- | --- | --- | --- |
| Vector | 1 | same | A column of numbers |
| List | 1 | mixed | Holding results of different kinds |
| Matrix | 2 | same | Mathematical tables |
| Array | 2 or more | same | Stacked tables, images |
| Factor | 1 | categories | Grouped (categorical) data |
| Data frame | 2 | mixed by column | Real datasets |

**Conclusion:** ek type ki values ke liye vector, mixed items ke liye list, grid mein numbers ke liye matrix ya array, categories ke liye factor, aur alag types ke rows-columns wale dataset ke liye data frame chuno.

Exam mein English mein likho: "R has vectors, lists, matrices, arrays, factors and data frames."
