**In simple words:** a **data frame** in R is a table. Each column is a vector (all values in a column have one type), and different columns can have different types. We build it with `data.frame()` and add rows with `rbind()`. <Cite id="pyq-2025-05-ce-w3-r-df" /> <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Part (i): create and display the data frame.**

```r
projects <- data.frame(
  Project_Id   = c(1, 2, 3, 4, 5),
  Project_Name = c("CRM Implementation", "Cloud Infrastructure",
                   "Network Upgrade", "E-Commerce Platform", "Data Analytics"),
  Budget       = c(120000, 180000, 60000, 220000, 90000),
  Status       = c("In Progress", "Completed", "Not Started",
                   "Completed", "In Progress"),
  stringsAsFactors = FALSE
)
print(projects)
```

Output:

```
  Project_Id         Project_Name Budget      Status
1          1   CRM Implementation 120000 In Progress
2          2 Cloud Infrastructure 180000   Completed
3          3      Network Upgrade  60000 Not Started
4          4  E-Commerce Platform 220000   Completed
5          5       Data Analytics  90000 In Progress
```

**Part (ii): add the two new projects.** Build a second data frame with the same column names and join it below the first with `rbind()`. The names must match, or R gives an error.

```r
new_projects <- data.frame(
  Project_Id   = c(6, 7),
  Project_Name = c("UX Research", "Cloud Integration"),
  Budget       = c(160000, 190000),
  Status       = c("Not Started", "Not Started"),
  stringsAsFactors = FALSE
)
projects <- rbind(projects, new_projects)
print(projects)
```

Output:

```
  Project_Id         Project_Name Budget      Status
1          1   CRM Implementation 120000 In Progress
2          2 Cloud Infrastructure 180000   Completed
3          3      Network Upgrade  60000 Not Started
4          4  E-Commerce Platform 220000   Completed
5          5       Data Analytics  90000 In Progress
6          6          UX Research 160000 Not Started
7          7    Cloud Integration 190000 Not Started
```

**Check:** `nrow(projects)` gives 7 (5 old + 2 new) and `ncol(projects)` gives 4. `str(projects)` shows 4 variables: two numeric columns and two character columns.

The table in the paper spells "Cloud Infrastructure" with a typo; the correct spelling is used above. This topic is not in the CSE (AI&ML) syllabus, but the paper asks it.
