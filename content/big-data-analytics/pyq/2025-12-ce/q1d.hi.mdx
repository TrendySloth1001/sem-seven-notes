**In simple words:** **recall** ye puchta hai: "jo items sach mein set mein hain, unmein se filter ne kitne dhoondhe?" Bloom filter kisi inserted item ke liye kabhi "no" nahi bolta, isliye wo un sabko dhoondh leta hai. Isi wajah se uska recall 100% hai. <Cite id="stream-counting-mmds-home" loc="§4.3" /> <Cite id="stream-counting-wiki-bloom" />

$$
\text{recall} = \frac{TP}{TP + FN}
$$

$TP$ (true positives) wo inserted items hain jinhe filter "present" bolta hai. $FN$ (false negatives) wo inserted items hain jinhe filter "absent" bolta hai.

**$FN = 0$ kyun hai**

1. Item insert karne par uske $k$ bits 1 ho jaate hain.
2. Koi bit kabhi wapas 0 nahi hota. Delete nahi hota.
3. Look-up par wahi $k$ bits dobara nikalte hain aur wo abhi bhi sab 1 hain, to answer hamesha "possibly present" aata hai.
4. To koi inserted item reject nahi hota: $FN = 0$ aur recall $= TP/(TP + 0) = 1 = 100\%$.

<Img id="img-bda-n2-bloom" caption="Har inserted item (x, y, z) apne bits 1 kar deta hai, aur wo bits 1 hi rehte hain. Isliye inserted item ka look-up uske saare bits set paata hai." />

| Look up kiya gaya item | Sach | Filter kya bolta hai | Result |
|---|---|---|---|
| Insert hua tha | present | possibly present | True positive (hamesha) |
| Kabhi insert nahi hua, ek bit 0 hai | absent | definitely absent | True negative |
| Kabhi insert nahi hua, saare bits dusre items se 1 hain | absent | possibly present | **False positive** |
| Insert hua tha | present | definitely absent | **Impossible** |

**Iski keemat.** Saari galtiyan dusri taraf hoti hain. Alag items bits share kar sakte hain, isliye kuch absent items present dikhte hain (false positives), aur **precision** 100% se kam hoti hai. Array bharne par false-positive rate badhta hai. Bloom filter wahan use hota hai jahan galat "yes" sasta hai (aage slow exact store check kar lo) lekin galat "no" nuksaan karega. <Cite id="stream-counting-gfg-bloom" />

**Conclusion:** bits sirf set hote hain, kabhi clear nahi, isliye inserted item hamesha pass hota hai. Recall 100% hai, sirf precision ka nuksaan hota hai.

Exam mein English mein likho: "A Bloom filter has no false negatives, so recall = TP / (TP + FN) = 100%."
