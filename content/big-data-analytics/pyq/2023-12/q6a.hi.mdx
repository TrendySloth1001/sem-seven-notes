**In simple words:** distance measure "do cheezein kitni alag hain?" ko ek number bana deta hai. Do major classes hain: **Euclidean** distances, jahan items coordinates wali space ke points hain, aur **non-Euclidean** distances, jahan items sets, strings, bit vectors ya documents hain. <Cite id="distance-measures-mmds" loc="§3.5, §7.1" /> <Cite id="distance-measures-av" />

**Distance ke rules** $d(x, y)$: kabhi negative nahi, sirf $x = y$ par 0, symmetric, aur triangle inequality $d(x,z) \le d(x,y) + d(y,z)$.

**Euclidean class.** Items numeric coordinates wale points hain, isliye hum hamesha **average** point le sakte hain (har coordinate ka average). Usual measures $L_2$ (straight-line), $L_1$ (Manhattan) aur $L_\infty$ hain. Cluster ka centre **centroid** hai, jo naya point ho sakta hai. <Cite id="distance-measures-gfg-euclid" /> <Cite id="distance-measures-wiki-euclid" />

<Img id="img-bda-2023-12-manhattan-vs-euclidean" caption="Green seedhi line Euclidean (L2) distance hai; red, blue aur yellow grid paths ki Manhattan (L1) length barabar hai." />

**Non-Euclidean class.** Items ke coordinates nahi hote, isliye items jod nahi sakte aur average item nahi nikal sakte. Examples: Jaccard (sets), cosine (vector directions), edit distance (strings), Hamming (bit vectors). Cluster ka centre koi existing item hona chahiye, **clustroid**. <Cite id="distance-measures-gfg-jaccard" />

| Point | Euclidean | Non-Euclidean |
|---|---|---|
| Items are | Points with coordinates | Sets, strings, bit vectors, documents |
| Examples | $L_2$, $L_1$, $L_\infty$ | Jaccard, cosine, edit, Hamming |
| Average item | Exists | Does not exist |
| Cluster centre | Centroid (a new point) | Clustroid (an existing item) |
| Typical data | Coordinates, heights, sensor values | Documents, DNA, usernames |

<Sum>

<Given>

Euclidean example: points $P(1, 2)$ aur $Q(4, 6)$. Non-Euclidean example: sets $A = \{a, b, c, d\}$ aur $B = \{c, d, e\}$ (Jaccard distance).

</Given>

<Find>

$L_2$, $L_1$ aur $L_\infty$ distances aur $P$, $Q$ ka average; $A$ aur $B$ ka Jaccard distance.

</Find>

<Steps>

1. Differences: $\Delta x = 4 - 1 = 3$, $\Delta y = 6 - 2 = 4$. *Reason: saare Euclidean measures coordinate differences use karte hain.*
2. $L_2 = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$.
3. $L_1 = 3 + 4 = 7$ aur $L_\infty = \max(3, 4) = 4$.
4. Average point $= ((1+4)/2, (2+6)/2) = (2.5, 4)$. *Reason: Euclidean space mein average hamesha hota hai.*
5. Sets: intersection $A \cap B = \{c, d\}$, size 2. Union $= \{a, b, c, d, e\}$, size 5.
6. Jaccard similarity $= 2/5 = 0.4$, to Jaccard distance $= 1 - 0.4 = 0.6$. *Reason: distance = 1 minus similarity.*

</Steps>

<Answer>

$L_2 = 5$, $L_1 = 7$, $L_\infty = 4$, average point $(2.5, 4)$; Jaccard distance $= 0.6$.

</Answer>

<Box kind="verify">

3-4-5 triangle se $L_2 = 5$ ($9 + 16 = 25$). Ordering $L_\infty \le L_2 \le L_1$ sahi hai ($4 \le 5 \le 7$). Sets ke liye union ki ginti dobara: $|A| + |B| - |A \cap B| = 4 + 3 - 2 = 5$, wahi union size. $A$ aur $B$ ka koi "average" set nahi hota, isliye is class ko clustroids chahiye.

</Box>

</Sum>

**Conclusion:** pehle dekho items kya hain. Points ke liye Euclidean measures; sets, strings aur bits ke liye non-Euclidean.
