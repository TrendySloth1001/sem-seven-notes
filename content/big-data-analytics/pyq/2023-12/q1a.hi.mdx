**In simple words:** Hadoop ek free, open-source framework hai jo bahut bada data ordinary computers ke cluster pe store karta hai aur sab pe ek saath process karta hai. Ye do Google papers (Google File System aur MapReduce) ke idea se bana hai. <Cite id="hadoop-ecosystem-wiki-hadoop" /> <Cite id="hadoop-ecosystem-ghemawat2003" /> <Cite id="hadoop-ecosystem-dean2004" />

**Ye kyun zaroori hai.** Ek server terabytes data hold nahi kar sakta, ek disk se padhne mein ghante lagte hain, aur bada special machine mehenga hota hai aur kharab ho to sab ruk jaata hai. Hadoop data aur kaam ko bahut saari sasti machines pe baant deta hai, jaise ek bada stove kharidne ki jagah bahut saare cooks rakhna. <Cite id="hadoop-ecosystem-ibm-hadoop" />

**Core parts.**

- **HDFS:** storage. Files ko blocks (default 128 MB) mein kaatta hai aur har block ki 3 copies alag nodes pe rakhta hai.
- **YARN:** cluster ki CPU aur memory ko jobs mein baantta hai.
- **MapReduce:** processing do steps mein, map aur reduce, data ke paas parallel chalte hain.
- **Hadoop Common:** shared libraries.

**Ye kyun matter karta hai.**

| Strength | Meaning |
|---|---|
| Scalable | Nodes jodo to storage aur speed badhti hai. |
| Low cost | Commodity hardware aur free software. |
| Fault tolerant | Block copies hoti hain, aur failed tasks dusri jagah dobara chalte hain. |
| Flexible | Structured, semi-structured aur unstructured data jaisa hai waisa store karta hai. |

<Cite id="hadoop-ecosystem-aws-hadoop" /> <Cite id="hadoop-ecosystem-gfg-hadoop-intro" />

**Example.** Bank saalon ke transaction logs Hadoop pe analyse karke fraud dhundta hai, jabki balances RDBMS mein rehte hain.

**Conclusion:** Hadoop important hai kyunki wo big data ko store aur analyse karna sasta, scalable aur failures se safe banata hai.
