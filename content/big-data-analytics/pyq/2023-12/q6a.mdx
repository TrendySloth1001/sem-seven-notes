**In simple words:** a distance measure turns "how different are two things?" into one number. The two major classes are **Euclidean** distances, where items are points in a space with coordinates, and **non-Euclidean** distances, where items are sets, strings, bit vectors or documents. <Cite id="distance-measures-mmds" loc="§3.5, §7.1" /> <Cite id="distance-measures-av" />

**Rules of a distance** $d(x, y)$: it is never negative, it is 0 only when $x = y$, it is symmetric, and it obeys the triangle inequality $d(x,z) \le d(x,y) + d(y,z)$.

**Euclidean class.** Items are points with numeric coordinates, so we can always take an **average** point (average each coordinate). The usual measures are the $L_2$ (straight-line), $L_1$ (Manhattan) and $L_\infty$ distances. The centre of a cluster is a **centroid**, which can be a new point. <Cite id="distance-measures-gfg-euclid" /> <Cite id="distance-measures-wiki-euclid" />

<Img id="img-bda-2023-12-manhattan-vs-euclidean" caption="The green straight line is the Euclidean (L2) distance; the red, blue and yellow grid paths all have the same Manhattan (L1) length." />

**Non-Euclidean class.** Items have no coordinates, so we cannot add items or find an average item. Examples are Jaccard (sets), cosine (vector directions), edit distance (strings) and Hamming (bit vectors). The centre of a cluster must be an existing item, a **clustroid**. <Cite id="distance-measures-gfg-jaccard" />

| Point | Euclidean | Non-Euclidean |
|---|---|---|
| Items are | Points with coordinates | Sets, strings, bit vectors, documents |
| Examples | $L_2$, $L_1$, $L_\infty$ | Jaccard, cosine, edit, Hamming |
| Average item | Exists | Does not exist |
| Cluster centre | Centroid (a new point) | Clustroid (an existing item) |
| Typical data | Coordinates, heights, sensor values | Documents, DNA, usernames |

<Sum>

<Given>

Euclidean example: points $P(1, 2)$ and $Q(4, 6)$. Non-Euclidean example: sets $A = \{a, b, c, d\}$ and $B = \{c, d, e\}$ (Jaccard distance).

</Given>

<Find>

the $L_2$, $L_1$ and $L_\infty$ distances and the average of $P$ and $Q$; the Jaccard distance of $A$ and $B$.

</Find>

<Steps>

1. Differences: $\Delta x = 4 - 1 = 3$, $\Delta y = 6 - 2 = 4$. *Reason: all Euclidean measures use coordinate differences.*
2. $L_2 = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$.
3. $L_1 = 3 + 4 = 7$ and $L_\infty = \max(3, 4) = 4$.
4. Average point $= ((1+4)/2, (2+6)/2) = (2.5, 4)$. *Reason: a Euclidean space always has an average.*
5. Sets: intersection $A \cap B = \{c, d\}$, size 2. Union $= \{a, b, c, d, e\}$, size 5.
6. Jaccard similarity $= 2/5 = 0.4$, so Jaccard distance $= 1 - 0.4 = 0.6$. *Reason: distance is 1 minus similarity.*

</Steps>

<Answer>

$L_2 = 5$, $L_1 = 7$, $L_\infty = 4$, average point $(2.5, 4)$; Jaccard distance $= 0.6$.

</Answer>

<Box kind="verify">

The 3-4-5 triangle gives $L_2 = 5$ ($9 + 16 = 25$). The ordering $L_\infty \le L_2 \le L_1$ holds ($4 \le 5 \le 7$). For the sets, counting from the union: $|A| + |B| - |A \cap B| = 4 + 3 - 2 = 5$, the same union size. There is no "average" of $A$ and $B$ that is a set, which is why this class needs clustroids.

</Box>

</Sum>

**Conclusion:** first ask what the items are. Points use Euclidean measures; sets, strings and bits use non-Euclidean ones.
