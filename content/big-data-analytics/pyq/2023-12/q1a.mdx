**In simple words:** Hadoop is a free, open-source framework that stores very large data on a cluster of ordinary computers and processes it on all of them at the same time. It grew out of two Google papers, the Google File System and MapReduce. <Cite id="hadoop-ecosystem-wiki-hadoop" /> <Cite id="hadoop-ecosystem-ghemawat2003" /> <Cite id="hadoop-ecosystem-dean2004" />

**Why it is needed.** One server cannot hold terabytes of data, reading it through one disk takes hours, and a big special machine is costly and stops everything when it breaks. Hadoop spreads the data and the work over many cheap machines, like hiring many cooks instead of buying one huge stove. <Cite id="hadoop-ecosystem-ibm-hadoop" />

**Core parts.**

- **HDFS:** storage. It cuts files into blocks (128 MB by default) and keeps 3 copies of each block on different nodes.
- **YARN:** shares the cluster's CPU and memory between jobs.
- **MapReduce:** processing in two steps, map and reduce, run in parallel near the data.
- **Hadoop Common:** the shared libraries.

**Why it matters.**

| Strength | Meaning |
|---|---|
| Scalable | Add nodes to add storage and speed. |
| Low cost | Commodity hardware and free software. |
| Fault tolerant | Block copies exist, and failed tasks run again elsewhere. |
| Flexible | Stores structured, semi-structured and unstructured data as it is. |

<Cite id="hadoop-ecosystem-aws-hadoop" /> <Cite id="hadoop-ecosystem-gfg-hadoop-intro" />

**Example.** A bank analyses years of transaction logs on Hadoop to find fraud, while its balances stay in an RDBMS.

**Conclusion:** Hadoop matters because it makes storing and analysing big data cheap, scalable and safe from failures.
