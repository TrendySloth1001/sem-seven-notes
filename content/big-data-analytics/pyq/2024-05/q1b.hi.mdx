**In simple words:** distance measure do items ke beech ki doori ko ek number mein batata hai (0 ka matlab bilkul same). Clustering, nearest-neighbour search, similar documents dhoondna aur recommendations sabko iski zaroorat hoti hai. Kaunsa measure use karna hai ye is pe depend karta hai ki items kya hain: sets, points, vectors ya strings. <Cite id="distance-measures-mmds" loc="§3.5" /> <Cite id="distance-measures-av" />

Ek sachchi distance kabhi 0 se kam nahi hoti, sirf identical items ke liye 0 hoti hai, dono taraf same hoti hai, aur triangle inequality maanti hai (seedha raasta kabhi ghumavdaar raaste se lamba nahi hota).

| Measure | Used for | Idea |
|---|---|---|
| Jaccard | Sets | $1 - \dfrac{\lvert A \cap B \rvert}{\lvert A \cup B \rvert}$: common items / saare items |
| Euclidean ($L_2$) | Points in space | Seedhi line ki doori, $\sqrt{\sum (x_i - y_i)^2}$ |
| Manhattan ($L_1$) | Points in space | Har coordinate ke gap ka sum |
| Cosine | Vectors, documents | Vectors ke beech ka angle, $\cos\theta = \dfrac{x \cdot y}{\lVert x \rVert \lVert y \rVert}$ |
| Edit | Strings | Ek string ko doosri banane ke liye kam se kam insertions aur deletions |
| Hamming | Barabar length ki strings ya bit strings | Kitni positions alag hain |

<Sum>

<Given>

Sets $A = \{1,2,3,4\}$, $B = \{3,4,5\}$. Points $p = (1,2)$, $q = (4,6)$. Vectors $x = (1,2)$, $y = (2,1)$. Strings abcde aur acfdeg. Bit strings 10101 aur 11001.

</Given>

<Find>

har distance.

</Find>

<Steps>

1. **Jaccard.** Common items \{3, 4\} se 2; saare items \{1, 2, 3, 4, 5\} se 5. Similarity $= 2/5 = 0.4$, distance $= 1 - 0.4 = 0.6$.
2. **Euclidean.** $\sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$.
3. **Manhattan.** $\lvert 4-1 \rvert + \lvert 6-2 \rvert = 3 + 4 = 7$.
4. **Cosine.** $x \cdot y = 1 \cdot 2 + 2 \cdot 1 = 4$; $\lVert x \rVert = \lVert y \rVert = \sqrt{5}$, to $\cos\theta = 4/5 = 0.8$ aur angle lagbhag $36.9^\circ$.
5. **Edit.** abcde aur acfdeg ki longest common subsequence acde hai (length 4). Distance $= 5 + 6 - 2 \times 4 = 3$ (b delete, f insert, g insert).
6. **Hamming.** 10101 aur 11001 positions 2 aur 3 pe alag hain, to distance 2.

</Steps>

<Answer>

Jaccard 0.6, Euclidean 5, Manhattan 7, cosine 0.8 (angle lagbhag $36.9^\circ$), edit 3, Hamming 2.

</Answer>

<Box kind="verify">

Euclidean 5 ek 3-4-5 right triangle se aata hai, aur wo Manhattan 7 se chhota hai, jaisa hona chahiye. Edit ke steps (b delete, f insert, g insert) abcde ko 3 moves mein acfdeg bana dete hain, formula se match karta hai. Hamming: positions 1, 4 aur 5 match karti hain (1, 0, 1), to 5 mein se sirf 2 alag hain.

</Box>

</Sum>

**Conclusion:** sets ke liye Jaccard, points ke liye Euclidean ya Manhattan, documents ke liye cosine, strings ke liye edit distance aur bit strings ke liye Hamming use karo. <Cite id="distance-measures-gfg-cosine" /> <Cite id="distance-measures-wiki-hamming" />
