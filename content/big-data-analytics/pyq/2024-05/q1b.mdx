**In simple words:** a distance measure gives one number for how far apart two items are (0 means identical). Clustering, nearest-neighbour search, finding similar documents and recommendations all need it. Which measure to use depends on what the items are: sets, points, vectors or strings. <Cite id="distance-measures-mmds" loc="§3.5" /> <Cite id="distance-measures-av" />

A true distance never goes below 0, is 0 only for identical items, is the same in both directions, and obeys the triangle inequality (the direct route is never longer than a detour).

| Measure | Used for | Idea |
|---|---|---|
| Jaccard | Sets | $1 - \dfrac{\lvert A \cap B \rvert}{\lvert A \cup B \rvert}$: shared items over all items |
| Euclidean ($L_2$) | Points in space | Straight-line distance, $\sqrt{\sum (x_i - y_i)^2}$ |
| Manhattan ($L_1$) | Points in space | Sum of gaps in each coordinate |
| Cosine | Vectors, documents | Angle between the vectors, $\cos\theta = \dfrac{x \cdot y}{\lVert x \rVert \lVert y \rVert}$ |
| Edit | Strings | Fewest insertions and deletions to turn one string into the other |
| Hamming | Equal-length strings or bit strings | Number of positions that differ |

<Sum>

<Given>

Sets $A = \{1,2,3,4\}$, $B = \{3,4,5\}$. Points $p = (1,2)$, $q = (4,6)$. Vectors $x = (1,2)$, $y = (2,1)$. Strings abcde and acfdeg. Bit strings 10101 and 11001.

</Given>

<Find>

each distance.

</Find>

<Steps>

1. **Jaccard.** Common items \{3, 4\} give 2; all items \{1, 2, 3, 4, 5\} give 5. Similarity $= 2/5 = 0.4$, distance $= 1 - 0.4 = 0.6$.
2. **Euclidean.** $\sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$.
3. **Manhattan.** $\lvert 4-1 \rvert + \lvert 6-2 \rvert = 3 + 4 = 7$.
4. **Cosine.** $x \cdot y = 1 \cdot 2 + 2 \cdot 1 = 4$; $\lVert x \rVert = \lVert y \rVert = \sqrt{5}$, so $\cos\theta = 4/5 = 0.8$ and the angle is about $36.9^\circ$.
5. **Edit.** The longest common subsequence of abcde and acfdeg is acde (length 4). Distance $= 5 + 6 - 2 \times 4 = 3$ (delete b, insert f, insert g).
6. **Hamming.** 10101 and 11001 differ in positions 2 and 3, so the distance is 2.

</Steps>

<Answer>

Jaccard 0.6, Euclidean 5, Manhattan 7, cosine 0.8 (angle about $36.9^\circ$), edit 3, Hamming 2.

</Answer>

<Box kind="verify">

Euclidean 5 comes from the 3-4-5 right triangle, and it is less than Manhattan 7, as it must be. The edit steps (delete b, insert f, insert g) turn abcde into acfdeg in 3 moves, matching the formula. Hamming: positions 1, 4 and 5 match (1, 0, 1), so only 2 of 5 differ.

</Box>

</Sum>

**Conclusion:** use Jaccard for sets, Euclidean or Manhattan for points, cosine for documents, edit distance for strings and Hamming for bit strings. <Cite id="distance-measures-gfg-cosine" /> <Cite id="distance-measures-wiki-hamming" />
