**i. Script to create `data1`**

The values are numbers, so make a numeric vector with `c()` (combine). The name `data1` is on the left of `<-`.

```r
data1 <- c(2, 3, 4, 5, 6.7, 7, 8.1, 9)
print(data1)
length(data1)
```

Output:

```text
[1] 2.0 3.0 4.0 5.0 6.7 7.0 8.1 9.0
[1] 8
```

R shows all numbers with one decimal because a vector has one type and 6.7 and 8.1 need a decimal. If the values must be text, put quotes: `c("2", "3", ...)`. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

**ii. Functions to combine different sets of data in R**

| Function | What it does | Example |
|---|---|---|
| `c()` | joins values or vectors into one longer vector | `c(1, 2, 3, 4, 5, 6)` gives 1 2 3 4 5 6 |
| `append()` | adds values to a vector, optionally after a position | `append(1:3, 99, after = 1)` gives 1 99 2 3 |
| `cbind()` | joins by **columns** (side by side); same number of rows | `cbind(a = 1:3, b = 4:6)` |
| `rbind()` | joins by **rows** (one below the other); same columns | `rbind(df1, df2)` |
| `merge()` | joins two data frames on a common column, like a SQL join | `merge(df1, df2, by = "id")` |
| `list()` | holds different types or lengths together | `list(1:3, "a")` |

<Cite id="pyq-2024-05-ce-r-cbind" /> <Cite id="pyq-2024-05-ce-r-merge" />

**cbind and rbind example**

```r
cbind(a = 1:3, b = 4:6)
```

```text
     a b
[1,] 1 4
[2,] 2 5
[3,] 3 6
```

`rbind(1:3, 4:6)` stacks the two vectors as the rows of a 2 by 3 matrix.

**merge example**

```r
df1 <- data.frame(id = c(1, 2, 3), name = c("Asha", "Ravi", "Meena"))
df2 <- data.frame(id = c(2, 3, 4), marks = c(75, 48, 60))
merge(df1, df2, by = "id")
```

```text
  id  name marks
1  2  Ravi    75
2  3 Meena    48
```

By default `merge()` keeps only ids found in both frames (inner join). `all = TRUE` keeps all ids and fills missing cells with `NA`; `all.x = TRUE` keeps all rows of the first frame. <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Conclusion:** use `c()` and `append()` for vectors, `cbind()` and `rbind()` to place data side by side or one below the other, and `merge()` to join tables by a key.
