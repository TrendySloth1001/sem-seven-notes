**In simple words:** data frame R ki ek table hai jiske columns ke naam hote hain. Kuch rows chunne ke liye ya to `[rows, columns]` se index karo, ya `subset()` call karo jo condition leta hai. <Cite id="pyq-2025-05-ce-gfg-r-df" /> <Cite id="pyq-2025-05-ce-w3-r-df" />

**Data frame banao**

```r
df <- data.frame(
  course = 1:6,
  id     = 11:16,
  class  = c(1, 2, 1, 2, 1, 2),
  marks  = c(56, 75, 48, 69, 84, 53)
)
```

**i. `[ ]` se course 5 se kam wala subset**

`[ ]` ke andar pehli position rows chunti hai, doosri columns. Column pe condition har row ke liye TRUE ya FALSE deti hai, aur R TRUE rows rakhta hai. Saare columns rakhne ke liye column wali position khali chhodo (comma dhyan se).

```r
df[df$course < 5, ]
```

Output:

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
3      3 13     1    48
4      4 14     2    69
```

**ii. `subset()` se course 4 se kam YA class 1 wala subset**

`subset(data, condition)` wo rows rakhta hai jahan condition true hai. Iske andar column names seedhe use hote hain, aur `|` ka matlab OR hai.

```r
subset(df, course < 4 | class == 1)
```

Output:

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
3      3 13     1    48
5      5 15     1    84
```

<Box kind="verify">

course 4 se kam wali rows 1, 2, 3 hain. class 1 wali rows 1, 3, 5 hain. Dono ka union rows 1, 2, 3, 5 hai, jo output se match karta hai (row 4 ka course 4 aur class 2 hai, to wo dono tests fail karti hai). Row numbers apni original value rakhte hain. Part i ke liye courses 1 se 4 do 5 se kam hain, to 4 rows. <Cite id="pyq-2024-05-ce-r-subset" />

</Box>

**Common galti:** `df[df$course < 5]` bina comma ke condition ko column choice samajhta hai aur error deta hai. AND ke liye `&` aur OR ke liye `|` use karo; `&&` aur `||` poore columns pe kaam nahi karte.

**Conclusion:** `[ ]` ko `df$column` aur comma chahiye, jabki `subset()` chhota hai kyunki wo column names seedhe padhta hai.
