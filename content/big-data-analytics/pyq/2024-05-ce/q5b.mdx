**In simple words:** a data frame is an R table with named columns. To pick some rows, either index it with `[rows, columns]` or call `subset()`, which takes a condition. <Cite id="pyq-2025-05-ce-gfg-r-df" /> <Cite id="pyq-2025-05-ce-w3-r-df" />

**Create the data frame**

```r
df <- data.frame(
  course = 1:6,
  id     = 11:16,
  class  = c(1, 2, 1, 2, 1, 2),
  marks  = c(56, 75, 48, 69, 84, 53)
)
```

**i. Subset where course is less than 5 using `[ ]`**

The first position inside `[ ]` chooses rows, the second chooses columns. A condition on a column gives TRUE or FALSE for every row, and R keeps the TRUE rows. Leave the column position empty (note the comma) to keep all columns.

```r
df[df$course < 5, ]
```

Output:

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
3      3 13     1    48
4      4 14     2    69
```

**ii. Subset where course is less than 4 OR class equals 1, using `subset()`**

`subset(data, condition)` keeps the rows where the condition is true. Inside it, column names are used directly, and `|` means OR.

```r
subset(df, course < 4 | class == 1)
```

Output:

```text
  course id class marks
1      1 11     1    56
2      2 12     2    75
3      3 13     1    48
5      5 15     1    84
```

<Box kind="verify">

Rows with course below 4 are 1, 2, 3. Rows with class 1 are 1, 3, 5. Their union is rows 1, 2, 3, 5, which matches the output (row 4 has course 4 and class 2, so it fails both tests). Row numbers keep their original values. For part i, courses 1 to 4 are below 5, so 4 rows. <Cite id="pyq-2024-05-ce-r-subset" />

</Box>

**Common mistake:** `df[df$course < 5]` without the comma treats the condition as a column choice and gives an error. Use `&` for AND and `|` for OR; `&&` and `||` do not work on whole columns.

**Conclusion:** `[ ]` needs `df$column` and a comma, while `subset()` is shorter because it reads column names directly.
