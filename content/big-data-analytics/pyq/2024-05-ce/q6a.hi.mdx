**i. `data1` banane ki script**

Values numbers hain, to `c()` (combine) se numeric vector banao. Naam `data1` `<-` ke left mein likhte hain.

```r
data1 <- c(2, 3, 4, 5, 6.7, 7, 8.1, 9)
print(data1)
length(data1)
```

Output:

```text
[1] 2.0 3.0 4.0 5.0 6.7 7.0 8.1 9.0
[1] 8
```

R sab numbers ek decimal ke saath dikhata hai kyunki vector ka ek hi type hota hai aur 6.7 aur 8.1 ko decimal chahiye. Agar values text honi chahiye to quotes lagao: `c("2", "3", ...)`. <Cite id="pyq-2025-05-ce-w3-r-vectors" />

**ii. R mein alag alag data sets ko jodne ke functions**

| Function | Kya karta hai | Example |
|---|---|---|
| `c()` | values ya vectors ko ek lambe vector mein jodta hai | `c(1, 2, 3, 4, 5, 6)` se 1 2 3 4 5 6 |
| `append()` | vector mein values jodta hai, chaho to kisi position ke baad | `append(1:3, 99, after = 1)` se 1 99 2 3 |
| `cbind()` | **columns** ke hisaab se jodta hai (side by side); rows ki sankhya same | `cbind(a = 1:3, b = 4:6)` |
| `rbind()` | **rows** ke hisaab se jodta hai (ek ke neeche ek); columns same | `rbind(df1, df2)` |
| `merge()` | do data frames ko common column pe jodta hai, SQL join ki tarah | `merge(df1, df2, by = "id")` |
| `list()` | alag types ya lengths ko saath rakhta hai | `list(1:3, "a")` |

<Cite id="pyq-2024-05-ce-r-cbind" /> <Cite id="pyq-2024-05-ce-r-merge" />

**cbind aur rbind example**

```r
cbind(a = 1:3, b = 4:6)
```

```text
     a b
[1,] 1 4
[2,] 2 5
[3,] 3 6
```

`rbind(1:3, 4:6)` do vectors ko 2 by 3 matrix ki rows ki tarah ek ke neeche ek rakhta hai.

**merge example**

```r
df1 <- data.frame(id = c(1, 2, 3), name = c("Asha", "Ravi", "Meena"))
df2 <- data.frame(id = c(2, 3, 4), marks = c(75, 48, 60))
merge(df1, df2, by = "id")
```

```text
  id  name marks
1  2  Ravi    75
2  3 Meena    48
```

Default mein `merge()` sirf wo ids rakhta hai jo dono frames mein hain (inner join). `all = TRUE` saare ids rakhta hai aur khali cells `NA` se bharta hai; `all.x = TRUE` pehle frame ki saari rows rakhta hai. <Cite id="pyq-2025-05-ce-gfg-r-df" />

**Conclusion:** vectors ke liye `c()` aur `append()`, data ko side by side ya ek ke neeche rakhne ke liye `cbind()` aur `rbind()`, aur tables ko key se jodne ke liye `merge()` use karo.
