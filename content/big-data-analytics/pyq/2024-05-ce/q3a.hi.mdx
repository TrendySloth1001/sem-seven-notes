**In simple words:** Flajolet-Martin (FM) bina items store kiye batata hai ki stream mein kitne **alag** items hain. Har item ko hash karke binary number banao aur uske **trailing zeros** (right end ke zeros) gino. Lambi trailing zeros ki run rare hoti hai, isliye dekhi gayi sabse lambi run $R$ size batati hai: estimate $= 2^R$. <Cite id="stream-counting-mmds-home" loc="§4.4" /> <Cite id="stream-counting-fm1985" /> <Cite id="stream-counting-gfg-fm" />

**Ye kyun kaam karta hai:** lagbhag aadhe hash values 0 pe khatam hote hain, chauthai 00 pe, aur aise hi aage. $r$ zeros pe khatam hone wale value ka chance $2^{-r}$ hota hai, to $R$ zeros dikhna matlab lagbhag $2^R$ alag items.

<Sum>

<Given>

stream $S = \{4, 2, 5, 9, 1, 6, 3, 7\}$, hash $h(x) = (3x + 7) \bmod 32$, 5-bit binary number ki tarah likha hua.

</Given>

<Find>

distinct elements ka estimate.

</Find>

<Steps>

1. **Har element ko hash karo aur 5 bits likho.** Phir trailing zeros gino:

   | $x$ | $3x + 7$ | mod 32 | 5-bit binary | Trailing zeros |
   |---|---|---|---|---|
   | 4 | 19 | 19 | 10011 | 0 |
   | 2 | 13 | 13 | 01101 | 0 |
   | 5 | 22 | 22 | 10110 | 1 |
   | 9 | 34 | 2 | 00010 | 1 |
   | 1 | 10 | 10 | 01010 | 1 |
   | 6 | 25 | 25 | 11001 | 0 |
   | 3 | 16 | 16 | 10000 | 4 |
   | 7 | 28 | 28 | 11100 | 2 |

2. **Maximum lo** trailing zeros ka: $R = \max(0,0,1,1,1,0,4,2) = 4$. *Reason: FM sirf sabse lambi run rakhta hai.*
3. **Estimate** $= 2^R = 2^4 = 16$.

</Steps>

<Answer>

$R = 4$, to distinct elements ka estimate $2^4 = 16$ hai.

</Answer>

<Box kind="verify">

Binary check: $19 = 16 + 2 + 1 = 10011$, $13 = 8 + 4 + 1 = 01101$, $22 = 16 + 4 + 2 = 10110$, $2 = 00010$, $10 = 8 + 2 = 01010$, $25 = 16 + 8 + 1 = 11001$, $16 = 10000$, $28 = 16 + 8 + 4 = 11100$. Asli distinct elements 8 hain, to ek hash 2 ke factor se zyada bata raha hai. Ye normal hai: ek hash function wala FM rough hota hai, aur practice mein kai hash functions milaye jaate hain (groups ke andar average, phir groups ka median). <Cite id="stream-counting-wiki-fm" />

</Box>

</Sum>

**Conclusion:** trailing zeros ki sabse lambi run $4$ hai, to FM $16$ distinct elements estimate karta hai, aur memory sirf ek number ki lagti hai.
