**In simple words:** Flajolet-Martin (FM) estimates how many **different** items a stream has without storing them. Hash every item to a binary number and count its **trailing zeros** (zeros at the right end). A long run of trailing zeros is rare, so the longest run $R$ seen tells the size: estimate $= 2^R$. <Cite id="stream-counting-mmds-home" loc="§4.4" /> <Cite id="stream-counting-fm1985" /> <Cite id="stream-counting-gfg-fm" />

**Why it works:** about half of all hash values end in 0, a quarter end in 00, and so on. A value ending in $r$ zeros has chance $2^{-r}$, so seeing $R$ zeros suggests about $2^R$ different items.

<Sum>

<Given>

stream $S = \{4, 2, 5, 9, 1, 6, 3, 7\}$, hash $h(x) = (3x + 7) \bmod 32$, written as a 5-bit binary number.

</Given>

<Find>

the estimated number of distinct elements.

</Find>

<Steps>

1. **Hash each element and write 5 bits.** Then count trailing zeros:

   | $x$ | $3x + 7$ | mod 32 | 5-bit binary | Trailing zeros |
   |---|---|---|---|---|
   | 4 | 19 | 19 | 10011 | 0 |
   | 2 | 13 | 13 | 01101 | 0 |
   | 5 | 22 | 22 | 10110 | 1 |
   | 9 | 34 | 2 | 00010 | 1 |
   | 1 | 10 | 10 | 01010 | 1 |
   | 6 | 25 | 25 | 11001 | 0 |
   | 3 | 16 | 16 | 10000 | 4 |
   | 7 | 28 | 28 | 11100 | 2 |

2. **Take the maximum** trailing zeros: $R = \max(0,0,1,1,1,0,4,2) = 4$. *Reason: FM keeps only the longest run.*
3. **Estimate** $= 2^R = 2^4 = 16$.

</Steps>

<Answer>

$R = 4$, so the estimated number of distinct elements is $2^4 = 16$.

</Answer>

<Box kind="verify">

Binary check: $19 = 16 + 2 + 1 = 10011$, $13 = 8 + 4 + 1 = 01101$, $22 = 16 + 4 + 2 = 10110$, $2 = 00010$, $10 = 8 + 2 = 01010$, $25 = 16 + 8 + 1 = 11001$, $16 = 10000$, $28 = 16 + 8 + 4 = 11100$. The true number of distinct elements is 8, so one hash overestimates by a factor 2. This is normal: FM with one hash function is rough, and in practice many hash functions are combined (average inside groups, then median of the groups). <Cite id="stream-counting-wiki-fm" />

</Box>

</Sum>

**Conclusion:** the longest run of trailing zeros is $4$, so FM estimates $16$ distinct elements, using memory for just one number.
