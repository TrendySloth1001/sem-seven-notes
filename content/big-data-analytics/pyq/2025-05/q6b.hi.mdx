**In simple words:** CURE (Clustering Using REpresentatives, Guha, Rastogi aur Shim, 1998) bade data ke liye clustering algorithm hai. Wo har cluster ko $c$ **well-scattered points** se represent karta hai, jinhe cluster ke centre ki taraf $\alpha$ fraction khiska diya jaata hai. Kyunki wo ek centre ki jagah kai points use karta hai, wo ajeeb shape aur size ke clusters dhoondh leta hai, aur shrinking use outliers se robust banati hai. <Cite id="cure-stream-clustering-guha1998" loc="§1.2" /> <Cite id="cure-stream-clustering-tp-cure" />

**Kyun chahiye:** k-means aur centroid methods gol, barabar size ke clusters dhoondhte hain aur lambe clusters ko tod dete hain; all-points method bridges ke through chain bana leta hai aur outliers se kharab hota hai. CURE in dono extremes ke beech mein hai.

**Algorithm**

1. **Sample.** Random sample lo jo memory mein aa jaaye.
2. **Sample ko cluster karo** hierarchically: har point apna cluster, aur sabse paas ki jodi merge karte jao jab tak $k$ clusters bachein.
3. Har cluster mein **$c$ well-scattered points chuno**: pehla centroid se sabse door wala, phir har agla unse sabse door jo pehle chune ja chuke hain.
4. Har point ko centroid ki taraf **shrink** karo: $p_{\text{new}} = p + \alpha(\text{centroid} - p)$. Door ke points (outliers) sabse zyada khiskte hain.
5. Un clusters ko **merge** karo jinke representatives ki sabse paas wali jodi sabse paas hai, naye representatives chuno, aur $k$ clusters bachne tak dohrao.
6. Baaki har point ko data ke ek scan mein sabse paas ke representative ke cluster ka **label** do.

<Sum>

<Given>

Chhe points ka ek cluster: $A(1,2)$, $B(3,2)$, $C(5,2)$, $D(9,2)$, $E(4,6)$, $F(2,-2)$. $c = 3$ representatives aur $\alpha = 0.2$ lo.

</Given>

<Find>

centroid, teen scattered points aur representatives.

</Find>

<Steps>

1. **Centroid.** $x$: $(1+3+5+9+4+2)/6 = 4$. $y$: $(2+2+2+2+6-2)/6 = 2$. Centroid $(4,2)$.
2. **Pehla point: centroid se sabse door.** Squared distances: A 9, B 1, C 1, D 25, E 16, F 20. Sabse bada $D(9,2)$.
3. **Doosra: D se sabse door.** D se squared distances: A 64, B 36, C 16, E 41, F 65. Sabse bada $F(2,-2)$.
4. **Teesra: sabse paas ke chune hue point se sabse door.** D aur F se squared distances mein chhota: A 17, B 17, C 16, E 41. Sabse bada $E(4,6)$.
5. **20 percent shrink** karo $p + 0.2(\text{centroid} - p)$ se: D $\to (9 + 0.2 \times (-5), 2) = (8,2)$; F $\to (2 + 0.2 \times 2, -2 + 0.2 \times 4) = (2.4,-1.2)$; E $\to (4, 6 + 0.2 \times (-4)) = (4,5.2)$.

</Steps>

<Answer>

Centroid $(4,2)$; scattered points $D(9,2)$, $F(2,-2)$, $E(4,6)$; representatives $(8,2)$, $(2.4,-1.2)$, $(4,5.2)$.

</Answer>

<Box kind="verify">

Har representative apne point se centroid tak ki line pe hai; E ke liye line $x = 4$ hai aur representative ka $x = 4$ hai. Door wala D 1 unit khiska (5 ka 20 percent), jabki paas wala point kam khiskta. x ka total doosre order mein: $(1+9)+(3+5)+(4+2) = 24$, aur $24/6 = 4$.

</Box>

</Sum>

| Advantages | Disadvantages |
|---|---|
| Kisi bhi shape aur size ke clusters dhoondhta hai | Euclidean space chahiye (centroids use karta hai) |
| Outliers se kam prabhavit | $c$, $\alpha$, sample size aur $k$ pe depend karta hai |
| Sampling aur partitioning se scale hota hai | Chhota cluster sample mein chhoot sakta hai |

<Cite id="cure-stream-clustering-wiki-cure" />

**Conclusion:** CURE sample ko shrunken representative points se cluster karta hai aur phir saare data ko sabse paas ke representative se label karta hai, jisse bade data pe achhe clusters milte hain.
