**In simple words:** traditional data chhota aur neat, table jaisa data hota hai jise ek database server aaram se store aur process kar leta hai. Big data itna bada, itna fast aur itna mixed hota hai ki ek server sambhal nahi paata, isliye use sasste computers ke cluster pe failaya jaata hai. <Cite id="big-data-intro-oracle" /> <Cite id="big-data-intro-gfg" />

| Point | Traditional data | Big data |
|---|---|---|
| Size | Megabytes se kuch terabytes | Terabytes se petabytes aur usse zyada |
| Type | Zyadatar structured (tables) | Structured, semi-structured aur unstructured |
| Schema | Store karne se pehle fixed (schema-on-write) | Flexible, read karte time lagta hai (schema-on-read) |
| Growth | Dheemi aur predictable | Tez aur lagatar |
| Scaling | Scale up: bada, mehenga server | Scale out: bahut saste nodes jodo |
| Processing | Ek machine; data program ke paas jaata hai | Cluster; program data ke paas jaata hai |
| Arrival | Zyadatar batch updates | Batch aur real-time streams |
| Tools | RDBMS, SQL, data warehouse | Hadoop, Spark, NoSQL, Kafka |
| Failure | Server fail hona serious hai | Node fail hona normal hai, copies sambhal leti hain |
| Cost | Mehenga hardware aur licence | Saste hardware, aksar open source |

<Cite id="big-data-intro-av" /> <Cite id="big-data-intro-mmds" />

**Example:** college ka fee register traditional data hai. Ek social media app ka har click, video aur post big data hai.

**Conclusion:** farak sirf size ka nahi hai. Big data mein speed aur alag-alag formats bhi hote hain, isliye ek database server ki jagah distributed tools chahiye.

Exam mein English mein likho: "Traditional data is small, structured and handled by one RDBMS server. Big data is huge, fast and varied, and is handled by a cluster."
