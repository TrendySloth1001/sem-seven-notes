**In simple words:** a distance measure gives a number for how far apart two items are (0 means identical). Big data methods such as clustering, nearest neighbours and similar-item search all need one. Which measure to use depends on what the items are. <Cite id="distance-measures-mmds" loc="§3.5" /> <Cite id="distance-measures-av" />

| Measure | Used for | Idea |
|---|---|---|
| Jaccard | Sets | $1 - \dfrac{\lvert A \cap B \rvert}{\lvert A \cup B \rvert}$, shared items over all items |
| Euclidean ($L_2$) | Points in space | Straight-line distance, $\sqrt{\sum (x_i - y_i)^2}$ |
| Manhattan ($L_1$) | Points in space | Sum of coordinate gaps, $\sum \lvert x_i - y_i \rvert$ |
| Cosine | Vectors, documents | Angle between the vectors, $\cos\theta = \dfrac{x \cdot y}{\lVert x \rVert \lVert y \rVert}$ |
| Edit | Strings | Fewest insertions and deletions to turn one string into the other |
| Hamming | Equal-length strings or bit vectors | Number of positions that differ |

<Sum>

<Given>

Sets $A = \{1,2,3,4\}$, $B = \{3,4,5\}$. Points $p = (1,2)$, $q = (4,6)$. Vectors $u = (1,0,1)$, $v = (1,1,0)$. Strings abcde and acfdeg. Bit strings 10101 and 11001.

</Given>

<Find>

each distance.

</Find>

<Steps>

1. **Jaccard.** Common items: 3 and 4, so 2. All items: 1, 2, 3, 4, 5, so 5. Similarity $2/5 = 0.4$, distance $1 - 0.4 = 0.6$.
2. **Euclidean.** $\sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5$.
3. **Manhattan.** $\lvert 4-1 \rvert + \lvert 6-2 \rvert = 3 + 4 = 7$.
4. **Cosine.** $u \cdot v = 1$, $\lVert u \rVert = \lVert v \rVert = \sqrt{2}$, so $\cos\theta = 1/2$, an angle of $60^\circ$ (or $1 - \cos\theta = 0.5$).
5. **Edit.** The longest common subsequence is acde (4 letters), so distance $= 5 + 6 - 2 \times 4 = 3$.
6. **Hamming.** Positions 2 and 3 differ, so the distance is 2.

</Steps>

<Answer>

Jaccard 0.6, Euclidean 5, Manhattan 7, cosine angle $60^\circ$, edit 3, Hamming 2.

</Answer>

<Box kind="verify">

Euclidean 5 is less than Manhattan 7, as it must be (a straight line is never longer than a walk along the axes). Edit: abcde, delete b, gives acde; insert f gives acfde; insert g gives acfdeg, which is 3 steps.

</Box>

</Sum>

**Conclusion:** Jaccard for sets, cosine for text vectors, Euclidean and Manhattan for numeric points, edit for spelling and Hamming for fixed-length codes.
