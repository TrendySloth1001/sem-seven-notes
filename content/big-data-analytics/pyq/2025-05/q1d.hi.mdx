**In simple words:** distance measure ek number deta hai ki do items kitne door hain (0 ka matlab bilkul same). Clustering, nearest neighbours aur similar-item search jaise big data methods ko iski zarurat padti hai. Kaun sa measure use karna hai, ye is pe depend karta hai ki items kya hain. <Cite id="distance-measures-mmds" loc="§3.5" /> <Cite id="distance-measures-av" />

| Measure | Used for | Idea |
|---|---|---|
| Jaccard | Sets | $1 - \dfrac{\lvert A \cap B \rvert}{\lvert A \cup B \rvert}$, common items / saare items |
| Euclidean ($L_2$) | Space ke points | Seedhi line ki doori, $\sqrt{\sum (x_i - y_i)^2}$ |
| Manhattan ($L_1$) | Space ke points | Coordinate gaps ka sum, $\sum \lvert x_i - y_i \rvert$ |
| Cosine | Vectors, documents | Vectors ke beech ka angle, $\cos\theta = \dfrac{x \cdot y}{\lVert x \rVert \lVert y \rVert}$ |
| Edit | Strings | Ek string ko dusri banane ke liye kam se kam insertions aur deletions |
| Hamming | Barabar length ki strings ya bit vectors | Kitni positions alag hain |

<Sum>

<Given>

Sets $A = \{1,2,3,4\}$, $B = \{3,4,5\}$. Points $p = (1,2)$, $q = (4,6)$. Vectors $u = (1,0,1)$, $v = (1,1,0)$. Strings abcde aur acfdeg. Bit strings 10101 aur 11001.

</Given>

<Find>

har distance.

</Find>

<Steps>

1. **Jaccard.** Common items: 3 aur 4, yani 2. Saare items: 1, 2, 3, 4, 5, yani 5. Similarity $2/5 = 0.4$, distance $1 - 0.4 = 0.6$.
2. **Euclidean.** $\sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5$.
3. **Manhattan.** $\lvert 4-1 \rvert + \lvert 6-2 \rvert = 3 + 4 = 7$.
4. **Cosine.** $u \cdot v = 1$, $\lVert u \rVert = \lVert v \rVert = \sqrt{2}$, to $\cos\theta = 1/2$, yani angle $60^\circ$ (ya $1 - \cos\theta = 0.5$).
5. **Edit.** Longest common subsequence acde hai (4 letters), to distance $= 5 + 6 - 2 \times 4 = 3$.
6. **Hamming.** Position 2 aur 3 alag hain, to distance 2.

</Steps>

<Answer>

Jaccard 0.6, Euclidean 5, Manhattan 7, cosine angle $60^\circ$, edit 3, Hamming 2.

</Answer>

<Box kind="verify">

Euclidean 5 Manhattan 7 se chhota hai, jo hona hi chahiye (seedhi line axes pe chalne se lambi nahi hoti). Edit: abcde, b delete karo to acde; f insert karo to acfde; g insert karo to acfdeg, yani 3 steps.

</Box>

</Sum>

**Conclusion:** sets ke liye Jaccard, text vectors ke liye cosine, numeric points ke liye Euclidean aur Manhattan, spelling ke liye edit aur fixed-length codes ke liye Hamming.
