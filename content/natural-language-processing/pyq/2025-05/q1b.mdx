**In simple words:** **Information Retrieval (IR)** finds the *documents* that are useful for a question, like a search engine. **Information Extraction (IE)** reads text and pulls out *facts* from it (who, what, when, where) and stores them in a structured form such as a table. <Cite id="pyq-2025-05-wiki-ir" /> <Cite id="pyq-2025-05-wiki-ie" />

| Point | Information Retrieval | Information Extraction |
|---|---|---|
| Goal | Find relevant documents | Find specific facts inside documents |
| Input | A query and a large collection | A document or text stream |
| Output | A ranked list of documents | Structured records (entity, relation, event) |
| Main steps | Indexing, query matching, ranking (TF-IDF, BM25) | Named entity recognition, relation and event extraction, template filling |
| Language understanding | Shallow, mostly keywords and statistics | Deeper, needs grammar and meaning |
| Domain | Open, works for any topic | Usually tied to a domain and fixed templates |
| Measured by | Precision, recall, ranking quality | Precision, recall and F-score of extracted facts |
| Example | Google search "monsoon in Mumbai 2024" | From a news line, extract *Company = Tata, Event = acquisition, Date = 2024* |

<Cite id="pyq-2025-05-gfg-ir-ie" />

**How they work together:** a system first uses IR to fetch the few relevant documents, then IE reads only those to fill a database. This is how question answering and news monitoring tools work.

**Conclusion:** IR answers "which documents?" and IE answers "what does the text say?"; IR is wide and shallow, IE is narrow and deep.
