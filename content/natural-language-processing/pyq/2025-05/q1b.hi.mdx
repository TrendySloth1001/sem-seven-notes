**In simple words:** **Information Retrieval (IR)** question ke liye kaam ke *documents* dhoondhta hai, jaise search engine. **Information Extraction (IE)** text padhkar usme se *facts* nikalta hai (who, what, when, where) aur unhe structured form mein, jaise table mein, rakhta hai. <Cite id="pyq-2025-05-wiki-ir" /> <Cite id="pyq-2025-05-wiki-ie" />

| Point | Information Retrieval | Information Extraction |
|---|---|---|
| Goal | Relevant documents dhoondhna | Documents ke andar se specific facts dhoondhna |
| Input | Ek query aur bada collection | Ek document ya text stream |
| Output | Documents ki ranked list | Structured records (entity, relation, event) |
| Main steps | Indexing, query matching, ranking (TF-IDF, BM25) | Named entity recognition, relation aur event extraction, template filling |
| Language understanding | Shallow, mostly keywords aur statistics | Deeper, grammar aur meaning chahiye |
| Domain | Open, kisi bhi topic pe chalta hai | Aksar ek domain aur fixed templates tak limited |
| Measured by | Precision, recall, ranking quality | Extract kiye facts ka precision, recall aur F-score |
| Example | Google search "monsoon in Mumbai 2024" | News line se nikalo: *Company = Tata, Event = acquisition, Date = 2024* |

<Cite id="pyq-2025-05-gfg-ir-ie" />

**Dono saath mein kaise chalte hain:** system pehle IR se kuch relevant documents laata hai, phir IE sirf unhe padhkar database bharta hai. Question answering aur news monitoring tools aise hi chalte hain.

**Conclusion:** IR batata hai "kaun se documents?" aur IE batata hai "text kya kehta hai?"; IR wide aur shallow hai, IE narrow aur deep.

Exam mein English mein likho: "IR retrieves relevant documents; IE extracts structured facts from them."
