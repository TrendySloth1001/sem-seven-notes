**In simple words:** both models tag each word in a sentence (noun, verb ...), and both have weak points. <Cite id="hmm-maxent-crf-slp3-ch18" loc="§18.5" /> <Cite id="hmm-maxent-crf-gfg-hmm-ml" />

**Limitations of HMM:**

1. **Hard to add clues.** It has only two tables, tag-to-tag and tag-to-word. Clues like "starts with a capital letter" or "ends in -ed" do not fit.
2. **Unknown words.** A word never seen in training has probability 0 under every tag, so the path dies unless a guess is added.
3. **Strong independence assumptions.** A tag depends only on the previous tag, and a word only on its own tag.
4. **Zero counts.** Unseen tag pairs need smoothing.
5. **Generative.** It models how words are produced, not directly the best tags.
6. Needs a large tagged corpus.

**Limitations of MaxEnt:**

1. **Label bias.** Each step is normalised alone, so a tag with few choices ignores the word. Later words cannot fix an early mistake. <Cite id="hmm-maxent-crf-wiki-memm" /> <Cite id="hmm-maxent-crf-lafferty2001" />
2. **Trained with the true previous tag**, but at test time that tag is a guess, so errors pile up.
3. **Features are written by hand**, and many features make training slow.
4. Not generative, so it cannot use unlabelled text.

| | HMM | MaxEnt |
|---|---|---|
| Type | Generative | Discriminative |
| Extra clues | Hard | Easy |
| Main weakness | Unknown words, independence | Label bias |

**Conclusion:** HMM is simple but rigid; MaxEnt is flexible but suffers label bias, which CRF fixes.
