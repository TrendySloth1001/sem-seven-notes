**In simple words:** morphological analysis root word aur uski grammar batane wale tags deta hai. Output lemma (root) + morphological tags hota hai. <Cite id="class-nlp-pyq2" loc="p. 9" />

| Word type | Input word | Morphological analysis (output) |
|---|---|---|
| Regular verb | walked | walk + V + Past |
| Irregular verb | went | go + V + Past |
| Singular noun | cat | cat + N + Sg |
| Plural noun | cats | cat + N + Pl |

- walked: walk root hai, V matlab verb, Past matlab past tense.
- went: surface form alag hai, par lemma go hai, isliye irregular forms ko lexical information (dictionary) chahiye.
- cat: noun, singular. cats: cat root hai, Pl matlab plural.

**Conclusion:** analysis = root + tags.
