**In simple words:** Natural Language Processing (NLP) lets computers read, understand and write human language such as English or Hindi. Because people talk and type all day, NLP is used almost everywhere. <Cite id="nlp-introduction-ibm-nlp" /> <Cite id="nlp-introduction-av-apps" />

**Main applications:**

| Application | What it does | Everyday example |
|---|---|---|
| Machine translation | Converts text from one language to another. <Cite id="nlp-applications-gfg-mt" /> | Google Translate |
| Information retrieval and search | Finds the documents that match a query. | Google search |
| Question answering and chatbots | Answers a question in natural language. | Customer-care bot, voice assistant |
| Sentiment analysis | Finds whether a text is positive, negative or neutral. | Product review analysis |
| Text summarization | Shortens a long text but keeps the main points. | News digest |
| Information extraction and NER | Pulls out names, places, dates and facts. <Cite id="pyq-2024-12-gfg-ner" /> | Reading names from a resume |
| Speech recognition and synthesis | Turns speech into text and text into speech. | Siri, Alexa |
| Spelling and grammar correction | Fixes mistakes while typing. | Auto-correct, Grammarly |
| Spam filtering and text classification | Sorts mail or news into classes. | Gmail spam folder |

**Why it matters:** it saves human effort, works day and night, and lets people use computers in their own language.

**Limitation:** language is ambiguous, so the output is sometimes wrong, for example in sarcasm or in a rare language.

**Conclusion:** NLP powers translation, search, chatbots, sentiment analysis, summaries and speech tools that we use every day.
