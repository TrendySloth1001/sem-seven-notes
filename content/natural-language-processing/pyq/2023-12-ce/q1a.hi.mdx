**In simple words:** rule-based tagger logon ke likhe rules follow karta hai; stochastic tagger tagged corpus se gine gaye probabilities follow karta hai.

**Rule-based tagger:** ye predefined grammatical rules se POS tags deta hai. Rules morphological features (jaise word endings) aur syntactic context se banaye jaate hain, isliye ye approach bahut interpretable aur transparent hai. <Cite id="class-nlp-pyq3" loc="p. 3" />

*Example:* rule "-tion ya -ment par khatam hone wale words ko Noun tag do". "The presentation highlighted the key achievements of the project's development" mein *presentation* aur *development* (aur *achievements*) is rule se noun ban jaate hain; *highlighted* ke liye alag rule chahiye (jaise -ed par khatam hone wala word verb hai). <Cite id="class-nlp-pyq3" loc="p. 3" /> <Cite id="class-nlp-pyq3" loc="p. 4" />

**Stochastic (statistical) tagger:** ye tagged corpus se seekhe probabilities use karta hai aur sabse probable tag ya tag sequence chunta hai. Hidden Markov Model (HMM) transition aur emission probabilities use karta hai, aur Maximum Entropy model context ke weighted features. <Cite id="class-nlp-pyq3" loc="p. 2" /> <Cite id="class-nlp-pyq3" loc="p. 8" />

| Point | Rule-based | Stochastic |
|---|---|---|
| Knowledge kahan se | Haath se likhe rules | Tagged corpus ki counting |
| Samajhna aasaan | Haan, bahut | Kam |
| Mehnat | Experts ko rules likhne padte hain | Bada tagged corpus chahiye |
| Example | Suffix rule (-tion matlab noun) | HMM, MaxEnt |

**Conclusion:** rules saaf aur check karne layak tagging dete hain; statistics data se seekhti hai.
