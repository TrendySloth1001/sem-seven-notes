**In simple words:** POS tagging har word ko ek tag (noun, verb, adjective wagairah) deta hai. Ye aasan lagta hai, lekin tagger ko kai problems milti hain. Sabse badi ye hai ki ek word ke kai tags ho sakte hain, aur sahi tag sirf context se pata chalta hai. <Cite id="pos-tagging-slp3-ch18" /> <Cite id="pos-tagging-gfg-pos" />

**1. Ambiguity (main challenge).** Bahut se common words ke ek se zyada tags hote hain. *Book* "read a **book**" mein noun hai aur "**book** a ticket" mein verb. Brown corpus mein word tokens ka bada hissa ambiguous hai, jabki zyadatar word types nahi hain. "Time flies like an arrow" ko kai tarah tag kiya ja sakta hai: *flies* verb ya noun, *like* verb ya preposition. <Cite id="pos-tagging-wiki-pos-tagging" />

**2. Unknown words.** Names, naye words (*selfie*), slang, typing mistakes aur technical terms training data mein nahi hote, isliye tagger ke paas unke counts nahi hote. Capital letters, suffixes (*-ing*, *-ly*, *-tion*) aur context ke clues use hote hain.

**3. Multi-word expressions aur idioms.** "in spite of", "New York", "kick the bucket" ek unit ki tarah kaam karte hain, lekin word-by-word tagger har word ko alag tag karta hai.

**4. Tag set aur annotation problems.** Tag sets ka size alag hota hai (Penn Treebank mein 45, Universal Dependencies mein 17) aur ek pe train model doosre ke saath use nahi ho sakta. Mushkil cases mein insaan annotators bhi disagree karte hain, isliye "gold" data mein errors hote hain; accuracy lagbhag 97 se 98 percent pe cap ho jati hai. <Cite id="pos-tagging-tp-pos" />

**5. Data sparsity aur domain change.** News pe train tagger tweets, medical text ya Hinglish pe kharab chalta hai. Rare word-tag pairs ke counts bahut kam hote hain.

**6. Long-distance context.** Simple HMM sirf pichle ek ya do tags dekhta hai, lekin kabhi clue door hota hai ("The horse raced past the barn fell").

**7. Free word order ya rich morphology wali languages** (Hindi, Turkish) mein bahut word forms hote hain, isliye har form ka data kam hota hai aur word order se kam hints milte hain.

| Challenge | Example | Common remedy |
|---|---|---|
| Ambiguity | book (noun or verb) | Context, HMM, CRF |
| Unknown words | selfie | Suffix and capital-letter features |
| Multi-word units | in spite of | Treat as one token |
| Different tag sets | 45 vs 17 tags | Map between tag sets |
| Domain shift | news vs tweets | Train on matching data |

**Conclusion:** ambiguity, unknown words aur limited context core challenges hain; behtar tagging context, word-shape features aur same domain ke training data se hoti hai.
