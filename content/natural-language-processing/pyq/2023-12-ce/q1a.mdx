**In simple words:** a rule-based tagger follows rules written by people; a stochastic tagger follows probabilities counted from a tagged corpus.

**Rule-based tagger:** it assigns POS tags using predefined grammatical rules. The rules are crafted from morphological features (like word endings) and syntactic context, so the approach is highly interpretable and transparent. <Cite id="class-nlp-pyq3" loc="p. 3" />

*Example:* rule "assign the tag Noun to words ending in -tion or -ment". In "The presentation highlighted the key achievements of the project's development", *presentation* and *development* (and *achievements*) become nouns by this rule; *highlighted* needs another rule (for example, a word ending in -ed is a verb). <Cite id="class-nlp-pyq3" loc="p. 3" /> <Cite id="class-nlp-pyq3" loc="p. 4" />

**Stochastic (statistical) tagger:** it uses probabilities learned from a tagged corpus and chooses the most probable tag or tag sequence. The Hidden Markov Model (HMM) uses transition and emission probabilities, and the Maximum Entropy model uses weighted features of the context. <Cite id="class-nlp-pyq3" loc="p. 2" /> <Cite id="class-nlp-pyq3" loc="p. 8" />

| Point | Rule-based | Stochastic |
|---|---|---|
| Knowledge from | Hand-written rules | Counts in a tagged corpus |
| Easy to understand | Yes, very | Less |
| Effort | Experts must write rules | Needs a large tagged corpus |
| Example | Suffix rule (-tion gives noun) | HMM, MaxEnt |

**Conclusion:** rules give clear, checkable tagging; statistics learn from data.
