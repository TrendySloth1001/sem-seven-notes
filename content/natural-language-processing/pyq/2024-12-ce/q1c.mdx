**In simple words:** rule-based machine translation (RBMT) translates with rules written by language experts, not with learning from data. <Cite id="class-nlp-m6" loc="slide 3" />

**Definition:** RBMT uses manually created grammar rules, bilingual dictionaries and linguistic information to translate text. The system analyzes the structure of the source sentence and applies predefined rules to generate the target-language sentence. Common techniques: grammar rules, bilingual dictionaries, morphological analysis and transfer rules.

<Img id="class-nlp-applications-rbmt-cycle" caption="RBMT cycle: rule creation, rule application, rule processing, rule refinement, and back to rule application." />

**Working (the teacher's cycle):** (1) **rule creation:** experts write the rules; (2) **rule application:** the rules are applied to the source sentence; (3) **rule processing:** the result is processed into the target sentence; (4) **rule refinement:** the rules are improved from the errors, and the cycle repeats. <Cite id="class-nlp-m6" loc="slide 3" />

**Limits:** every rule is written by hand, so it is slow to build and hard to scale (this limit is common knowledge and not on the slide).

**Conclusion:** RBMT is the oldest approach; statistical and neural methods replaced it for most work.
