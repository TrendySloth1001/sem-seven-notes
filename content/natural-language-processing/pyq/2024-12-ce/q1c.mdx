**In simple words:** a rule-based machine translation (RBMT) system translates text with hand-written grammar rules and bilingual dictionaries made by language experts. It uses no training data. <Cite id="nlp-applications-wiki-rbmt" />

**Three types** <Cite id="nlp-applications-gfg-mt" />

1. **Direct:** replace each source word using a dictionary, then reorder words with a few rules. Simple but crude.
2. **Transfer:** analyse the source sentence into a parse, apply transfer rules to change it to the target structure, then generate the target words.
3. **Interlingua:** convert the sentence to a language-free meaning, then generate the target language from it.

**Example (English to Hindi):** "I eat apples" has the order subject, verb, object. Hindi needs subject, object, verb, so a transfer rule reorders it to *main seb khata hoon* ("I apples eat").

| Advantages | Disadvantages |
|---|---|
| Predictable, rules can be inspected | Writing rules is slow and costly |
| Needs no big parallel corpus | Cannot cover all exceptions and idioms |
| Good for related languages | Hard to scale to new language pairs |

**Conclusion:** RBMT translates using linguistic rules and dictionaries; it is accurate for the cases covered, but statistical and neural systems replaced it for general use. <Cite id="nlp-applications-slp3-13" />
