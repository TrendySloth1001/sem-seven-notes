**In simple words:** a prime number is bigger than 1 and divisible only by 1 and itself. To test a number n, we try dividing it by 2, 3, 4 and so on. If any of them divides it exactly, it is not prime. We only need to try divisors up to the square root of n, because a bigger divisor always comes with a smaller one. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract PrimeCheck {
    function isPrime(uint n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        for (uint i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
}
```

**Line by line:**

- `pragma solidity ^0.8.0;` means compile with version 0.8.0 or a newer 0.8.x. The `SPDX` line only states the licence.
- `contract PrimeCheck` is the container for our code, like a class.
- `function isPrime(uint n) public pure returns (bool)` takes one whole number `n` and gives back true or false. `public` means anyone can call it. `pure` means it reads and writes no blockchain data, so calling it costs no gas. <Cite id="solidity-docs-types" />
- `if (n < 2) return false;` because 0 and 1 are not prime.
- The `for` loop starts with `i = 2` and runs while `i * i <= n`, that is, while `i` is not above the square root of `n`.
- `n % i == 0` means the remainder is zero, so `i` divides `n` and `n` is not prime. We return `false` at once.
- If the loop ends without finding a divisor, we return `true`.

<Box kind="verify">

**Call `isPrime(29)`:** i = 2, 4 ≤ 29, 29 % 2 = 1. i = 3, 9 ≤ 29, 29 % 3 = 2. i = 4, 16 ≤ 29, 29 % 4 = 1. i = 5, 25 ≤ 29, 29 % 5 = 4. i = 6, 36 > 29, the loop stops. Returns **true**, and 29 is prime.

**Call `isPrime(21)`:** i = 2 gives remainder 1. i = 3 gives 21 % 3 = 0, so it returns **false**, and 21 = 3 x 7. `isPrime(1)` and `isPrime(0)` return false at the first check.

Compiled without errors with solc 0.8.38.

</Box>

**Note:** the loop runs about the square root of n times, which is cheap for small numbers. <Cite id="solidity-gfg-intro" /> <Cite id="solidity-by-example" />
