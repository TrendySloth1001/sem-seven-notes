**In simple words:** Bitcoin is digital money. Ethereum is a computer on the blockchain that can run programs, and it also has its own money (ether). Mining difficulty is how hard it is to find a valid block hash in Bitcoin.

**Comparison of Bitcoin and Ethereum:**

| Point | Bitcoin | Ethereum |
|---|---|---|
| Purpose | Peer-to-peer digital cash | Platform for smart contracts and dApps |
| Creator | Satoshi Nakamoto (2009) | Vitalik Buterin and others (2015) |
| Coin | BTC | ETH (ether) |
| Consensus | Proof of Work (SHA-256) | Proof of Stake since the Merge (September 2022) |
| Block time | About 10 minutes | 12-second slots |
| Data model | UTXO | Account model with a world state |
| Programming | Limited Script | Solidity, Turing-complete EVM |
| Fees | Fee per byte of transaction | Gas used x gas price |
| Supply | Capped at 21 million | No fixed cap |

**Mining difficulty in Bitcoin.** A miner must find a nonce so that the block hash is **below a target number**. A smaller target means fewer valid hashes, so it is harder. Difficulty compares the current target with the easiest possible target (target_1):

$$
\text{Difficulty} = \frac{\text{target}_1}{\text{current target}}
$$

To keep a block about every 10 minutes whatever the total hash power, the network **retargets every 2016 blocks** (about 2 weeks, since 2016 x 10 min = 14 days):

$$
\text{new difficulty} = \text{old difficulty} \times \frac{14\ \text{days}}{\text{actual time for the last 2016 blocks}}
$$

If blocks came faster than 10 minutes, difficulty goes up. If slower, it goes down. A single change is limited to a factor of 4. On average a miner needs about difficulty x 2^32 hashes to find one block. <Cite id="bitcoin-btcwiki-difficulty" /> <Cite id="bitcoin-mb-ch12-mining" />

<Sum>

<Given>

old difficulty $= 1{,}000{,}000$; the last 2016 blocks took 10 days instead of the planned 14 days.

</Given>

<Find>

the new difficulty and the average number of hashes per block.

</Find>

<Steps>

1. Blocks came too fast, so difficulty must rise. *Reason: 10 days is less than 14 days.*
2. Ratio $= 14 / 10 = 1.4$. *Reason: planned time divided by actual time.*
3. New difficulty $= 1{,}000{,}000 \times 1.4 = 1{,}400{,}000$.
4. Hashes per block $\approx 1{,}400{,}000 \times 2^{32} = 1{,}400{,}000 \times 4{,}294{,}967{,}296 \approx 6.01 \times 10^{15}$. *Reason: each unit of difficulty needs about $2^{32}$ hashes.*

</Steps>

<Answer>

new difficulty $= 1{,}400{,}000$, and about $6.01 \times 10^{15}$ hashes per block.

</Answer>

<Box kind="verify">

If the same miners keep working, blocks now take $10 \times 1.4 = 14$ days for 2016 blocks, which is the planned time. The ratio 1.4 is also within the allowed limit of 4.

</Box>

</Sum>

**Conclusion:** Bitcoin is a simple, secure money network; Ethereum is a programmable platform. Bitcoin keeps its pace by changing difficulty every 2016 blocks.
