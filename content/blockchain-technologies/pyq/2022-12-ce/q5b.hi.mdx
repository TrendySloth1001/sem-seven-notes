**In simple words:** array numbered boxes ki ek row hai jisme sab boxes mein same type ki value hoti hai. **Fixed-size array** ki length code likhte waqt decide hoti hai aur kabhi nahi badalti. **Dynamic array** contract chalte waqt badh aur ghat sakta hai. <Cite id="solidity-docs-types" />

| Point | Fixed-size array | Dynamic array |
|---|---|---|
| Declaration | `uint[3] a;` | `uint[] b;` |
| Length | Compile time pe set | Run time pe badalti hai |
| Add or remove | Possible nahi | `push()` aur `pop()` (storage arrays) |
| Gas | Sasta, size known | Length ke saath badhta hai |
| Index | 0 se start, length se chhota hona chahiye | Same |

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ArrayDemo {
    uint[3] public fixedArr = [10, 20, 30];
    uint[] public dynArr;

    function setFixed(uint index, uint value) public {
        fixedArr[index] = value;
    }

    function addDynamic(uint value) public {
        dynArr.push(value);
    }

    function removeLast() public {
        dynArr.pop();
    }

    function dynLength() public view returns (uint) {
        return dynArr.length;
    }

    function memoryArray() public pure returns (uint[] memory) {
        uint[] memory temp = new uint[](3);
        temp[0] = 1;
        temp[1] = 2;
        temp[2] = 3;
        return temp;
    }
}
```

**Line by line:**

- `uint[3] public fixedArr = [10, 20, 30];` exactly 3 numbers ka fixed array hai, starting values ke saath. `public` se Solidity ek getter `fixedArr(i)` bana deta hai jo ek item padhta hai.
- `uint[] public dynArr;` dynamic array hai jo khaali start hota hai.
- `setFixed` ek item badalta hai. Index 3 ya usse zyada fail hota hai, kyunki length fixed hai.
- `push(value)` end mein item add karke array lamba kar deta hai. `pop()` aakhri item hata deta hai. `length` count deta hai. Yeh sirf dynamic storage arrays pe kaam karte hain.
- `memoryArray` dikhata hai ki function ke andar ke array (`memory`) pe `push` nahi chalta, isliye size `new uint[](3)` se set karna padta hai. <Cite id="solidity-docs-datalocation" />

<Box kind="verify">

**Start:** `fixedArr(1)` returns **20**. `dynLength()` returns **0**.

**`addDynamic(5)` aur `addDynamic(8)` call karo:** `dynLength()` returns **2**, aur `dynArr(1)` returns **8**. **`removeLast()` call karo:** `dynLength()` returns **1**.

**`setFixed(2, 99)` call karo:** `fixedArr(2)` returns **99**. **`setFixed(3, 1)` call karo:** yeh revert hota hai, kyunki length-3 array ke liye index 3 range ke bahar hai.

Compiled without errors with solc 0.8.38.

</Box>

**Conclusion:** size pata ho to fixed array use karo, aur list badhti ho to dynamic array. <Cite id="solidity-gfg-arrays" /> <Cite id="solidity-tp-arrays" />

Exam mein English mein likho: "A fixed-size array has a length set at compile time, while a dynamic array can change length at run time using push and pop."
