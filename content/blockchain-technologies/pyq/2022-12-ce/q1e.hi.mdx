**In simple words:** prime number 1 se bada hota hai aur sirf 1 aur khud se divide hota hai. Number n ko test karne ke liye hum use 2, 3, 4 aur aage se divide karke dekhte hain. Koi bhi exactly divide kare to woh prime nahi hai. Hume sirf n ke square root tak divisors try karne hain, kyunki bada divisor hamesha ek chhote divisor ke saath aata hai. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract PrimeCheck {
    function isPrime(uint n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        for (uint i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
}
```

**Line by line:**

- `pragma solidity ^0.8.0;` ka matlab version 0.8.0 ya usse naye 0.8.x se compile karo. `SPDX` line sirf licence batati hai.
- `contract PrimeCheck` hamare code ka container hai, class jaisa.
- `function isPrime(uint n) public pure returns (bool)` ek whole number `n` leta hai aur true ya false deta hai. `public` ka matlab koi bhi call kar sakta hai. `pure` ka matlab blockchain ka koi data read ya write nahi hota, isliye call karne mein gas nahi lagti. <Cite id="solidity-docs-types" />
- `if (n < 2) return false;` kyunki 0 aur 1 prime nahi hain.
- `for` loop `i = 2` se start hota hai aur jab tak `i * i <= n` chalta hai, yaani jab tak `i` `n` ke square root se upar na jaye.
- `n % i == 0` ka matlab remainder zero hai, to `i` `n` ko divide karta hai aur `n` prime nahi hai. Hum turant `false` return karte hain.
- Loop bina divisor mile khatam ho jaye to `true` return karte hain.

<Box kind="verify">

**Call `isPrime(29)`:** i = 2, 4 ≤ 29, 29 % 2 = 1. i = 3, 9 ≤ 29, 29 % 3 = 2. i = 4, 16 ≤ 29, 29 % 4 = 1. i = 5, 25 ≤ 29, 29 % 5 = 4. i = 6, 36 > 29, loop ruk jaata hai. Returns **true**, aur 29 prime hai.

**Call `isPrime(21)`:** i = 2 pe remainder 1. i = 3 pe 21 % 3 = 0, to returns **false**, aur 21 = 3 x 7. `isPrime(1)` aur `isPrime(0)` pehle check pe hi false return karte hain.

Compiled without errors with solc 0.8.38.

</Box>

**Note:** loop lagbhag n ke square root baar chalta hai, jo chhote numbers ke liye sasta hai. <Cite id="solidity-gfg-intro" /> <Cite id="solidity-by-example" />

Exam mein English mein likho: "The function checks divisors from 2 up to the square root of n and returns false if any divides n."
