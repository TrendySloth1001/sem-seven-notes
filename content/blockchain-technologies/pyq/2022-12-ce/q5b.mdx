**In simple words:** an array is a numbered row of boxes that all hold the same type of value. A **fixed-size array** has its length decided when you write the code and it never changes. A **dynamic array** can grow and shrink while the contract runs. <Cite id="solidity-docs-types" />

| Point | Fixed-size array | Dynamic array |
|---|---|---|
| Declaration | `uint[3] a;` | `uint[] b;` |
| Length | Set at compile time | Changes at run time |
| Add or remove | Not possible | `push()` and `pop()` (storage arrays) |
| Gas | Cheaper, known size | Grows with length |
| Index | Starts at 0, must be less than length | Same |

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ArrayDemo {
    uint[3] public fixedArr = [10, 20, 30];
    uint[] public dynArr;

    function setFixed(uint index, uint value) public {
        fixedArr[index] = value;
    }

    function addDynamic(uint value) public {
        dynArr.push(value);
    }

    function removeLast() public {
        dynArr.pop();
    }

    function dynLength() public view returns (uint) {
        return dynArr.length;
    }

    function memoryArray() public pure returns (uint[] memory) {
        uint[] memory temp = new uint[](3);
        temp[0] = 1;
        temp[1] = 2;
        temp[2] = 3;
        return temp;
    }
}
```

**Line by line:**

- `uint[3] public fixedArr = [10, 20, 30];` is a fixed array of exactly 3 numbers with starting values. `public` makes Solidity create a getter `fixedArr(i)` to read one item.
- `uint[] public dynArr;` is a dynamic array that starts empty.
- `setFixed` changes one item. An index of 3 or more fails, because the length is fixed.
- `push(value)` adds an item at the end and makes the array longer. `pop()` removes the last item. `length` gives the count. These work only on dynamic storage arrays.
- `memoryArray` shows that an array inside a function (`memory`) cannot use `push`, so its size must be set with `new uint[](3)`. <Cite id="solidity-docs-datalocation" />

<Box kind="verify">

**Start:** `fixedArr(1)` returns **20**. `dynLength()` returns **0**.

**Call `addDynamic(5)` and `addDynamic(8)`:** `dynLength()` returns **2**, and `dynArr(1)` returns **8**. **Call `removeLast()`:** `dynLength()` returns **1**.

**Call `setFixed(2, 99)`:** `fixedArr(2)` returns **99**. **Call `setFixed(3, 1)`:** it reverts, since index 3 is out of range for a length-3 array.

Compiled without errors with solc 0.8.38.

</Box>

**Conclusion:** use fixed arrays when the size is known, and dynamic arrays when the list grows. <Cite id="solidity-gfg-arrays" /> <Cite id="solidity-tp-arrays" />
