**In simple words:** second largest element wo sabse bada value hai jo largest se chhota ho. Hum array ko ek baar padhte hain aur do numbers yaad rakhte hain: ab tak ka largest aur ab tak ka second largest. Har naya element inme se kisi ko replace kar sakta hai. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SecondLargest {
    function secondLargest(uint[] memory arr) public pure returns (uint) {
        require(arr.length >= 2, "Need at least 2 elements");

        uint largest = arr[0];
        uint second = 0;
        bool hasSecond = false;

        for (uint i = 1; i < arr.length; i++) {
            uint v = arr[i];
            if (v > largest) {
                second = largest;
                largest = v;
                hasSecond = true;
            } else if (v < largest && (!hasSecond || v > second)) {
                second = v;
                hasSecond = true;
            }
        }

        require(hasSecond, "All elements are equal");
        return second;
    }
}
```

**Line by line:**

- `pragma solidity ^0.8.0;` matlab compiler version 0.8.0 ya usse naya 0.8.x. `SPDX` line sirf licence batati hai.
- `function secondLargest(uint[] memory arr) public pure returns (uint)` whole numbers ka array leta hai. `memory` matlab temporary copy. `pure` matlab ye blockchain ko touch nahi karta, isliye call karne pe gas nahi lagta. <Cite id="solidity-docs-types" />
- `require(arr.length >= 2, ...)` do se kam items hon to error deke ruk jaata hai, kyunki tab second largest hota hi nahi.
- `largest = arr[0]` pehle item ko largest maan ke shuru karte hain. `second` 0 se shuru hota hai aur `hasSecond` false hai, matlab "abhi tak second value nahi mili". Ye flag isliye chahiye kyunki 0 bhi array ki real value ho sakti hai.
- Loop `i = 1` se shuru hota hai aur har item `v` ko dekhta hai.
- Agar `v > largest`, to purana largest second ban jaata hai, aur `v` naya largest.
- Warna agar `v < largest` aur (abhi second nahi hai, ya `v`, `second` se bada hai), to `v` second ban jaata hai. Jo items `largest` ke barabar hain wo skip hote hain, isliye repeated maximum second nahi ginta.
- Aakhri `require` error deta hai agar saare items barabar the. Warna `second` return hota hai.

<Box kind="verify">

**`secondLargest([10, 5, 20, 8])` call karo:** largest = 10, hasSecond = false se shuru.

1. v = 5: 10 se bada nahi, 10 se chhota hai aur abhi second nahi hai, to second = 5.
2. v = 20: 10 se bada hai, to second = 10 aur largest = 20.
3. v = 8: 20 se chhota hai lekin second (10) se bada nahi, to kuch nahi badla.

Returns **10**, jo sahi hai (sorted: 5, 8, 10, 20).

**`secondLargest([7, 7, 3])` call karo:** doosra 7 largest ke barabar hai, to skip. Phir v = 3 se second = 3 hota hai. Returns **3**. **`[4, 4]` call karo:** hasSecond false hi rehta hai, to "All elements are equal" ke saath revert hota hai.

solc 0.8.38 se bina error ke compile hua.

</Box>
