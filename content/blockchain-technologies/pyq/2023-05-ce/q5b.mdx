**In simple words:** an array is a numbered list of items of the same type, counted from index 0. A **fixed-size array** has a length written in the code and it never changes, like a train with exactly 3 coaches. A **dynamic array** has no fixed length and can grow or shrink, like a queue that people join and leave. <Cite id="solidity-docs-types" />

**Fixed-size array:** written `T[k]`, for example `uint[3]`. The length `k` is known when the code is compiled. Items can be changed, but items cannot be added or removed. It has `.length` but no `push` or `pop`.

**Dynamic array:** written `T[]`, for example `uint[]`. It starts empty. In storage it has `push(x)` to add an item at the end, `pop()` to remove the last item, and `.length`. <Cite id="solidity-gfg-arrays" />

**Memory arrays:** inside a function, an array can live in `memory` (temporary). Its size is chosen once with `new uint[](n)` and then cannot change, so there is no `push` on a memory array. <Cite id="solidity-docs-datalocation" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ArrayDemo {
    // Fixed-size array: length 3, can never change
    uint[3] public fixedArr = [10, 20, 30];

    // Dynamic array: starts empty, can grow and shrink
    uint[] public dynamicArr;

    function setFixed(uint index, uint value) public {
        fixedArr[index] = value;
    }

    function sumFixed() public view returns (uint total) {
        for (uint i = 0; i < fixedArr.length; i++) {
            total += fixedArr[i];
        }
    }

    function addToDynamic(uint value) public {
        dynamicArr.push(value);
    }

    function removeLast() public {
        dynamicArr.pop();
    }

    function lengthOfDynamic() public view returns (uint) {
        return dynamicArr.length;
    }

    function getDynamic() public view returns (uint[] memory) {
        return dynamicArr;
    }

    // Memory arrays: temporary, fixed length chosen when created
    function squares(uint n) public pure returns (uint[] memory) {
        uint[] memory arr = new uint[](n);
        for (uint i = 0; i < n; i++) {
            arr[i] = i * i;
        }
        return arr;
    }
}
```

**Line by line:**

- `pragma solidity ^0.8.0;` means compiler 0.8.0 or a newer 0.8.x.
- `uint[3] public fixedArr = [10, 20, 30];` is the fixed array with 3 items. `public` makes Solidity create a getter `fixedArr(i)`.
- `uint[] public dynamicArr;` is the dynamic array. It is empty at the start and lives in **storage**, which is kept on the blockchain and costs gas.
- `setFixed` changes one item. If `index` is 3 or more, the call fails (reverts), because fixed arrays cannot grow.
- `sumFixed` loops over all items and adds them into `total`, which starts at 0. `view` means it only reads.
- `addToDynamic` uses `push` to add an item. `removeLast` uses `pop`, which fails on an empty array.
- `lengthOfDynamic` returns `.length`. `getDynamic` returns a temporary copy of the whole array.
- `squares` makes a memory array of size `n` and fills it by index (`i * i`). `pure` means it does not touch the blockchain.

<Box kind="verify">

**Example run (fresh deployment):**

1. `fixedArr(1)` returns 20. `sumFixed()` returns 10 + 20 + 30 = 60.
2. `setFixed(1, 50)` then `sumFixed()` returns 10 + 50 + 30 = 90. `setFixed(3, 1)` reverts.
3. `addToDynamic(5)` and `addToDynamic(7)` make `dynamicArr` = [5, 7], so `lengthOfDynamic()` returns 2.
4. `removeLast()` leaves [5] and the length is 1.
5. `squares(4)` returns [0, 1, 4, 9].

Compiled without errors with solc 0.8.38.

</Box>

| Point | Fixed-size `T[k]` | Dynamic `T[]` |
|---|---|---|
| Length | Set in code, never changes | Changes at run time |
| `push` / `pop` | Not available | Available (storage arrays) |
| Declaration | `uint[3] a;` | `uint[] a;` |
| Gas | Cheaper, size known | Grows with each item |
| Use when | Size is known (days of week) | Size is not known (list of users) |

**Conclusion:** use a fixed array when the size never changes, and a dynamic array when the list must grow. Memory arrays are temporary and have a fixed size once created. <Cite id="solidity-tp-arrays" />
