**In simple words:** array ek numbered list hai same type ke items ki, index 0 se ginti shuru hoti hai. **Fixed-size array** ki length code mein likhi hoti hai aur kabhi nahi badalti, jaise ek train jisme exactly 3 coaches hain. **Dynamic array** ki fixed length nahi hoti, wo badh ya ghat sakta hai, jaise queue jisme log judte aur jaate rehte hain. <Cite id="solidity-docs-types" />

**Fixed-size array:** `T[k]` likhte hain, jaise `uint[3]`. Length `k` compile time pe pata hoti hai. Items badle ja sakte hain, lekin items add ya remove nahi ho sakte. Isme `.length` hai lekin `push` ya `pop` nahi. 

**Dynamic array:** `T[]` likhte hain, jaise `uint[]`. Ye khaali se shuru hota hai. Storage mein ismein `push(x)` hai (end mein item jodne ke liye), `pop()` (aakhri item hatane ke liye) aur `.length`. <Cite id="solidity-gfg-arrays" />

**Memory arrays:** function ke andar array `memory` (temporary) mein rah sakta hai. Uska size `new uint[](n)` se ek baar chuna jaata hai aur phir badal nahi sakta, isliye memory array pe `push` nahi hota. <Cite id="solidity-docs-datalocation" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ArrayDemo {
    // Fixed-size array: length 3, can never change
    uint[3] public fixedArr = [10, 20, 30];

    // Dynamic array: starts empty, can grow and shrink
    uint[] public dynamicArr;

    function setFixed(uint index, uint value) public {
        fixedArr[index] = value;
    }

    function sumFixed() public view returns (uint total) {
        for (uint i = 0; i < fixedArr.length; i++) {
            total += fixedArr[i];
        }
    }

    function addToDynamic(uint value) public {
        dynamicArr.push(value);
    }

    function removeLast() public {
        dynamicArr.pop();
    }

    function lengthOfDynamic() public view returns (uint) {
        return dynamicArr.length;
    }

    function getDynamic() public view returns (uint[] memory) {
        return dynamicArr;
    }

    // Memory arrays: temporary, fixed length chosen when created
    function squares(uint n) public pure returns (uint[] memory) {
        uint[] memory arr = new uint[](n);
        for (uint i = 0; i < n; i++) {
            arr[i] = i * i;
        }
        return arr;
    }
}
```

**Line by line:**

- `pragma solidity ^0.8.0;` matlab compiler 0.8.0 ya naya 0.8.x.
- `uint[3] public fixedArr = [10, 20, 30];` 3 items wala fixed array hai. `public` se Solidity getter `fixedArr(i)` bana deta hai.
- `uint[] public dynamicArr;` dynamic array hai. Shuru mein khaali hai aur **storage** mein rehta hai, jo blockchain pe save hota hai aur gas lagta hai.
- `setFixed` ek item badalta hai. Agar `index` 3 ya zyada hai to call fail (revert) ho jaata hai, kyunki fixed array badh nahi sakta.
- `sumFixed` saare items pe loop karke `total` mein jodta hai, jo 0 se shuru hota hai. `view` matlab sirf padhta hai.
- `addToDynamic` `push` se item jodta hai. `removeLast` `pop` use karta hai, jo khaali array pe fail hota hai.
- `lengthOfDynamic` `.length` return karta hai. `getDynamic` poore array ki temporary copy return karta hai.
- `squares` size `n` ka memory array banata hai aur index se bharta hai (`i * i`). `pure` matlab blockchain ko touch nahi karta.

<Box kind="verify">

**Example run (fresh deployment):**

1. `fixedArr(1)` returns 20. `sumFixed()` returns 10 + 20 + 30 = 60.
2. `setFixed(1, 50)` ke baad `sumFixed()` returns 10 + 50 + 30 = 90. `setFixed(3, 1)` revert hota hai.
3. `addToDynamic(5)` aur `addToDynamic(7)` se `dynamicArr` = [5, 7], to `lengthOfDynamic()` returns 2.
4. `removeLast()` ke baad [5] bacha aur length 1.
5. `squares(4)` returns [0, 1, 4, 9].

solc 0.8.38 se bina error ke compile hua.

</Box>

| Point | Fixed-size `T[k]` | Dynamic `T[]` |
|---|---|---|
| Length | Code mein tay, kabhi nahi badalti | Run time pe badalti hai |
| `push` / `pop` | Nahi milta | Milta hai (storage arrays) |
| Declaration | `uint[3] a;` | `uint[] a;` |
| Gas | Sasta, size pata hai | Har item ke saath badhta hai |
| Kab use karein | Size pata ho (hafte ke din) | Size pata na ho (users ki list) |

**Conclusion:** jab size kabhi na badle to fixed array use karo, aur jab list badhni ho to dynamic array. Memory arrays temporary hote hain aur ek baar bante hi unka size fixed ho jaata hai. <Cite id="solidity-tp-arrays" />
