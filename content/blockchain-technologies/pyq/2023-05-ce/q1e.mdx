**In simple words:** the second largest element is the biggest value that is smaller than the largest one. We read the array once and keep two numbers: the largest seen so far and the second largest seen so far. Each new element may replace one of them. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SecondLargest {
    function secondLargest(uint[] memory arr) public pure returns (uint) {
        require(arr.length >= 2, "Need at least 2 elements");

        uint largest = arr[0];
        uint second = 0;
        bool hasSecond = false;

        for (uint i = 1; i < arr.length; i++) {
            uint v = arr[i];
            if (v > largest) {
                second = largest;
                largest = v;
                hasSecond = true;
            } else if (v < largest && (!hasSecond || v > second)) {
                second = v;
                hasSecond = true;
            }
        }

        require(hasSecond, "All elements are equal");
        return second;
    }
}
```

**Line by line:**

- `pragma solidity ^0.8.0;` means compile with version 0.8.0 or a newer 0.8.x. The `SPDX` line only states the licence.
- `function secondLargest(uint[] memory arr) public pure returns (uint)` takes an array of whole numbers. `memory` means a temporary copy. `pure` means it does not touch the blockchain, so calling it costs no gas. <Cite id="solidity-docs-types" />
- `require(arr.length >= 2, ...)` stops with an error if there are fewer than two items, because then there is no second largest.
- `largest = arr[0]` starts with the first item as the largest. `second` starts at 0 and `hasSecond` is false, which means "no second value found yet". We need this flag because 0 can be a real array value.
- The loop starts at `i = 1` and looks at each item `v`.
- If `v > largest`, the old largest becomes the second, and `v` becomes the new largest.
- Else if `v < largest` and (no second yet, or `v` is bigger than `second`), then `v` becomes the second. Items equal to `largest` are skipped, so a repeated maximum is not counted as the second.
- The last `require` stops with an error if all items were equal. Otherwise `second` is returned.

<Box kind="verify">

**Call `secondLargest([10, 5, 20, 8])`:** start with largest = 10, hasSecond = false.

1. v = 5: not above 10, below 10 and no second yet, so second = 5.
2. v = 20: above 10, so second = 10 and largest = 20.
3. v = 8: below 20 but not above second (10), so nothing changes.

Returns **10**, which is correct (sorted: 5, 8, 10, 20).

**Call `secondLargest([7, 7, 3])`:** the second 7 equals the largest, so it is skipped. Then v = 3 sets second = 3. Returns **3**. **Call `[4, 4]`:** hasSecond stays false, so it reverts with "All elements are equal".

Compiled without errors with solc 0.8.38.

</Box>

**Complexity:** one pass over the array, so the work grows with the array length n. Long arrays cost more gas when this is used inside a transaction. <Cite id="solidity-gfg-arrays" /> <Cite id="solidity-by-example" />
