**In simple words:** ERC20 tokens **interchangeable** hote hain, jaise rupee ke note (koi bhi 10 rupaye dusre 10 rupaye ke barabar). ERC721 tokens **unique** hote hain, jaise zameen ka deed (har ek alag). Dono Ethereum ke token standards hain: functions ki ek fixed list jo har token contract mein honi chahiye taaki wallets aur apps uske saath kaam kar sakein. <Cite id="cryptocurrencies-tokens-eip20" /> <Cite id="cryptocurrencies-tokens-eip721" />

| Point | ERC20 | ERC721 |
|---|---|---|
| Type | Fungible (identical, divisible) | Non-fungible (NFT, unique, indivisible) |
| What is tracked | Har address ka balance | Har token ID ka owner |
| Key functions | `transfer`, `balanceOf`, `approve`, `transferFrom`, `allowance` | `ownerOf`, `safeTransferFrom`, `approve`, `getApproved` |
| Divisibility | Haan, decimals se (jaise 18) | Nahi, ek token matlab ek poori cheez |
| Uniqueness | Koi nahi | Har tokenId alag |
| Use cases | Stablecoins, utility tokens, ICO tokens, voting tokens | Digital art, game items, tickets, property deeds |
| Examples | USDT, LINK, UNI | CryptoKitties, Bored Ape NFTs |
| Standard | EIP-20 | EIP-721 |

**Ek line mein idea:** ERC20 mein contract `balances[address]` rakhta hai, yani "mere paas 50 tokens hain". ERC721 mein contract `owner[tokenId]` rakhta hai, yani "token 7 mera hai". <Cite id="cryptocurrencies-tokens-gfg-erc-vs" />

**Conclusion:** jab har unit same chahiye tab ERC20 use karo; jab har item one of a kind chahiye tab ERC721. <Cite id="cryptocurrencies-tokens-eth-erc721" />
