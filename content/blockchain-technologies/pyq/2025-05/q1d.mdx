**In simple words:** a prime number is divisible only by 1 and itself. To check it, we try dividing by small numbers. If any divides evenly, it is not prime. We only need to try up to the square root of the number. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract PrimeChecker {
    function isPrime(uint256 n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        if (n == 2) {
            return true;
        }
        if (n % 2 == 0) {
            return false;
        }
        for (uint256 i = 3; i * i <= n; i += 2) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
}
```

**Line by line:**

- `// SPDX-License-Identifier: MIT` tells the licence of the code; the compiler warns if it is missing.
- `pragma solidity ^0.8.0;` says to compile with version 0.8.0 or newer 0.8.x.
- `contract PrimeChecker` is the contract, like a class.
- `function isPrime(uint256 n) public pure returns (bool)` takes one whole number `n`. `public` lets anyone call it. `pure` means it neither reads nor changes blockchain data, so calling it costs no gas when called from outside. <Cite id="solidity-docs-view-pure" />
- `n < 2` : 0 and 1 are not prime, so return `false`.
- `n == 2` : 2 is prime.
- `n % 2 == 0` : any other even number is not prime. `%` gives the remainder.
- The `for` loop starts at 3, goes in steps of 2 (only odd divisors), and stops when `i * i` becomes bigger than `n` (no need to go past the square root).
- `n % i == 0` : a divisor was found, so `false`.
- If the loop ends without finding any, return `true`.

<Box kind="verify">

**Call `isPrime(29)`:** 29 is not below 2, not 2, and 29 % 2 = 1. Loop: i = 3, 9 ≤ 29, 29 % 3 = 2, no divisor. i = 5, 25 ≤ 29, 29 % 5 = 4, no divisor. i = 7, 49 > 29, loop stops. Returns **true**.

**Call `isPrime(21):`** i = 3, 9 ≤ 21, 21 % 3 = 0, returns **false** (21 = 3 x 7).

</Box>

**Note:** the loop runs about the square root of n times, so a very large n costs more gas when called inside a transaction. <Cite id="solidity-gfg-intro" /> <Cite id="solidity-by-example" />
