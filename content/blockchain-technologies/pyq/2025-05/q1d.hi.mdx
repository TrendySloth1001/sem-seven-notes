**In simple words:** prime number sirf 1 aur khud se divide hota hai. Check karne ke liye hum chhote numbers se divide karke dekhte hain. Koi bhi barabar divide kare to number prime nahi hai. Number ke square root tak hi try karna kaafi hai. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract PrimeChecker {
    function isPrime(uint256 n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        if (n == 2) {
            return true;
        }
        if (n % 2 == 0) {
            return false;
        }
        for (uint256 i = 3; i * i <= n; i += 2) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
}
```

**Line by line:**

- `// SPDX-License-Identifier: MIT` code ka licence batata hai; missing ho to compiler warning deta hai.
- `pragma solidity ^0.8.0;` kehta hai ki version 0.8.0 ya usse naye 0.8.x se compile karo.
- `contract PrimeChecker` contract hai, class jaisa.
- `function isPrime(uint256 n) public pure returns (bool)` ek whole number `n` leta hai. `public` ka matlab koi bhi call kar sakta hai. `pure` ka matlab ye blockchain ka data na padhta hai na badalta hai, isliye bahar se call karne pe gas nahi lagti. <Cite id="solidity-docs-view-pure" />
- `n < 2` : 0 aur 1 prime nahi hain, to `false` return karo.
- `n == 2` : 2 prime hai.
- `n % 2 == 0` : baaki har even number prime nahi hai. `%` remainder deta hai.
- `for` loop 3 se start hota hai, 2 ke step mein jaata hai (sirf odd divisors), aur jab `i * i`, `n` se bada ho jaye tab ruk jaata hai (square root ke aage jaane ki zaroorat nahi).
- `n % i == 0` : divisor mil gaya, to `false`.
- Loop bina divisor mile khatam ho jaye to `true` return karo.

<Box kind="verify">

**`isPrime(29)` call:** 29, 2 se chhota nahi hai, 2 nahi hai, aur 29 % 2 = 1. Loop: i = 3, 9 ≤ 29, 29 % 3 = 2, divisor nahi. i = 5, 25 ≤ 29, 29 % 5 = 4, divisor nahi. i = 7, 49 > 29, loop ruk gaya. Return **true**.

**`isPrime(21)` call:** i = 3, 9 ≤ 21, 21 % 3 = 0, return **false** (21 = 3 x 7).

</Box>

**Note:** loop lagbhag n ke square root baar chalta hai, isliye bahut bade n pe transaction ke andar call karne se gas zyada lagti hai. <Cite id="solidity-gfg-intro" /> <Cite id="solidity-by-example" />
