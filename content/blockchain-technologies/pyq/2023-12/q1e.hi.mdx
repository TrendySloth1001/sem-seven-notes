**In simple words:** dono Ethereum pe token standards hain, yaani functions ka ek common set taaki wallets aur apps koi bhi token handle kar sakein. **ERC20** un tokens ke liye hai jinki har unit same hoti hai (rupee notes ki tarah). **ERC721** un tokens ke liye hai jinka har token unique hota hai (numbered painting ki tarah). <Cite id="cryptocurrencies-tokens-gfg-erc-vs" />

| Point | ERC20 | ERC721 |
|---|---|---|
| Type | Fungible (interchangeable) | Non-fungible (unique, NFT) |
| Matlab | Ek token kisi bhi dusre ke barabar | Har token ka apna `tokenId` |
| Divisible | Yes, up to `decimals` | No, poora token hi |
| Ownership record | Har address ka balance | Har token id ka owner |
| Main functions | `transfer`, `balanceOf`, `approve`, `transferFrom`, `allowance`, `totalSupply` | `ownerOf`, `safeTransferFrom`, `approve`, `getApproved`, `setApprovalForAll`, `balanceOf` |
| Metadata | Name, symbol, decimals | `tokenURI` image aur details ki taraf point karta hai |
| Use | Currency, utility, voting, stablecoins | Art, game items, tickets, land deeds |
| Examples | USDT, LINK, UNI | CryptoKitties, Bored Apes |
| EIP | EIP-20 | EIP-721 |

<Cite id="cryptocurrencies-tokens-eip20" /> <Cite id="cryptocurrencies-tokens-eip721" />

**Example:** agar aapke paas 5 ERC20 tokens hain, to koi bhi 2 kisi ke 2 se swap karo, kuch nahi badalta. ERC721 mein token #7 aur token #8 alag items hain, to unhe like-for-like swap nahi kar sakte. <Cite id="cryptocurrencies-tokens-eth-nft" />

**Conclusion:** jab units identical aur countable hon to ERC20 use karo, aur jab har item unique ho to ERC721.
