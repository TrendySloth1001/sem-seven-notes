**In simple words:** Ethereum account ek identity hai jo ether (ETH) rakh sakti hai aur transactions bhej sakti hai. Ethereum mein **do types ke accounts** hote hain: externally owned accounts aur contract accounts. <Cite id="ethereum-eth-accounts" />

**1. Externally Owned Account (EOA)**

- Insaan (ya program) ise **private key** se control karta hai.
- Address public key se banta hai. Isme **koi code nahi** hota.
- ETH rakh sakta hai aur transactions **start** kar sakta hai (ETH bhejna, contracts call karna, contracts deploy karna).
- Banana free hai, kyunki sirf key pair chahiye.
- Example: aapka MetaMask wallet account.

**2. Contract Account**

- Ise apna **code** (smart contract) control karta hai. Isme **private key nahi** hoti.
- Contract deploy karne pe banta hai, aur iska apna address hota hai.
- ETH rakh sakta hai, aur iska storage hota hai.
- Ye khud se transaction **start nahi** kar sakta. Ye tabhi chalta hai jab koi EOA (ya dusra contract) ise call kare.
- Banane mein gas lagta hai.
- Example: token contract ya voting contract.

**Har account ke chaar fields hote hain:** `nonce` (usne kitne transactions bheje, ya kitne contracts banaye), `balance` (wei mein), `storageRoot` (uske storage ka hash) aur `codeHash` (uske code ka hash, EOA ke liye empty code ka hash). <Cite id="ethereum-me-ch6" />

| | EOA | Contract account |
|---|---|---|
| Controlled by | Private key | Contract code |
| Has code | No | Yes |
| Can start a transaction | Yes | No |
| Cost to create | Free | Gas |

<Cite id="ethereum-gfg-accounts" />

**Conclusion:** EOAs wo users hain jo action lete hain, aur contract accounts wo programs hain jo react karte hain.
