**In simple words:** an array is a list of items of the same type. Solidity has fixed-size arrays, dynamic arrays, memory arrays, multi-dimensional arrays and arrays of strings. This contract shows each one. <Cite id="solidity-docs-types" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ArrayTypes {
    // 1. Fixed-size array: length 3, set when written
    uint[3] public fixedArr = [10, 20, 30];

    // 2. Dynamic array in storage: can grow and shrink
    uint[] public dynamicArr;

    // 3. Multi-dimensional (array of arrays) in storage
    uint[][] public nested;

    // 4. Array of strings
    string[] public names;

    // push adds one item at the end
    function addToDynamic(uint x) public {
        dynamicArr.push(x);
    }

    // pop removes the last item (reverts if the array is empty)
    function removeLast() public {
        dynamicArr.pop();
    }

    // length gives the number of items
    function lengthOfDynamic() public view returns (uint) {
        return dynamicArr.length;
    }

    // returns the whole storage array
    function getDynamic() public view returns (uint[] memory) {
        return dynamicArr;
    }

    // loops over the fixed array and adds its items
    function sumFixed() public view returns (uint s) {
        for (uint i = 0; i < fixedArr.length; i++) {
            s += fixedArr[i];
        }
    }

    // 5. Memory array: temporary, size must be given at creation
    function memoryArray(uint n) public pure returns (uint[] memory) {
        uint[] memory arr = new uint[](n);
        for (uint i = 0; i < n; i++) {
            arr[i] = i * 2;
        }
        return arr;
    }

    // adds a row (inner array) of two numbers to nested
    function addRow(uint a, uint b) public {
        uint[] memory row = new uint[](2);
        row[0] = a;
        row[1] = b;
        nested.push(row);
    }

    function addName(string memory n) public {
        names.push(n);
    }
}
```

**Line by line, in simple words:**

- `pragma solidity ^0.8.0;` means the code works with compiler version 0.8.0 or a newer 0.8.x. The `SPDX` line only states the licence.
- `contract ArrayTypes { ... }` is like a class. All the data and functions live inside.
- `uint[3] public fixedArr = [10, 20, 30];` is a **fixed-size array**: exactly 3 numbers, length can never change. `public` makes Solidity create a getter `fixedArr(index)` for free.
- `uint[] public dynamicArr;` is a **dynamic array**: it starts empty and can grow. It lives in **storage** (kept on the blockchain forever, costs gas).
- `uint[][] public nested;` is a **multi-dimensional array**: a dynamic array whose items are dynamic arrays.
- `string[] public names;` is an array of strings.
- `addToDynamic` uses `push` to add `x` at the end. `removeLast` uses `pop`; on an empty array it fails (reverts).
- `lengthOfDynamic` returns `.length`. `view` means it only reads data, so calling it from outside costs no gas.
- `getDynamic` returns the array as `memory`, i.e. a temporary copy.
- `sumFixed` loops `i` from 0 to 2 and adds each item into the return variable `s` (which starts at 0).
- `memoryArray` makes a temporary array with `new uint[](n)`. Memory arrays have a fixed size and have **no** `push`, so we fill them by index. `pure` means it neither reads nor writes the blockchain.
- `addRow` builds a two-item array in memory and pushes it as one row of `nested`.

<Box kind="verify">

**Example run (fresh deployment):**

1. `addToDynamic(5)` then `addToDynamic(7)`: `dynamicArr` is now [5, 7].
2. `lengthOfDynamic()` returns 2, and `getDynamic()` returns [5, 7].
3. `sumFixed()` returns 10 + 20 + 30 = 60.
4. `memoryArray(3)` returns [0, 2, 4], since i*2 for i = 0, 1, 2.
5. `removeLast()` makes `dynamicArr` = [5], and the length becomes 1.
6. `addRow(1, 2)` then `nested(0, 1)` returns 2, the second item of row 0.

This code was compiled with solc 0.8.28 without errors. You can also test it in Remix (compiler 0.8.x).

</Box>

**Conclusion:** fixed arrays have a set size, dynamic arrays can grow with `push`, memory arrays are temporary, and arrays can be nested. <Cite id="solidity-gfg-arrays" /> <Cite id="solidity-docs-datalocation" />
