**In simple words:** Bitcoin is a digital money that works without a bank. People send coins directly to each other, and the network of computers checks and records every payment. <Cite id="bitcoin-wiki-bitcoin" />

**What is Bitcoin?** It is the first cryptocurrency, described by Satoshi Nakamoto in 2008 and started in 2009. It is a peer-to-peer electronic cash system. Payments are stored in a public blockchain, protected by cryptography (hashes and digital signatures), and new blocks are added by miners using proof of work. <Cite id="blockchain-fundamentals-nakamoto" />

**What is hash cash?** Hashcash is a proof-of-work idea by Adam Back (proposed 1997, paper 2002), made to stop email spam. The sender must do some computer work for each email: find a number (nonce) so that the hash of the email header starts with a fixed number of zero bits. The work is costly to do, but anyone can check it with one hash. So a normal user pays almost nothing, while a spammer sending millions of mails pays a lot. <Cite id="bitcoin-hashcash-back" />

**Role of hash cash in Bitcoin:**

1. Bitcoin uses the same idea as its **proof of work**. A miner changes the nonce in the block header until the SHA-256 hash of the header is below a target.
2. It makes adding a block **expensive**, so cheating costs real electricity and hardware.
3. It makes the **longest chain** hard to fake: an attacker must redo the work for every block.
4. Checking is cheap: other nodes verify with a single hash.
5. It controls who creates the next block and how fast, since the target (difficulty) is adjusted to keep about one block per 10 minutes.

| | Hashcash | Bitcoin PoW (2009) |
|---|---|---|
| Purpose | Stop spam email | Agree on the next block |
| Work done on | Email header | Block header |
| Hash | SHA-1 | Double SHA-256 |

**Conclusion:** Bitcoin is peer-to-peer digital cash, and hash cash gives it the costly-to-make, easy-to-check work that keeps the chain secure.
