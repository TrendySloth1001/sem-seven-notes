**In simple words:** an Ethereum account is an identity that can hold ether (ETH) and send transactions. Ethereum has **two types of accounts**: externally owned accounts and contract accounts. <Cite id="ethereum-eth-accounts" />

**1. Externally Owned Account (EOA)**

- Controlled by a human (or program) through a **private key**.
- Has an address made from the public key. It has **no code**.
- Can hold ETH and **start** transactions (send ETH, call contracts, deploy contracts).
- Creating one is free, because it only needs a key pair.
- Example: your MetaMask wallet account.

**2. Contract Account**

- Controlled by its **code** (a smart contract). It has **no private key**.
- Created when someone deploys a contract, and it has its own address.
- Can hold ETH, and has storage.
- It **cannot start** a transaction by itself. It runs only when an EOA (or another contract) calls it.
- Creating one costs gas.
- Example: a token contract or a voting contract.

**Every account has four fields:** `nonce` (number of transactions sent, or contracts created, by it), `balance` (in wei), `storageRoot` (hash of its storage) and `codeHash` (hash of its code, which is the hash of empty code for an EOA). <Cite id="ethereum-me-ch6" />

| | EOA | Contract account |
|---|---|---|
| Controlled by | Private key | Contract code |
| Has code | No | Yes |
| Can start a transaction | Yes | No |
| Cost to create | Free | Gas |

<Cite id="ethereum-gfg-accounts" />

**Conclusion:** EOAs are the users who act, and contract accounts are the programs that react.
