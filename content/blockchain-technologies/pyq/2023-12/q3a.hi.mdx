**In simple words:** array same type ke items ki list hoti hai. Solidity mein fixed-size arrays, dynamic arrays, memory arrays, multi-dimensional arrays aur strings ke arrays hote hain. Ye contract har ek dikhata hai. <Cite id="solidity-docs-types" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ArrayTypes {
    // 1. Fixed-size array: length 3, set when written
    uint[3] public fixedArr = [10, 20, 30];

    // 2. Dynamic array in storage: can grow and shrink
    uint[] public dynamicArr;

    // 3. Multi-dimensional (array of arrays) in storage
    uint[][] public nested;

    // 4. Array of strings
    string[] public names;

    // push adds one item at the end
    function addToDynamic(uint x) public {
        dynamicArr.push(x);
    }

    // pop removes the last item (reverts if the array is empty)
    function removeLast() public {
        dynamicArr.pop();
    }

    // length gives the number of items
    function lengthOfDynamic() public view returns (uint) {
        return dynamicArr.length;
    }

    // returns the whole storage array
    function getDynamic() public view returns (uint[] memory) {
        return dynamicArr;
    }

    // loops over the fixed array and adds its items
    function sumFixed() public view returns (uint s) {
        for (uint i = 0; i < fixedArr.length; i++) {
            s += fixedArr[i];
        }
    }

    // 5. Memory array: temporary, size must be given at creation
    function memoryArray(uint n) public pure returns (uint[] memory) {
        uint[] memory arr = new uint[](n);
        for (uint i = 0; i < n; i++) {
            arr[i] = i * 2;
        }
        return arr;
    }

    // adds a row (inner array) of two numbers to nested
    function addRow(uint a, uint b) public {
        uint[] memory row = new uint[](2);
        row[0] = a;
        row[1] = b;
        nested.push(row);
    }

    function addName(string memory n) public {
        names.push(n);
    }
}
```

**Line by line, simple words mein:**

- `pragma solidity ^0.8.0;` ka matlab code compiler version 0.8.0 ya usse naye 0.8.x ke saath chalta hai. `SPDX` line sirf licence batati hai.
- `contract ArrayTypes { ... }` class jaisa hai. Saara data aur functions iske andar rehte hain.
- `uint[3] public fixedArr = [10, 20, 30];` ek **fixed-size array** hai: exactly 3 numbers, length kabhi nahi badal sakti. `public` se Solidity free mein getter `fixedArr(index)` bana deta hai.
- `uint[] public dynamicArr;` ek **dynamic array** hai: khaali shuru hota hai aur grow kar sakta hai. Ye **storage** mein rehta hai (blockchain pe hamesha, gas lagta hai).
- `uint[][] public nested;` ek **multi-dimensional array** hai: dynamic array jiske items khud dynamic arrays hain.
- `string[] public names;` strings ka array hai.
- `addToDynamic` `push` se `x` ko end mein add karta hai. `removeLast` `pop` use karta hai; khaali array pe ye fail (revert) ho jaata hai.
- `lengthOfDynamic` `.length` return karta hai. `view` ka matlab sirf data padhta hai, to bahar se call karne pe gas nahi lagta.
- `getDynamic` array ko `memory` mein return karta hai, yaani ek temporary copy.
- `sumFixed` `i` ko 0 se 2 tak loop karta hai aur har item return variable `s` (jo 0 se start hota hai) mein jodta hai.
- `memoryArray` `new uint[](n)` se temporary array banata hai. Memory arrays ka size fixed hota hai aur unme `push` **nahi** hota, to index se bharte hain. `pure` ka matlab ye blockchain ko na padhta hai na likhta hai.
- `addRow` memory mein do items ka array banakar use `nested` ki ek row ki tarah push karta hai.

<Box kind="verify">

**Example run (fresh deployment):**

1. `addToDynamic(5)` phir `addToDynamic(7)`: `dynamicArr` ab [5, 7] hai.
2. `lengthOfDynamic()` 2 return karta hai, aur `getDynamic()` [5, 7] return karta hai.
3. `sumFixed()` 10 + 20 + 30 = 60 return karta hai.
4. `memoryArray(3)` [0, 2, 4] return karta hai, kyunki i = 0, 1, 2 ke liye i*2.
5. `removeLast()` se `dynamicArr` = [5], aur length 1 ho jaati hai.
6. `addRow(1, 2)` phir `nested(0, 1)` 2 return karta hai, row 0 ka doosra item.

Ye code solc 0.8.28 se bina error ke compile ho gaya. Remix (compiler 0.8.x) mein bhi test kar sakte ho.

</Box>
