**In simple words:** smart contract blockchain pe stored ek program hai jo apni conditions poori hone par khud chalta hai. Vending machine socho: paise daalo, button dabao, snack gir jaata hai, koi dukandaar nahi. Ye idea Nick Szabo (1994) ka hai. <Cite id="smart-contracts-szabo-1994" />

**Key features:** automatic, koi middleman nahi, transparent, aur deploy hone ke baad badla nahi ja sakta (immutable). Ethereum pe ye Solidity mein likhe jaate hain aur EVM pe chalte hain. <Cite id="smart-contracts-eth-intro" />

**Types of smart contracts:**

1. **Smart legal contracts:** legal agreements jo code mein badle gaye hain, jaise rent ya insurance agreement jo automatically pay karta hai.
2. **Decentralised autonomous organisations (DAOs):** contracts jo funds rakhte hain aur members ko vote karne dete hain ki use kaise karna hai.
3. **Application logic contracts (dApp contracts):** decentralised app ka back-end, jaise token, game ya lending pool.
4. **Deterministic contracts:** bahar ke data ki zaroorat nahi; same input hamesha same result deta hai (jaise token transfer).
5. **Non-deterministic contracts:** bahar ke data (price, weather) pe depend karte hain, jo oracle laata hai.
6. **Multi-signature contracts:** paisa hilne se pehle kai owners ki approval chahiye.

Ek aur common split hai **on-chain** contracts (saara code blockchain pe) aur **off-chain** logic jo sirf results record karta hai. <Cite id="smart-contracts-gfg-smart-contracts" />

**Conclusion:** smart contracts logon ke trust ki jagah code pe trust rakhte hain. <Cite id="smart-contracts-ibm-smart-contracts" />

Exam mein English mein likho: "A smart contract is a self-executing program stored on the blockchain."
