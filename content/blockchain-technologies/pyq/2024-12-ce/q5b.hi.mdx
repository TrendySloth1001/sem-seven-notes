**In simple words:** `view` aur `pure` function pe lage labels hain jo Solidity (aur padhne wale) ko batate hain ki function ko blockchain ke data ke saath kya karne ki ijazat hai. Jo function kuch badalta nahi, use bahar se free call kar sakte hain, transaction ki zaroorat nahi. <Cite id="solidity-docs-view-pure" />

**View function:** state variables **padh** sakta hai par **badal** nahi sakta. Getters ke liye use karo.

**Pure function:** na state padh sakta hai na badal sakta hai; sirf apne inputs aur local variables pe kaam karta hai. Calculations ke liye use karo.

**Normal function:** state padh aur badal sakta hai; call karne par transaction jaata hai jo gas leta hai.

| Point | view | pure | Normal |
|---|---|---|---|
| Read state | Yes | No | Yes |
| Change state | No | No | Yes |
| Gas when called from outside | Free | Free | Needs a transaction and gas |
| Typical use | Getters | Maths helpers | Set or update data |

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ViewPureDemo {
    uint public price = 100;

    // view: reads state, does not change it
    function priceWithTax(uint taxPercent) public view returns (uint) {
        return price + (price * taxPercent) / 100;
    }

    // pure: neither reads nor changes state
    function add(uint a, uint b) public pure returns (uint) {
        return a + b;
    }

    // normal function: changes state, costs gas
    function setPrice(uint newPrice) public {
        price = newPrice;
    }
}
```

**Explanation:** `priceWithTax` state variable `price` use karta hai, isliye `view` hona chahiye. `add` sirf apne do inputs use karta hai, isliye `pure` ho sakta hai. `setPrice` `price` mein likhta hai, isliye na view na pure, aur transaction chahiye. Agar `view` function state mein likhne ki koshish kare, ya `pure` function state padhne ki, to compiler error deta hai. <Cite id="solidity-gfg-view-pure" />

<Box kind="verify">

`add(2, 3)` 5 return karta hai, koi state use kiye bina. `price = 100` ke saath, `priceWithTax(10)` deta hai 100 + (100 x 10) / 100 = 110. `setPrice(200)` ke baad `priceWithTax(10)` deta hai 200 + 20 = 220, to view ka result state ke saath badalta hai, jabki `add(2, 3)` ab bhi 5 hai. Maine ye code solc 0.8.26 se bina errors ke compile kiya.

</Box>

**Conclusion:** calculations ke liye `pure`, data padhne ke liye `view`, aur normal functions tabhi jab state badalni ho. <Cite id="solidity-docs-functions" />

Exam mein English mein likho: "A view function reads state but does not modify it; a pure function neither reads nor modifies state."
