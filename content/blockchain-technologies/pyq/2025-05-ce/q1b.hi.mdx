**In simple words:** prime number 1 se bada hota hai aur sirf 1 aur khud se divide hota hai. Number n ko test karne ke liye hum use 2, 3, 4 aur aage se divide karke dekhte hain. Agar koi bhi barabar divide kare, to n prime nahi hai. Jab divisor ka square n se bada ho jaaye tab ruk sakte hain, kyunki bada divisor ka ek chhota jodidaar pehle hi try ho chuka hota hai. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract PrimeChecker {
    function isPrime(uint256 n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        for (uint256 i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
}
```

**Line by line:**

- `// SPDX-License-Identifier: MIT` code ka licence batata hai. Missing ho to compiler warning deta hai.
- `pragma solidity ^0.8.0;` matlab compiler version 0.8.0 ya naya 0.8.x use karo.
- `contract PrimeChecker` contract hai, dusri languages ki class jaisa.
- `function isPrime(uint256 n) public pure returns (bool)` ek whole number `n` leta hai (negative nahi). `public` se koi bhi call kar sakta hai. `pure` matlab ye blockchain data na padhta hai na badalta hai, isliye bahar se call karne pe gas nahi lagta. Ye true ya false return karta hai. <Cite id="solidity-docs-view-pure" />
- `if (n < 2) return false;` kyunki 0 aur 1 prime nahi hain.
- `for (uint256 i = 2; i * i <= n; i++)` har divisor `i` ko 2 se tab tak try karta hai jab tak `i * i`, `n` se aage na nikal jaaye.
- `if (n % i == 0) return false;` jahan `%` remainder deta hai. Remainder 0 matlab `i`, `n` ko divide karta hai, to `n` prime nahi.
- `return true;` tabhi pahunchta hai jab koi divisor nahi mila.

<Box kind="verify">

**Call `isPrime(29)`:** 29, 2 se chhota nahi hai. Loop: i = 2 pe 29 % 2 = 1. i = 3 pe 29 % 3 = 2. i = 4 pe 29 % 4 = 1. i = 5 (25 ≤ 29) pe 29 % 5 = 4. i = 6 pe 36 > 29, loop ruk jaata hai. Returns **true**.

**Call `isPrime(21)`:** i = 2 pe remainder 1. i = 3 pe 21 % 3 = 0, to returns **false** (21 = 3 x 7).

**Call `isPrime(1)`:** pehle check pe hi returns **false**.

</Box>

**Note:** loop lagbhag n ke square root baar chalta hai, isliye bahut bada n ho aur function transaction ke andar call ho to gas zyada lagti hai. Code solc 0.8.26 se compile hota hai. <Cite id="solidity-gfg-intro" /> <Cite id="solidity-by-example" />
