**In simple words:** a prime number is bigger than 1 and can be divided evenly only by 1 and itself. To test a number n, we try dividing it by 2, 3, 4 and so on. If any of them divides evenly, n is not prime. We can stop once the divisor squared is bigger than n, because a bigger divisor would have a matching smaller one that we already tried. <Cite id="solidity-docs-control" />

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract PrimeChecker {
    function isPrime(uint256 n) public pure returns (bool) {
        if (n < 2) {
            return false;
        }
        for (uint256 i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
}
```

**Line by line:**

- `// SPDX-License-Identifier: MIT` states the licence of the code. The compiler warns if it is missing.
- `pragma solidity ^0.8.0;` means compile with version 0.8.0 or a newer 0.8.x version.
- `contract PrimeChecker` is the contract, like a class in other languages.
- `function isPrime(uint256 n) public pure returns (bool)` takes one whole number `n` (no negative values). `public` lets anyone call it. `pure` means it does not read or change blockchain data, so calling it from outside costs no gas. It returns true or false. <Cite id="solidity-docs-view-pure" />
- `if (n < 2) return false;` because 0 and 1 are not prime.
- `for (uint256 i = 2; i * i <= n; i++)` tries each divisor `i` from 2 until `i * i` passes `n`.
- `if (n % i == 0) return false;` where `%` gives the remainder. Remainder 0 means `i` divides `n`, so `n` is not prime.
- `return true;` is reached only if no divisor was found.

<Box kind="verify">

**Call `isPrime(29)`:** 29 is not below 2. Loop: i = 2 gives 29 % 2 = 1. i = 3 gives 29 % 3 = 2. i = 4 gives 29 % 4 = 1. i = 5 (25 ≤ 29) gives 29 % 5 = 4. i = 6 gives 36 > 29, so the loop stops. Returns **true**.

**Call `isPrime(21)`:** i = 2 gives remainder 1. i = 3 gives 21 % 3 = 0, so it returns **false** (21 = 3 x 7).

**Call `isPrime(1)`:** returns **false** at the first check.

</Box>

**Note:** the loop runs about the square root of n times, so a very large n costs more gas if the function is called inside a transaction. The code compiles with solc 0.8.26. <Cite id="solidity-gfg-intro" /> <Cite id="solidity-by-example" />
