**In simple words:** cloud computing means using servers, storage and software over the internet from a provider, and paying only for what you use, like electricity instead of owning a power plant. Its benefits are mainly about cost, speed and flexibility. <Cite id="note-cloud-computing-aws-cloud" />

**Definition:** cloud computing is a model for convenient, on-demand network access to a shared pool of computing resources (servers, storage, applications) that can be quickly provided with little management effort. <Cite id="note-cloud-computing-nist-800-145" />

**Key benefits and analysis**

| Benefit | Why it matters | Example |
|---|---|---|
| Lower upfront cost | No servers to buy; capital cost becomes running cost | A start-up launches without a data centre |
| Pay-as-you-go | Pay only for use, so little waste | Paying per hour for a test server |
| Scalability and elasticity | Capacity grows or shrinks with demand | A shopping site adding capacity for a big sale |
| Speed and agility | New resources in minutes; faster time to market | A team tries an idea on a new server the same day |
| Global reach | Deploy near users in many regions | A streaming service serving many countries |
| Reliability and recovery | Cheaper backup and disaster recovery | Data copied to another region survives a failure |
| Access from anywhere | Work from any device with internet | Staff using Microsoft 365 from home |
| Less IT burden | Provider handles updates and patches | A small firm without an IT team uses SaaS |
| Advanced services | AI and analytics offered as services | A firm uses a ready analytics service |
| Collaboration | Many people edit the same file at once | A class group on Google Docs |

**Analysis:** benefits are largest when demand is uneven, when the firm is small or new, or when speed matters. They are smaller for steady, predictable workloads where owning hardware can be cheaper, and for data under strict rules.

**Limits:** security and privacy worries, dependence on the internet, vendor lock-in (switching is costly) and bills that can grow unnoticed. <Cite id="note-cloud-computing-wiki-lockin" />

**Conclusion:** cloud computing gives low cost, flexibility and speed, so it suits most modern businesses, if risks such as lock-in and security are managed.
