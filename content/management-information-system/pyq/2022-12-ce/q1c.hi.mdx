**In simple words:** Web 2.0 social web hai, jahan users bade companies ke platforms pe content likhte aur share karte hain. Web 3.0 agla idea hai: ek smarter web jo meaning samajhta hai aur, Web3 ke view mein, users ko apne data ka ownership deta hai. <Cite id="social-computing-gfg-web-versions" />

**Web 2.0:** lagbhag 2004 se shuru hua. Users read aur write dono kar sakte hain: post, comment, like, upload, share. Examples: Facebook, YouTube, Wikipedia, Instagram. <Cite id="social-computing-oreilly-web2" />

**Web 3.0:** abhi emerging hai aur iski koi ek agreed definition nahi hai. Ye Semantic Web (aisa data jiska meaning clear ho aur machines samajh sakein) aur Web3 (blockchain pe bana decentralised web) dono ke liye bola jaata hai. Ismein AI se aapko dikhne wali cheezein personalise bhi hoti hain. <Cite id="social-computing-wiki-web3" />

**Web 2.0 aur Web 3.0 ka difference**

| Point | Web 2.0 | Web 3.0 |
|---|---|---|
| Nickname | Read-write, social web | Read-write-own, smart and decentralised web |
| Content | Users company platforms pe banate hain | Users banate hain, machines aur AI madad karte hain |
| Data control | Bade platforms jaise Facebook, Google | User (Web3 view mein) |
| Technology | Ajax, JavaScript, blogs, wikis, cloud | Semantic tags, AI, blockchain, smart contracts |
| Intelligence | Pages dynamic hain par machines unka meaning nahi samajhti | Machines meaning samajhti hain aur personalise karti hain |
| Communication | Two-way, central server ke through | Peer-to-peer aur machine-to-machine bhi |
| Example | Facebook, YouTube, Amazon reviews | Semantic search, Ethereum apps, smart assistants |
| Weak point | Privacy loss, data platforms ke paas | Complex, slow, early stage, rules clear nahi |

<Cite id="social-computing-av-web2-web3" />

**Conclusion:** Web 2.0 ne web ko social banaya; Web 3.0 use meaningful aur user-owned banana chahta hai.
