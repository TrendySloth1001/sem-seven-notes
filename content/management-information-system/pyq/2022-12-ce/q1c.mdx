**In simple words:** Web 2.0 is the social web, where users write and share content on platforms owned by big companies. Web 3.0 is the next idea: a smarter web that understands meaning and, in the Web3 view, gives users ownership of their data. <Cite id="social-computing-gfg-web-versions" />

**Web 2.0:** started around 2004. Users can read and write: post, comment, like, upload, share. Examples: Facebook, YouTube, Wikipedia, Instagram. <Cite id="social-computing-oreilly-web2" />

**Web 3.0:** still emerging and has no single agreed definition. It is used for the Semantic Web (data with clear meaning that machines can understand) and for Web3 (a decentralised web built on blockchain). It also uses AI to personalise what you see. <Cite id="social-computing-wiki-web3" />

**Difference between Web 2.0 and Web 3.0**

| Point | Web 2.0 | Web 3.0 |
|---|---|---|
| Nickname | Read-write, social web | Read-write-own, smart and decentralised web |
| Content | Created by users on company platforms | Created by users, with machines and AI helping |
| Data control | Big platforms such as Facebook and Google | The user (in the Web3 view) |
| Technology | Ajax, JavaScript, blogs, wikis, cloud | Semantic tags, AI, blockchain, smart contracts |
| Intelligence | Pages are dynamic but mostly not "understood" by machines | Machines understand meaning and personalise |
| Communication | Two-way, through a central server | Also peer-to-peer and machine-to-machine |
| Example | Facebook, YouTube, Amazon reviews | Semantic search, Ethereum apps, smart assistants |
| Weak point | Privacy loss, data owned by platforms | Complex, slow, early stage, unclear rules |

<Cite id="social-computing-av-web2-web3" />

**Conclusion:** Web 2.0 made the web social; Web 3.0 aims to make it meaningful and user-owned.
