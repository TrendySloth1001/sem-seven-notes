**In simple words:** computer crime wo crime hai jismein computer ya network tool, target ya crime ki jagah hota hai, jaise hacking, online fraud ya viruses phailana. Reasons analyse karne ka matlab hai ye poochna: ye crimes baar-baar kyun hote hain? <Cite id="ethics-privacy-wiki-cybercrime" />

**Definition:** computer crime (cybercrime) koi bhi illegal act hai jisme computer ya network crime ka tool, target ya jagah hota hai. <Cite id="note-information-security-gfg-cybercrime" />

**Main reasons** <Cite id="ethics-privacy-gfg-cybercrime-causes" /> <Cite id="ethics-privacy-gfg-cyber-criminals" />

| Reason | Crime ko kyun badhawa deta hai | Example |
|---|---|---|
| Financial gain | Fraud, ransomware aur card theft mein paisa milta hai; sabse bada motive | Paise maangne wala ransomware |
| Weak systems | Unpatched software, default ya weak passwords se andar aana aasaan | Known bug ke liye server update nahi hua |
| Awareness ki kami | Users links par click karte hain, passwords repeat karte hain, OTP share karte hain | Employee fake bank page par password daalta hai |
| Data ki aasaan copying | Digital data seconds mein copy ho jaata hai aur original waisa hi dikhta hai | Customer database pen drive mein copy hua |
| Anonymity aur borders | Attackers dusre desh se fake identity ke peeche chhupte hain; trace karna mushkil | Dusre desh mein baitha attacker |
| Weak laws aur under-reporting | Pakde jaane ya saza milne ka chance kam | Victims loss report nahi karte |
| Insiders | Employees ke paas pehle se access hai; lalach ya badla | Naraz staff records leak karta hai |
| Thrill, ego, politics | Kuch log skill dikhane, jasoosi ya protest ke liye attack karte hain | Hacktivist website deface karta hai |
| Technology ka tez change | Naye tools defences se pehle aa jaate hain | Voice-cloning scam |
| Digital growth | Online zyada paisa, log aur data matlab zyada targets | UPI aur e-commerce fraud |

**Common types:** phishing, identity theft, ransomware, hacking, denial-of-service, cyberstalking aur piracy. <Cite id="note-information-security-gfg-cybercrime" />

**Indian law:** Information Technology Act, 2000 hacking (section 66), identity theft (66C), computer se personation karke cheating (66D) aur cyber terrorism (66F) ko punish karta hai. Incidents cyber crime portal aur CERT-In ko report kiye jaate hain. <Cite id="note-information-security-wiki-itact" />

**Kaise kam karein:** software patch karo, strong passwords aur OTP use karo, users ko train karo, backups lo, data encrypt karo aur systems monitor karo.

**Conclusion:** computer crime wahan badhta hai jahan gain zyada, defences weak, users laparwah aur saza ka chance kam ho. Ye chaar cheezein theek karne se crime kam hota hai.
