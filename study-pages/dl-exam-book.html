Gradient descent and optimizers

asked in all 5 papers1 in assignments

Gradient descent moves every weight a small step downhill on the loss, again and again, until the loss is minimum.

Must write
  • Update rule: Wnew = Wold - η·∂L/∂W. The gradient points uphill, so we subtract it.
  • Learning rate η: small = slow, large = overshoots, proper = fast and stable.
  • Batch GD = all data, SGD = one sample, mini-batch = small group per update. Mini-batch is the most used.
  • Momentum remembers the previous update: Vt = βVt-1 - η·∂L/∂W, Wnew = Wold + Vt, β about 0.9.
  • Adam = Momentum + RMSProp with bias correction (β1 = 0.9, β2 = 0.999).

Mini-batchBatch of 16, 32, 64...Slight zig-zagBest balance, most used

AdaGrad: Gt = Gt-1 + gt²; Wnew = Wold - η·gt / (√Gt + ε)

Feedforward neural network (MLP)

asked in 3 of 5 papers2 in assignments

A feedforward network is a network where data moves in one direction only, from the input layer through the hidden layers to the output layer, with no feedback or loop.

Must write
  • Data flows one way: input layer, hidden layer(s), output layer. No feedback, no loop.
  • Input layer: one neuron per feature, no calculation. Hidden layers calculate and learn patterns. Output layer gives the prediction.
  • Each neuron: z = Σ wixi + b, then a = f(z) (weights, bias, activation).
  • Hidden units add non-linearity through the activation, so problems like XOR become solvable.
  • Learning: error goes back by backpropagation, gradient descent updates the weights. No memory of earlier inputs.

Layers and hidden units

LayerJob
InputTakes the features; one neuron per feature; no calculation
HiddenMultiply by weights, add bias, apply activation; first layers find edges, later layers shapes and object parts
OutputFinal prediction; one neuron per output
  • Called "hidden" because the training data does not show their desired output.
  • Design choices: depth (number of layers) and width (units per layer). Layers are chained: f(x) = f(3)(f(2)(f(1)(x))).
  • Default hidden unit: ReLU; the best size is found by trial on a validation set.

Activation functions

asked in all 5 papers

An activation function takes z = w·x + b of a neuron and turns it into the neuron's output, which makes the network non-linear so it can learn complex patterns.

Must write
  • Without an activation function the whole network is only a linear model. The activation adds non-linearity.
  • Significance: non-linearity, controls the neuron output, helps backpropagation, sets the output range.
  • Sigmoid (0 to 1): binary output. Tanh (-1 to 1): hidden, zero-centered. ReLU = max(0, z): most used in hidden layers.
  • Leaky ReLU fixes dying ReLU. Softmax gives class probabilities that add to 1 (multi-class output).
  • Problems: vanishing gradient (sigmoid, tanh) and dying ReLU.

Types at a glance

Key facts

  • Sigmoid gives 0.5 at z = 0. ReLU turns 8, 3, 0, -2, -7 into 8, 3, 0, 0, 0. A neuron that always gets negative input stays at 0 and stops learning (dying ReLU).
  • Softmax example: z = (2, 1, 0) gives ez = 7.389, 2.718, 1; sum 11.107; probabilities 0.665, 0.245, 0.090 (add to 1). The biggest score gets the biggest probability.

Loss functions and the learning process

asked in 3 of 5 papers

A loss function measures how far the prediction is from the actual answer, and the network learns by repeating forward pass, loss, backpropagation and weight update until this loss is small.

Must write
  • Loss = difference between predicted and actual output. Small loss = good prediction.
  • Loss is for one example; cost is the average over the whole training set (cost = loss + regularization term).
  • MSE = (1/n) Σ (y - ŷ)² for regression; cross entropy for classification, it punishes a confident wrong answer heavily.
  • Learning loop: forward pass (predict), loss (measure), backpropagation (find gradients), optimizer (update weights).
  • Backpropagation only computes the gradient; the optimizer updates the weights: Wnew = Wold - η·∂L/∂W.

MSE example: errors -5, 5, -10, 5 give squares 25, 25, 100, 25; sum 175; MSE = 175/4 = 43.75. We square to remove the sign and punish big errors more.

One learning cycle with numbers

x = 2, y = 4, w = 3, ŷ = wx, L = (ŷ - y)², η = 0.1.

  1. Forward: ŷ = 3 × 2 = 6. Loss L = (6 - 4)² = 4.
  2. Gradient: ∂L/∂w = 2(ŷ - y)x = 2 × 2 × 2 = 8.
  3. Update: w = 3 - 0.1 × 8 = 2.2. New ŷ = 4.4, new loss = 0.4² = 0.16.

Learning efficiency depends on: learning rate, optimizer, batch size, activation, weight initialization, loss function, data, regularization, batch normalization.

Overfitting and regularization

asked in 3 of 5 papers1 in assignments

Overfitting means a model is very good on training data but poor on new data, and regularization is the set of tricks that reduces it by keeping the model simple.

Must write
  • Underfitting: model too simple, poor on both training and testing data (high bias).
  • Overfitting: learns training data including noise, very high training accuracy but low testing accuracy (high variance).
  • Sign of overfitting: training loss keeps falling but validation loss rises.
  • Regularization: Total Loss = Prediction Error + Regularization Penalty, so large weights are discouraged. λ controls strength.
  • Techniques: L1, L2, dropout, early stopping, data augmentation (also batch normalization, simpler model, more data).

Example: underfitting calls an apple a banana; overfitting learns "an apple always has a black spot", so a spotless apple is "Not Apple".

CNN architecture and workflow

asked in 4 of 5 papers1 in assignments

A CNN is a deep network for images that learns features automatically with convolution filters, then uses fully connected layers and softmax to decide the class.

Must write
  • CNN = convolution + pooling (feature extractor), then flatten + fully connected + softmax (classifier).
  • Local connectivity, weight sharing and pooling give far fewer parameters than a fully connected network.
  • Convolution: filters slide over the image and give feature maps; ReLU turns negatives to 0.
  • Pooling reduces height and width, not depth. Flatten turns the 3D maps into a 1D vector.
  • Softmax gives class probabilities that add to 1; the largest is the prediction.

Why CNN

A fully connected network on a 28 × 28 image with 100 neurons needs 784 × 100 = 78,400 weights and loses where pixels are. A CNN reuses small filters, so it needs far fewer parameters and keeps position.

  • Filter weights are not set by hand: prediction, loss and backpropagation update them.
  • Padding adds border pixels; stride is how far the filter jumps.
  • Uses: image classification, face recognition, object detection, medical images.

CNN numericals: output size and parameters

asked in 1 of 5 papers3 in assignments

For a convolution layer, output size is ⌊(N - F + 2P)/S⌋ + 1 with depth equal to the number of filters, and parameters are (F × F × D + 1) × K.

Must write
  • Output height and width = ⌊(N - F + 2P)/S⌋ + 1; output depth = K (number of filters).
  • Each filter has the depth of its input: F × F × D.
  • Parameters = (F × F × D + 1) × K; the +1 is the bias of each filter.
  • Stride and padding change the output size, not the parameter count. Image size never appears in the parameter count (weight sharing).
  • Max pooling output = (N - F)/S + 1, with no parameters.

Method (3 steps)

  1. Write the given values N, D, F, K, S, P.
  2. Output size from the formula, depth = K.
  3. Parameters = (F × F × D + 1) × K.

Sum 1: Assignment 2, Q4d (two layers)

Input 100×100×3. Layer 1: 8 filters 3×3, S = 1, P = 0. Layer 2: 1 filter 3×3, S = 1, P = 0.

  1. Layer 1 output: (100 - 3 + 0)/1 + 1 = 98, depth 8, so 98×98×8.
  2. Layer 1 params: filter is 3×3×3 = 27 weights + 1 bias = 28; 28 × 8 = 224.
  3. Layer 2 output: (98 - 3)/1 + 1 = 96, depth 1, so 96×96×1.
  4. Layer 2 params: the filter must be 3×3×8 (depth of its input, not 3): 72 + 1 = 73.
  5. Total = 224 + 73 = 297.

Sum 2: Dec 2024, Q4b (10 marks)

Input 64×64 with 32 channels; 64 filters 3×3, S = 1, P = 0. Find the parameters.

  1. Weights per filter: 3 × 3 × 32 = 288 (the filter covers all 32 channels).
  2. All filters: 288 × 64 = 18,432 weights. Biases: 64.
  3. Total with bias: (288 + 1) × 64 = 289 × 64 = 18,496. Output: (64 - 3)/1 + 1 = 62, so 62×62×64.

RNN and backpropagation through time

asked in 4 of 5 papers

An RNN reads a sequence one item at a time and keeps a hidden state (its memory) of what it has seen, using the same weights at every step.

Must write
  • RNN = a network with a hidden state, so past output is used as input; it is made for sequential data.
  • Same cell and same weights (U, W, V) at every time step: fewer parameters, any length.
  • ht = tanh(U xt + W ht-1 + b) and ŷt = softmax(V ht + c).
  • BPTT = forward through time, loss, backward through time, update weights.
  • Vanishing gradient (too small) and exploding gradient (too large) come from multiplying the same factor at every step.

Working, step by step

  1. Take input xt and previous hidden state ht-1.
  2. Combine them: ht = tanh(U xt + W ht-1 + b); output ŷt = softmax(V ht + c).
  3. Pass ht to the next step. The weights never change between steps.

BPTT (backpropagation through time)

  1. Forward pass: read the whole sequence, get all ht and outputs.
  2. Loss: add the loss of every step.
  3. Backward pass: send the error back from the last step to the first. A shared weight gets the sum of its gradients from all steps.
  4. Update the weights, repeat.
∂L/∂W = Σt ∂Lt/∂W, and the gradient reaching step k contains the product ∂ht/∂ht-1 × ... × ∂hk+1/∂hk

LSTM

asked in 3 of 5 papers1 in assignments

LSTM is an RNN with a cell state (long-term memory) and three gates that decide what to forget, what to add and what to output, so it can learn long-term dependencies.

Must write
  • RNN problem: vanishing gradient, so long-term dependencies are lost ("I grew up in India ... I speak Hindi").
  • Two states: cell state Ct (long-term) and hidden state Ht (short-term).
  • Three sigmoid gates (values 0 to 1): forget, input, output.
  • Ct = ft Ct-1 + it Nt, Ht = ot tanh(Ct).
  • The cell state changes only a little each step, so information and gradient pass through many steps.

The gates (σ = sigmoid, 0 forgets, 1 keeps)

GateEquationJob
Forgetft = σ(xtUf + Ht-1Wf)remove useless old memory
Inputit = σ(xtUi + Ht-1Wi)choose what new memory to add
New infoNt = tanh(xtUc + Ht-1Wc)the candidate to add
Outputot = σ(xtUo + Ht-1Wo)decide what to show as output
Ct = ft · Ct-1 + it · Nt    Ht = ot · tanh(Ct)

Worked step: f = 0.2, Ct-1 = 10, i = 0.8, N = 5. Then Ct = 0.2×10 + 0.8×5 = 2 + 4 = 6.

How LSTM fixes the RNN limit

  • RNN memory is overwritten at every step and the gradient is multiplied again and again.
  • LSTM changes the cell state by a small forget and a small add, so old information and the gradient travel many steps almost unchanged.
  • Gates choose what to keep, so it learns long-term dependencies.

LSTM vs GRU

asked in 3 of 5 papers

GRU is a simpler gated RNN with only two gates (reset and update) and no separate cell state, while LSTM has three gates and a cell state.

Must write
  • Both fix the long-term dependency (vanishing gradient) problem of the basic RNN.
  • LSTM: cell state + hidden state, 3 gates (forget, input, output).

Autoencoders

asked in 3 of 5 papers2 in assignments

An autoencoder is a network that squeezes its input into a small code and then rebuilds the input from that code (goal: output ≈ input), with no labels needed.

Must write
  • Three parts: encoder, bottleneck (code / latent space), decoder.
  • Unsupervised: the input is its own target; loss = reconstruction error (MSE).
  • Undercomplete: code has fewer neurons than the input, so it cannot just copy.
  • Types differ only by an extra rule: sparse, denoising, contractive, VAE.
  • Write the loss of every type you explain.

Types of autoencoder

TypeWhat makes it differentLoss
Undercompletecode smaller than input, so it must compressreconstruction
Sparseonly a few hidden neurons active at a time (suits overcomplete layers)reconstruction + sparsity penalty (L1 or KL)
Denoisingnoisy input, clean target; learns robust featuresreconstruction against the clean input
Contractivesmall input change gives small code change (stable features)reconstruction + λ‖∂h/∂x‖F2
VAEencoder gives mean μ and variance σ²; samples z = μ + σε; can generate new datareconstruction + KL divergence

Training in short

  1. Input goes through encoder, code, decoder.
  2. Loss: MSE = (1/n) Σ (x - x')².
  3. Backpropagation updates weights; repeat until the error is small.
  • Undercomplete vs overcomplete: overcomplete has more hidden neurons than input and can copy, so it needs sparse or denoising rules.
  • Uses: compression, denoising, dimensionality reduction, anomaly detection, generation (VAE).
  • Drawbacks: output not exactly equal to input; a too-small bottleneck loses information.

GAN

asked in all 5 papers1 in assignments

A GAN is a model that makes new data that looks real, using two networks that compete: a generator that makes fakes and a discriminator that tells real from fake.

Must write
  • GAN = generator G + discriminator D trained against each other.
  • G: random noise in, fake sample out; goal is to fool D (forger).
  • D: real or fake sample in, REAL/FAKE out; goal is to tell them apart (examiner).
  • Minimax game: minG maxD E[log D(x)] + E[log(1 - D(G(z)))].
  • After training only the generator is used to make new samples from new noise.

Training steps

  1. G takes random noise and makes a fake sample.
  2. D gets real samples and fake samples and says real or fake.
  3. Loss: if D errs its loss rises; if G is caught its loss rises.
  4. Backpropagation updates D (better judge) and G (better forger).
  5. Repeat until D can no longer tell the difference.

The loss

minG maxD V(D, G) = Ex[log D(x)] + Ez[log(1 - D(G(z)))]
  • D wants D(x) near 1 for real x and D(G(z)) near 0 for fake, so it maximizes V.
  • G wants D(G(z)) near 1, so it minimizes V.
  • Example: fake currency; forger (G) versus examiner (D).
PartInputOutput
Generatorrandom noisefake sample
Discriminatorreal or fake sampleREAL or FAKE

Uses: image generation, image-to-image translation, super-resolution, restoration, synthetic data, DeepFake (misuse risk). Problems: unstable training, mode collapse (G keeps making a few similar outputs).
