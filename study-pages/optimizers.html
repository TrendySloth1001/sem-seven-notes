2. The big idea: each one fixes the last

  • Momentum remembers the previous update, so the path is smooth. Problem: it can overshoot.
  • NAG checks the slope ahead before moving. Fixes the overshoot.
  • AdaGrad gives every weight its own learning rate. Problem: the rate keeps shrinking.
  • RMSProp uses only recent gradients. Fixes the shrinking rate.
  • Adam = Momentum + RMSProp. Fast and stable, the most popular.
One-line memory trickMomentum = direction memory. AdaGrad and RMSProp = speed control per weight. Adam = direction memory + speed control.

3. NAG (Nesterov Accelerated Gradient)

Explain in simple words

Momentum moves first and corrects later, like turning the steering wheel only after you reach the curve. NAG first looks ahead using the momentum, calculates the gradient at that look-ahead point, and then moves. If the look-ahead point has already gone past the bottom, the gradient there points back, so NAG brakes in time.

How to draw it: a bowl, a dot on the left side, a dashed jump past the bottom, a small red arrow back from there, then a solid arrow to the final point.

Formulas (teacher, slide 78, with the sign corrected)

Wlook = W + β·Vt−1
Vt = β·Vt−1 − η·∇L(Wlook)
Wnew = Wold + Vt

The slide prints Wlook = W − βV. With the slide's own update (W + V), the velocity V already carries the minus sign, so the look-ahead is W + βV. Write the corrected form.

Small numerical (my own example, to show the difference)

Loss L = W², so gradient = 2W. Start W = 5, V = 0.5, β = 0.9, η = 0.1.

MomentumNAG
Where the gradient is measuredW = 5, gradient 10Wlook = 5 + 0.9×0.5 = 5.45, gradient 10.9
Velocity V0.9×0.5 − 0.1×10 = −0.550.45 − 0.1×10.9 = −0.64
New W5 − 0.55 = 4.455 − 0.64 = 4.36

NAG sees the steeper slope ahead and corrects harder. On a loss that curves back up, this is what prevents the overshoot.

Write in the exam Definition: Nesterov Accelerated Gradient (NAG) is an improved version of momentum gradient descent. Instead of calculating the gradient at the current position, it first looks ahead using the momentum and then calculates the gradient there.
Working: (1) use momentum to look ahead, (2) calculate the gradient at the look-ahead position, (3) update the weights with this better gradient.
Example: Momentum turns the steering wheel after seeing the curve; NAG sees the curve ahead and turns before reaching it.
Result: better direction, less overshooting, faster convergence.

4. AdaGrad (Adaptive Gradient)

Explain in simple words

Plain gradient descent uses one learning rate for every weight. But some weights get updated all the time and some almost never. AdaGrad gives each weight its own learning rate: weights updated often get a smaller rate, weights updated rarely get a larger rate. It does this by keeping a running total of each weight's squared gradients.

Teacher's example: a teacher gives less attention to students who already understand and more to those who are struggling.

Formulas (slide 81)

Gt = Gt−1 + gt²
Wnew = Wold − ( η / (√Gt + ε) ) · gt

gt = current gradient, Gt = sum of all past squared gradients, η = initial learning rate, ε ≈ 10−8 (stops division by zero).

Small numerical (my own example)

η = 0.1, gradients 0.4 then 0.3.

StepGtRate η/√GStep size = rate × g
10.160.1 / 0.4 = 0.250.25 × 0.4 = 0.100
20.16 + 0.09 = 0.250.1 / 0.5 = 0.200.20 × 0.3 = 0.060

The rate fell from 0.25 to 0.20 and will keep falling, because G only grows.

AdvantagesDisadvantages
Rate adjusts automatically; no manual tuning per weight; good for sparse data (text, NLP, recommendations)The rate keeps decreasing, training slows down, it may stop before the best solution; not ideal for long deep-learning training
Write in the exam Definition: AdaGrad (Adaptive Gradient) is an optimizer that gives each weight its own learning rate. Frequently updated weights get a smaller rate and rarely updated weights get a larger rate.
Working: calculate the gradient, accumulate the squared gradients, adjust each weight's learning rate automatically.
Formulas: the two above.
Limitation: the accumulated sum keeps growing, so the learning rate shrinks toward zero. (This leads to RMSProp.)

5. RMSProp (Root Mean Square Propagation)

Explain in simple words

AdaGrad never forgets: its total only grows, so the learning rate dies. RMSProp keeps a moving average of squared gradients, so only recent gradients matter and old ones fade away. The learning rate stays healthy.

Teacher's example: preparing for an exam. AdaGrad remembers every mistake you ever made and becomes too cautious. RMSProp mainly focuses on your recent mistakes, old mistakes matter less, and you keep improving.

Formulas (slide 84)

St = β·St−1 + (1 − β)·gt²
Wnew = Wold − ( η / (√St + ε) ) · gt

β = decay rate (usually 0.9). The only change from AdaGrad is how the total is kept: AdaGrad adds g² forever, RMSProp averages it with decay.

Same gradients as before (my own example), β = 0.9, η = 0.1

StepStRate η/√SStep size
1 (g = 0.4)0.1 × 0.16 = 0.0160.1 / 0.1265 = 0.790.79 × 0.4 = 0.316
2 (g = 0.3)0.9×0.016 + 0.1×0.09 = 0.02340.1 / 0.1530 = 0.650.65 × 0.3 = 0.196

AdaGrad's rate on the same gradients was 0.25 then 0.20, and it keeps falling. RMSProp's rate is larger and settles instead of dying. (Early on, RMSProp's start is large because S starts at zero; Adam's bias correction fixes this.)

AdvantagesDisadvantages
Solves AdaGrad's vanishing rate; adaptive; faster, stable; good for deep networks and RNNsNeeds β and η tuned; slightly more computation than AdaGrad; usually outperformed by Adam
Write in the exam Problem with AdaGrad: it adds all past squared gradients, so the learning rate shrinks to almost zero and learning stops.
Definition: RMSProp adjusts the learning rate using a moving average of squared gradients, so only recent gradients matter.
Formulas: the two above. Example: the exam-preparation example.

6. Adam (Adaptive Moment Estimation)

Explain in simple words

Momentum fixes direction. RMSProp fixes speed. Each solves only one problem, so Adam combines both: it keeps an average of the gradients (like momentum) and an average of the squared gradients (like RMSProp), corrects both for their zero start, and updates the weight.

Teacher's example (driving a car): momentum remembers the direction, RMSProp adjusts the speed to the road, Adam does both at the same time.

Four formulas (slide 87)

1. mt = β₁·mt−1 + (1 − β₁)·gt
2. vt = β₂·vt−1 + (1 − β₂)·gt²
3. m̂t = mt / (1 − β₁t) , v̂t = vt / (1 − β₂t)
4. Wnew = Wold − η · m̂t / (√v̂t + ε)

Defaults: β₁ = 0.9, β₂ = 0.999, ε = 10−8. Why bias correction: m and v start at 0, so the first estimates are too small; dividing by (1 − βt) fixes that.

First step, worked (g₁ = 0.4, η = 0.1)

  1. m₁ = 0.1 × 0.4 = 0.04 and v₁ = 0.001 × 0.16 = 0.00016
  2. m̂₁ = 0.04 / 0.1 = 0.4 and v̂₁ = 0.00016 / 0.001 = 0.16, so √v̂₁ = 0.4
  3. Step = 0.1 × 0.4 / 0.4 = 0.1, so W decreases by 0.1
Write in the exam Definition: Adam (Adaptive Moment Estimation) combines Momentum, which remembers the previous direction, and RMSProp, which adapts the learning rate. It is one of the most popular optimizers because training is fast, stable and efficient.
Working: calculate the gradient, use momentum to remember previous updates, use RMSProp to adjust the learning rate, update the weights, repeat until the loss is minimum.
Formulas: the four above. Example: the car example.

9. Common mistakes

  • Forgetting ε in the denominator, or writing Gt without the square root.
  • Saying AdaGrad "averages"; it adds. RMSProp averages.
  • Writing Adam without the bias-correction step, or without the defaults 0.9 and 0.999.
  • Writing the NAG look-ahead as W − βV; with the update W + V it is W + βV.

10. Self-test (cover the answers)

What does NAG do differently from momentum?

It calculates the gradient at the look-ahead position, not the current one.

Why does AdaGrad's learning rate go to zero?

It sums all past squared gradients, which only grow, and the rate is divided by that sum.

What one change turns AdaGrad into RMSProp?

Replace the running sum by a decaying moving average (decay β, usually 0.9).

Which two optimizers is Adam built from?

Momentum (m) and RMSProp (v).

Why does Adam use bias correction?

m and v start at zero, so the early values are too small; dividing by (1 − βt) corrects this.

When would you use AdaGrad?

Sparse features (many zeros) such as text classification, NLP and recommendation systems.
